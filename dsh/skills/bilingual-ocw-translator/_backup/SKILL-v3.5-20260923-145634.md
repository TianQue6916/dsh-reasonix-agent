# 第 1 章 🚨 铁律（不可违反）

> 所有 🚨 规则集中于此。**每次开工前默念一遍。** 每条都来自实战教训（prob7sol / Strang 50 页 / PS01 / lec16 / lec18 / lec19 / L12），违反任一铁律的交付视为不合格。
> 铁律分四类：**格式类（1-10）**、**分工类（11-13）**、**来源类（14-18）**、**流程类（19-20）**。历史教训溯源见 HISTORY.md 8.2。

## 格式类铁律

### 铁律 1：禁止英中分段对照（最高铁律）

输出必须是**中文主体 + 英文术语行内嵌入**的单行双语格式。**绝对禁止**「先写完整英文段落、再写中文翻译段落」的对照模式。

```
❌ In a weighted directed graph G = (V, E), the weighted eccentricity ε(u) of a vertex u ∈ V is...
   在带权有向图 G = (V, E) 中，顶点 u ∈ V 的 weighted eccentricity（带权离心率）ε(u)...

✅ 在带权有向图 G = (V, E) 中，vertex（顶点）u ∈ V 的 weighted eccentricity（带权离心率）ε(u) 是其到最远 vertex v 的最短带权距离。
```

**识别方法**：输出中任何一行以英文单词开头、长度超 10 词且后面紧跟一行中文翻译，即违规。正确的输出中**没有完整的英文原句**。

### 铁律 2：英文句子开头禁止

**每句话第一个字必须是中文**，不能以英文单词开句。
`❌ A sequence（序列）就是...` → `✅ 一个 sequence（序列）就是...`

### 铁律 3：术语格式 English（中文），仅首次加括号

格式：**`English term（中文翻译）`**——英文术语先出现，中文翻译括号紧随。同一术语**首次出现**时加括号，**后续出现省略括号**（避免冗余）。
`❌ 用 real numbers（实数）来研究 real numbers（实数）` → `✅ 用 real numbers（实数）来研究实数的性质`

### 铁律 4：不合并句子（逐句翻译）

原文**每一句都对应至少一句中文翻译**，不得将 3-5 句压缩为 1 句。逐句阅读 → 逐句翻译 → 逐句输出。
**密度标准**：每页 30-40 行译文、平均每行 6-7 个中文字——低于此密度即为概括式伪翻译。

### 铁律 5：LaTeX 环境内不翻译

`$...$`、` ```math ` fenced block、`\begin{}...\end{}` 环境内的任何文本（包括 `\text{}` 内的内容）保持英文原样，不做翻译。

### 铁律 6：行内 `$...$`，块级 ` ```math `，禁止 `$$`

- 所有数学公式必须用 LaTeX：`$O(n \log n)$`、`$\delta(s,v)$`、`$x_n$`、`$\{a,b,c\}$`、`$\le$` 等，**不得用文字代替**（`❌ O(|V|³)`）
- **禁止 `$$...$$`**（MarkText 渲染异常）；块级公式用 fenced math block：
  ````markdown
  ```math
  公式
  ```
  ````
- 数集用 `\mathbb{}`（$\mathbb{R}, \mathbb{Q}, \mathbb{Z}, \mathbb{N}$）；变量用斜体（$x, m, n, h$）
- **禁止 Unicode 上下标字符**（₀₁₂₃₄₅₆₇₈₉、⁰¹²³⁴⁵⁶⁷⁸⁹）——内置字体不含 glyph，渲染成黑块；一律用 LaTeX `$x_n$`/`$x^n$`
- 定理陈述独立成命题，证明以 $\square$ 结尾

### 铁律 7：标题标记在行首

`#` `##` `###` `####` 等 heading markers 必须位于行首，前面不能有 `<span>` 或其他 HTML tag，否则 Markdown 解析器不识别为标题。
`✅ ### <span ...>**[problem]**</span> Title` | `❌ <span ...>**[problem]**</span> ### Title`

### 铁律 8：禁止 `<div>`

`<div>` 在 MarkText 中不渲染（显示"空的HTML块"）。用标题层级实现视觉区分，`>` blockquote 虚化次要内容。

### 铁律 9：教材的非必要习题直接跳过，例题必须翻译

- **例题（Examples）必须完整行内双语翻译**——例题是核心教学载体，其描述、推导、结论全部按标准格式翻译
- **教材的非必要习题（Exercises）直接跳过**——不保留原文、不收录进翻译稿。常规练习题与正文核心论证无关，翻译稿中省略（如需练习请读原书；练习时阅读英文原题是必要的学术技能）。仅当习题被正文核心论证直接引用、不翻译会破坏正文可读性时（**必要习题**），才保留英文原题并允许最小翻译
- 被收录的必要习题答案保持英文原文，只有过程性描述可做最小翻译（如"Proof（证明）"标签本身）
- Notes、Theorems/Proofs/Definitions、正文段落**完整行内双语翻译**

### 铁律 10：字幕引文必须附带中文翻译

注中引用视频字幕（🎥 标注的教授原话）时，**每条引文必须附带中文翻译**，禁止只写英文原文。

```
✅ 🎥 *Demaine 强调*："Because we memoize, we'll only solve each subproblem once."（翻译：因为我们做了记忆化，每个子问题只会被求解一次。）
❌ 🎥 *Demaine 强调*："Because we memoize, we'll only solve each subproblem once."
```

- 格式：`🎥 *教授名在视频中[教学动作]*："English original text"（翻译：中文翻译）`；引文较长可改用破折号——即「中文翻译」
- 一条注内多条引文**每条**都要单独翻译；翻译可意译，可在翻译后追加括号解释，但不得以解释替代翻译
- dsh 任务 prompt 必须包含本规则

## 分工类铁律

### 铁律 11：核心翻译——小规模主代理直译，大规模 25×2 dsh 任务分工

- **小规模（≤50 页 / ≤500 行英文）**：主代理直接逐句翻译，审计/写注走 dsh（铁律 12/21）
- **大规模（>50 页）**：一律 dsh 任务翻译——25 个翻译 worker（**dsh flash**，每个分 2 页）+ 10 审计 + 3 写注（**dsh flash**）+ 2 交叉引用，主代理只做切分、组装、派发、合并、回填修订版、最终审查
- **全 dsh 派发（铁律 21）**：Reasonix 内建子代理一律不用，一切 worker = dsh-remote 任务，按主力机并发能力分批派发
- **Strang 教训不丢**：四个陷阱转为翻译 worker 的 prompt 避坑清单（见第 6 章 6.1）

## 来源类铁律

### 铁律 14：补充内容必须有真实来源

写 `[note]` 或 `[alternative]` 前**必须联网查证**（web search / GitHub / 论文检索），不得依赖训练数据瞎写。查不到可靠来源就不写。写完二次审查：(a) 有真实来源支撑 (b) 表述准确无歧义 (c) 与原文清晰区分。不确定的宁可不写。

### 铁律 15：译者注禁止甩名词

每条注 **800-1200 字**（配图/公式/字幕引文不计入），结构完整成"小专题"。跨课程连接必须精确到**课程名 + 具体概念 + 连接路径**（如"你在 6.042J 学过的等价关系，在这里就是 rational number 的相等定义——同一个等价类内的所有分数表示被视为'相同'"），而非"这在群论中叫商集"。每个高级概念要么从用户已知概念出发解释（脚手架法），要么不提。**先查用户学业水平再写注**（记忆 `global/academic-level-and-teaching-style.md`）。

### 铁律 16：每 200 行自检 + 交付前 grep 扫英文行首

翻译过程中**每输出约 200 行执行一次「英中对照自检」**（任何一行以英文单词开头且超 10 词 = 违规）。交付前：
```bash
grep -nE '^[A-Z][a-z]+ [a-z]+' 输出.md
```
人工确认所有疑似英文行首。

### 铁律 17：全量完整输出，不交增量补丁

交付时一次性给出完整章节/全文，不"先给一部分，其余后续补"。修订版必须包含全文或明确标注"仅修订 XX 节"。审计输出完整清单（所有节，不只问题节）。

### 铁律 18：绝不硬编码编号

### 铁律 22：dsh 用量纪律——全任务一档模型（v4.1 flash），难任务靠资料/prompt/多轮（2026-09-10 用户拍板）

> 🚨 **用户原话（2026-09-10）："v4.1 flash 全面超越 pro，以后就都用 v4.1 flash，需要 pro 的地方也换成 flash，不管什么任务都暂时用 flash，只不过难任务需要多查资料多给提示词多优化几轮。"** 全流程只有一档模型 `deepseek-v4.1-flash`；**pro 弃用**；难任务不做模型升级，而是**补充资料 + 加厚 prompt + 多跑几轮迭代**（`-e max` + 局部重跑）。
>
> **怎么应用**：
> 1. **一档模型制**：全流程统一 `dsh-remote -m deepseek-v4.1-flash`；`-e` 按难度选 off/low/high/max，没有 pro 档。
> 2. **小问题主代理直改**：修复注里的错字/粘连、补术语括号、调格式、回填错误等**局部机械小修**，一律主代理直改（或 `dsh-remote -m deepseek-v4.1-flash -e low "任务"`），不必动用大任务。
> 3. **判定"是不是难问题"**：决定的是 **effort 与迭代轮数**，不是模型——需深度推理/长文生成/多步证明 → `-e max` + 必要时多轮；机械替换/格式核对/单点修复 → 主代理直改。
> 4. **难任务的做法**：一批注整体扩写/重写 → `-e max` 一次成批；若只有个别注不合格，只对那几条**局部重跑**（`-e low/high` 小任务），不整批重跑。
> 5. 实战教训（part012 审阅 2026-09-08 + 2026-09-10 校准）：过去把 8 批全发 pro 审阅 → 每批 pro+max 跑 25-40 分钟、批次 7 跑偏；v4.1 flash 全面超越 pro 后，**同质量工作用 flash 跑更快更省**——质量靠 prompt 完整度与迭代轮数，不靠模型档位。

### 铁律 24：扫描版（无文字层）源文件必须做视觉核对（2026-09-23 用户拍板「以后可以多侧重视觉」）

>

>
> **配套必查**（详见 §9.4）：订正会**删注**（订正前后统计译者注条数，丢失的从备份回插）、```math 围栏失衡、任务超 **32767 字符**静默失败（rc=0 零输出）。
>
> **人机分工**：机器负责"看得全"（逐页转写 + 编号比对），人负责"看得懂"（相似度低的地方要人判断是不是等价改写）。

### 铁律 25：替换式改稿必须覆盖到公式边界 + 交付前必跑「公式体检」（2026-09-23 part005 实战）

**踩坑事实**：part005 视觉终校用「old 串只匹配到公式中途、new 串以 `（续）` 结尾」的补丁批量改 50 页，`$` 看似正常，但**7 处公式被撕成两半**：

- 3 处在正文行内 → 例：`从最后一个方程 $x_1 = \lambda x_4$ 出发…于是得到 $\lambda^4 = 1$。**mbda^4 q_1$**，于是…` → `$` 计数变奇数，可被捕获；
- 4 处在 ```math 围栏内 → 例：`... = \lambda_j u_j . \tag{3} **\text{ 1}}{h^2}** = \lambda_j(...)`、`\tag{4} **\text{ 2 \end{bmatrix} \tag{4}**`、`\tag{9}**tag{9}**`、`A for low frequencies, } D for high frequencies}` → **`$` 配对检查完全查不出来**；KaTeX 报错后 `throwOnError:false` 让公式以**裸 LaTeX 文本**出现在成品 PDF 里（`\frac`、`\begin{bmatrix}` 直接印在纸上），直到渲染完逐页看才发现 —— 白跑两轮渲染。

**三条纪律**：

1. **补丁的 old 串必须覆盖到公式/围栏的自然边界**（整行、整个 ```math 块，或至少到 `\tag{N}` / `\end{...}`）。宁可用更长、更唯一的 old 串，也不要「前半段匹配 + 后半段自动保留」。**严禁**在 new 串末尾留 `（续）`、`\text{`、`\tag{pre}` 这类「占位式接续」标记——它们就是撕裂源。
2. **交付前必跑公式体检**（主代理直跑，秒级；已并入 `check_mechanical_p005.py`）：
   - 围栏外逐行 `$` 计数必须为**偶**（忽略 `\$`）；
   - 围栏内逐行花括号 `{` / `}` 必须**相等**；
   - 围栏内不得出现 `\tag{X} \text{`、`\tag{X}tag`、同行两个 `\tag{`。
3. **改完合并稿必须同步改 `pages/` 源页**，否则下一次 `assemble` 会把回退带回来（part005 出现过这个次序陷阱：先改合并稿、忘了源页，第二次合并又裂开）。

> 💡 **根因**：这类撕裂源于「用替换串模拟续写」。真正安全的做法是**整块替换**（把要改的公式整段写进 old，整段写进 new），或**直接重写该行/该块**。

# 第 3 章 译者注指南（[note] 写法）

> 🚨 **写注用 dsh flash v4.1（铁律 12，2026-09-10：v4.1 flash 全面超越 pro，全任务统一）**

## 3.1 注的类型（6 种）

1. **跨课程连接**：将当前内容与用户知识体系中的其他课程连接。**可用的连接锚点**：离散数学 6.042J（等价关系、偏序集、数论）、CSAPP（浮点表示、机器级编程、内存层次）、CLRS 算法导论（二分搜索、分治、复杂度分析）、线性代数 Strang（矩阵方法、SVD）。具体到课程名和章节，并解释连接路径。
2. **第一性原理洞察**：解释定理背后的核心直觉，追溯最基础的假设。回答"为什么必须这样？"用用户已经理解的简单概念作为脚手架搭建新概念。
3. **证明策略模板**：把证明方法抽象为可复用的思维模板（ε/2 技巧、ε-剥离法、峰点论证、分组放缩、归纳三步法、supremum sandwich 等）。**命名模板**（如"上确界夹逼法""ε-剥离法"）便于记忆复用。
4. **历史与人物**：数学家为什么这么想？当时要解决什么具体问题？对后世的影响。标注具体年份（如 Bolzano 1817、Cauchy 1821、Weierstrass 1872）。⚠️ 2026-09-03 用户校准：**以机制/概念为主，历史只作点缀**，不要堆年表（"查知识不是查历史"）。
5. **拓展前沿**：相关的更高级概念。**必须从用户已知概念出发解释**，不得裸甩名词。如果用户没学过前置知识，要么搭建脚手架解释，要么暂时不提。
6. **图解注（配图辅助理解，2026-09-03 用户要求）**：对空间/结构/流程类概念（子问题 DAG、状态转移表、递推树、依赖图、谱系嵌套图等），**自己生成示意图或找现成图**辅助理解。可以：① 用 matplotlib/graphviz/ASCII 艺术/Mermaid 手绘概念图嵌入注中；② 从离线维基/OCW 原文/教材找现成插图（标注来源）；③ 生成 SVG/PNG 存到译文同目录 `assets/` 并用 Markdown 图片语法引用。图要小、聚焦一个概念、配一句图注，不做装饰性配图。

## 3.2 质量标准（必须严格遵守）

- **每条注 800-1200 字**（配图/公式/字幕引文不计入），信息密度高，不凑数、不注水；写成可独立阅读的"小专题"——机制展开 + 例子 + 连接
- 跨课程连接要明确提及**课程名 + 具体概念 + 连接路径**（如"你在 6.042J 学过的等价关系，在这里就是 rational number 的相等定义——同一个等价类内的表示被视为'相同'"而非"这在群论中叫商集"）
- 🚫 **禁止甩名词**——不得只提高级概念名而不解释。写注前先查 `memory`（`global/academic-level-and-teaching-style.md`）确认用户学业水平
- 分布均匀，每个关键定理至少一条注
- 结合视频字幕中的教授口语化讲解，增加"教学现场感"；引用字幕时使用 `🎥` 标注来源（🚨 铁律 10：每条引文必须附中文翻译）
- 📖 交叉引用：指向用户已有的讲义（如 L01/L02/L03）或教材（如 CLRS §x.y）
- 🖼️ **配图辅助（2026-09-03 用户要求）**：空间/结构/流程类概念尽量配图——自己生成（matplotlib/graphviz/Mermaid/ASCII）或找现成图（离线维基/OCW 原图/教材插图，标来源），存译文同目录 `assets/` 引用；图聚焦单一概念并配图注

## 3.3 拓展连接的铁律（PS01 教训）

用户对拓展知识**有强烈兴趣**（跨学科连接是人格画像核心特征），但**禁止甩名词**——不能只提一个高级概念的名字而不解释。这是 PS01 初版犯的错误（甩了群论/商环/拓扑学/非标准分析等用户没学过的概念）。

**每条拓展连接的处理规则：**

1. **先查学业水平**——写注前必须用 `memory` 工具查询 `global/academic-level-and-teaching-style.md`，判断用户是否已具备理解该概念的前置知识
2. **脚手架法**——如果用户没学过前置知识，要么从第一性原理构建解释（从用户已知的概念出发，逐步推导到新概念），要么暂时不提。**绝不裸甩名词**
3. **精确连接路径**——每条跨课程连接必须精确到：课程名 + 具体概念 + 为什么类比成立 + 区别在哪。不是"这在群论中也有"而是"你在 6.042J 学过的等价关系，在这里就是 rational number 的相等定义——同一个等价类内的所有分数表示被视为'相同'。群论中把这个结构称为'商群'，但核心思想你已经会了。"
4. **拓展 ≠ 炫耀**——拓展的目的是帮用户看到知识地图的全貌，不是展示你懂多少高级概念。如果一个拓展概念需要 3 页纸才能讲清楚，而当前上下文只够提一句名字，那就不要提

## 3.10 费曼式注

## 4.8 交叉引用标注体系（Cross-Reference Mapping）

为每个定理/定义/例子/公式标注其在主教材（源 PDF）中的位置，便于读者在翻译版中快速查询原文。

### 4.8.1 编号体系映射规则

- 页码：`p.47` 表示源 PDF 的书页编号（非 PDF 文件页码）

### 4.8.2 覆盖范围

| 单元类型 | 标注要求 | 示例 |
|---------|---------|------|
| Theorem | 必标 | `TBB §2.9, p.47` |
| Definition | 必标 | `TBB §2.9, p.47` |
| Example | 必标 | `TBB §2.10, p.50` |
| Corollary | 必标 | `TBB §2.8, p.43` |
| Formula (关键公式) | 建议标 | `TBB §2.10, p.51` |
| Exercise | 选标（仅在跨卷引用时） | `TBB §2.9, p.49` |
| Lemma | 必标 | `TBB §3.4, p.85` |

### 4.8.3 跨教材交叉引用

如果翻译内容引用了其他教材中的定理（如讲义中说"见 CLRS Theorem 24.8"），也要标注：
```
> <span style="color:#7f8c8d;">CLRS §24.5, p.661 | TBB §2.9, p.47</span>
```

### 交叉引用锚点命名（可选增强）

统一锚点便于读者检索：`sec:` 节、`thm:` 定理、`def:` 定义、`eq:` 公式、`lem:` 引理、`ex:` 例子。引用写作格式：`见 [thm:2.28] Theorem 2.28（单调收敛定理）的证明`，同时保留灰色引用行。

## 8.4 本轮教训（全部实测，违反必返工）

1. **🚨 dsh 结果文件会互相覆盖**：`dsh-gate-conc.ps1` 的结果文件名精度只到"秒"，同秒完成的两个并发任务写同一路径 → **必须按 TaskId 读 `%TEMP%\dsh-gate\<TaskId>-<model>.diag.txt`**（diag 名含 TaskId，唯一）。
2. **diag 里 reasoning 与答案混排**：前 30-3200 行是英文思考流，答案起点 = **最后一个** `### <span ...**[problem]**`（题块任务）或 `# <span ...18.065`（课程头任务）。dsh 偶发**重复输出整题**（前一遍带 reasoning 碎片）→ 取最后一处起点即得干净全文。
3. **超长输出会触发流式中断**（TRANSPORT / `rc=-1`）：单任务要求"输出 30000 字"实测失败（114s/279s 中断）→ **按题拆分**（每题输出 ≤20K 字符）后 11 个终审任务 100% 成功（34-185s）。
4. **dsh 会丢 span 引号**：输出写成 `<span style=color:#xxxxxx;>` → 回填时机械修复为 `<span style="color:#xxxxxx;">`（并统一 `[solution]` 用 `#1e8449`、h2 用 `#c0392b`）。
5. **注普遍超长**：每题一个任务时 dsh 倾向把一切塞进注（实测单条 2000-8000 字）。终审 prompt 必须显式写「按主题拆分为多条 800-1200 字注，🚫 不得为压字数删数学内容/例子/跨课程连接」——实测可拆为（其一）…（其六），拆分后正文汉字 500-1000（公式/引文不计）。

## 8.9 PDF 渲染与交付：四道实测坑（2026-09-23 part005 全流程验证）

> 交付物：`part005.bilingual.md`（314,967 bytes / 2,474 非空行 / 49,330 汉字）→ 横版 41 页 + 竖版 35 页 PDF，公式 3,660 个，泄漏点 **0**。

1. 🚨 **`os.tmpdir()` 会被 Reasonix 会话重定向**：本会话 `os.tmpdir()` = `...\Temp\reasonix-session-tmp-<pid>`，而依赖装在 `...\Temp\pdfbuild\node_modules` → 沿用旧脚本的 `path.join(os.tmpdir(), "pdfbuild", "node_modules")` 必然 `MODULE_NOT_FOUND`。

3. 🚨 **渲染后必做「泄漏扫描」**（`scan_pdf_leaks.py`）：PyMuPDF 逐页 `get_text()`，grep `\tag{`、`\begin{`、`\end{`、`\frac{`、`\mathrm{` 等**只该出现在公式里的命令**；命中 = KaTeX 渲染失败、公式以裸文本入 PDF。**交付目标值 0**。（配套的 md 侧体检见铁律 25。）
4. 🚨 **WPS 打开必须用 `ksolaunch.exe`，不是 `office6\wps.exe`**（2026-09-23 实测，`.md`/`.pdf` 都一样）：

## 9.5 可复用脚本（第 9 章产物，直接抄到新工作区）

**`vision_ocr.py`** — 批量视觉转写：渲染页 → 缩图 → v4.1 → `vision_out/page_NNN.txt`（带宽 1100 + JPEG q85 + 浏览器 UA）

```python
# -*- coding: utf-8 -*-
"""Batch-transcribe the scanned pages with the vision-capable GOAT model.

Purpose: get an authoritative transcription (formulas in LaTeX) of each source
page, so the translation can be diffed against the original instead of against
the noisy Windows-OCR text.

Usage: python vision_ocr.py [start_page] [end_page] [workers]
Writes: <WS>/vision_out/page_NNN.txt  (one file per page)
"""
import base64, io, json, os, re, sys, time, urllib.request, urllib.error
from concurrent.futures import ThreadPoolExecutor
from PIL import Image
sys.stdout.reconfigure(encoding='utf-8')

WS = r"C:\Users\27063\AppData\Roaming\reasonix\文件翻译\strang_p004"
PNG = r"C:\Users\27063\strang_ocr_pages_p004"
OUT = os.path.join(WS, "vision_out")
os.makedirs(OUT, exist_ok=True)

HOME = os.path.expanduser("~")
key = None
for ln in open(os.path.join(HOME, ".dsh", ".env"), encoding="utf-8", errors="replace"):
    m = re.match(r'^\s*COMMANDCODE_API_KEY=(.*)$', ln.strip())
    if m:
        key = m.group(1).strip().strip('"').strip("'")
stxt = open(os.path.join(HOME, ".dsh", "settings.yaml"), encoding="utf-8-sig", errors="replace").read()
base = re.search(r'(?mi)^\s*baseURL:\s*(\S+)', stxt).group(1).strip().strip('"')
URL = base.rstrip("/") + "/chat/completions"
MODEL = os.environ.get("VISION_MODEL", "deepseek-v4-flash-vision-exp")

PROMPT = ("This is a scanned page from Gilbert Strang's 'Linear Algebra and Learning From Data'. "
          "Transcribe it faithfully: every sentence and EVERY formula. "
          "Write all mathematics as LaTeX (\\\\frac, \\\\lambda, \\\\begin{bmatrix} ...). "
          "Keep equation numbers like (23). Do not summarize, do not translate, do not add commentary.")

def transcribe(pdfpage):
    dst = os.path.join(OUT, f"page_{pdfpage}.txt")
    if os.path.exists(dst) and os.path.getsize(dst) > 400:
        return (pdfpage, "cached")
    idx = pdfpage - 150
    src = os.path.join(PNG, f"page_{idx:03d}.png")
    im = Image.open(src).convert("RGB")
    w, h = im.size
    im = im.resize((1100, int(h * 1100 / w)), Image.LANCZOS)
    buf = io.BytesIO()
    im.save(buf, format="JPEG", quality=85)
    b64 = base64.b64encode(buf.getvalue()).decode()
    payload = {"model": MODEL, "messages": [{"role": "user", "content": [
        {"type": "text", "text": PROMPT},
        {"type": "image_url", "image_url": {"url": "data:image/jpeg;base64," + b64}}]}],
        "max_tokens": 8192}
    req = urllib.request.Request(URL, data=json.dumps(payload).encode(),
                                 headers={"Content-Type": "application/json",
                                          "Accept": "application/json",
                                          "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                                                        "AppleWebKit/537.36 (KHTML, like Gecko) "
                                                        "Chrome/126.0.0.0 Safari/537.36",
                                          "Authorization": "Bearer " + key})
    try:
        with urllib.request.urlopen(req, timeout=600) as r:
            out = json.load(r)
        msg = out["choices"][0]["message"]["content"]
        open(dst, "w", encoding="utf-8").write(msg)
        return (pdfpage, f"ok {len(msg)} chars")
    except urllib.error.HTTPError as e:
        return (pdfpage, f"HTTP {e.code} {e.read()[:200].decode('utf-8','replace')}")
    except Exception as e:
        return (pdfpage, f"ERR {type(e).__name__} {e}")

if __name__ == "__main__":
    a = int(sys.argv[1]) if len(sys.argv) > 1 else 151
    b = int(sys.argv[2]) if len(sys.argv) > 2 else 200
    workers = int(sys.argv[3]) if len(sys.argv) > 3 else 3
    pages = list(range(a, b + 1))
    print(f"transcribing {len(pages)} pages with {MODEL}, {workers} workers", flush=True)
    done = 0
    with ThreadPoolExecutor(max_workers=workers) as ex:
        for pg, res in ex.map(transcribe, pages):
            done += 1
            print(f"[{done}/{len(pages)}] page_{pg}: {res}", flush=True)
    print("ALL DONE", flush=True)

**`diff_tags.py`** — 编号存在性比对：原文 vs 译文的 `\tag{n}` / `(n)`，输出缺失编号及其原文公式

```python
# -*- coding: utf-8 -*-
"""Reliable diff: equation-number presence, plus the original formula body for
each number the translation is missing (so a human can judge quickly).
"""
import os, re, sys, glob
sys.stdout.reconfigure(encoding='utf-8')

WS = r"C:\Users\27063\AppData\Roaming\reasonix\文件翻译\strang_p004"
PAGES = os.path.join(WS, "pages")
VIS = os.path.join(WS, "vision_out")

DISPLAY = re.compile(r'(?:\\\[(.*?)\\\]|\$\$(.*?)\$\$|\\begin\{equation\*?\}(.*?)\\end\{equation\*?\})', re.S)

def vision_tags(text):
    out = {}
    for m in DISPLAY.finditer(text):
        body = next(g for g in m.groups() if g is not None)
        for tg in re.finditer(r'\\tag\{(\d+)\}', body):
            out[int(tg.group(1))] = body.strip()
    # inline tags (vision sometimes emits plain (n) at line end after a formula line)
    for m in re.finditer(r'(?m)^(.*?)\s*\\tag\{(\d+)\}\s*$', text):
        out.setdefault(int(m.group(2)), m.group(1).strip())
    # bare printed numbers like  (13)  at line end
    for m in re.finditer(r'(?m)^(.*?)\s*\((\d{1,2})\)\s*$', text):
        out.setdefault(int(m.group(2)), m.group(1).strip())
    return out

def trans_tags(text):
    out = {}
    for m in re.finditer(r'```math\s*\n(.*?)\n```', text, re.S):
        body = m.group(1)
        tg = re.search(r'\\tag\{(\d+)\}', body)
        if tg:
            out[int(tg.group(1))] = body.strip()
    for m in re.finditer(r'(?m)^(.{0,300}?)\\tag\{(\d+)\}\s*$', text):
        out.setdefault(int(m.group(2)), m.group(1).strip())
    for m in re.finditer(r'(?m)^(.{0,300}?)\s*\((\d{1,2})\)\s*$', text):
        out.setdefault(int(m.group(2)), m.group(1).strip())
    return out

print("page\t缺编号\t原文该编号的公式（截断）")
rows = []
for f in sorted(glob.glob(os.path.join(VIS, "page_*.txt"))):
    p = int(re.search(r'page_(\d+)\.txt', f).group(1))
    tp = os.path.join(PAGES, f"page_{p}.bilingual.md")
    if not os.path.exists(tp):
        continue
    vt = vision_tags(open(f, encoding="utf-8").read())
    tt = trans_tags(open(tp, encoding="utf-8").read())
    missing = sorted(set(vt) - set(tt))
    extra = sorted(set(tt) - set(vt))
    if missing:
        print(f"\npage_{p}\t缺 {missing}")
        for n in missing:
            print(f"   ({n}) 原文: " + re.sub(r'\s+', ' ', vt[n])[:230])
    if extra:
        print(f"page_{p}\t译文多出编号 {extra}（疑错号，需核对）")
        rows.append((p, missing, extra))

print("\n===== 汇总 =====")
print("有缺号的页:", [r[0] for r in rows])
```

**`fix_restore.py`** — 从备份恢复被订正误删的译者注 + 重建被删掉开头的 ```math 块

```python
# -*- coding: utf-8 -*-
"""Retry the two repairs with correct logic.

A) page_155: the stray ``` fence closes a ```math block whose opening line was
   deleted by wave-5 -> rebuild the block around the orphan formula line.
B) page_173 / page_188: restore dropped translator notes; identity is now
   (label text + first 20 chars of prose) instead of a shared 40-char prefix.
"""
import os, re, sys, glob, difflib
sys.stdout.reconfigure(encoding='utf-8')

WS = r"C:\Users\27063\AppData\Roaming\reasonix\文件翻译\strang_p004"
PAGES = os.path.join(WS, "pages")
BK = sorted(glob.glob(os.path.join(WS, "backup", "*before-wave5-reback*")))[-1]

# ---------- A) fence ----------
f = os.path.join(PAGES, "page_155.bilingual.md")
lines = open(f, encoding="utf-8").read().splitlines()
opens = [i for i, l in enumerate(lines) if l.strip().lstrip(">").strip().startswith("```")]
if len(opens) % 2 == 1:
    out, fixed = [], False
    for i, ln in enumerate(lines):
        if (not fixed and ln.startswith("C=\\sum")
                and i + 1 < len(lines) and lines[i + 1].strip() == "```"):
            out += ["> ```math", "> " + ln, "> ```"]
            fixed = True
            skip_next = True
            continue
        if fixed and skip_next and ln.strip() == "```":
            skip_next = False
            continue
        out.append(ln)
    open(f, "w", encoding="utf-8").write("\n".join(out) + "\n")
    n = sum(1 for l in out if l.strip().lstrip(">").strip().startswith("```"))
    print(f"page_155 fence rebuilt -> ``` count = {n}")
else:
    print(f"page_155 fence already balanced ({len(opens)} markers)")

# ---------- B) notes ----------
LABEL = re.compile(r'<span style="color:#1e8449;">\*\*\[note\]\s*([^*]{0,40})\*\*</span>\s*(.{0,30})')

def note_blocks(text):
    lines = text.splitlines()
    out = []
    for i, ln in enumerate(lines):
        m = LABEL.search(ln)
        if not m or "OCR" in m.group(1):
            continue
        key = re.sub(r'\s+', '', m.group(1) + m.group(2))[:34]
        j = i + 1
        while j < len(lines):
            s = lines[j]
            if s.strip() == "":
                break
            if s.lstrip().startswith(">") or s.lstrip().startswith("```"):
                j += 1
                continue
            break
        out.append((key, i, j, lines[i:j]))
    return out

for pg in (173, 188):
    cur_f = os.path.join(PAGES, f"page_{pg}.bilingual.md")
    cur = open(cur_f, encoding="utf-8").read()

    cur_keys = {k for k, *_ in note_blocks(cur)}

    cur_lines = cur.splitlines()

    for key, oi, oj, block in old_blocks:
        if key in cur_keys:
            continue
        prev = [l for l in old.splitlines()[:oi] if l.strip()]
        prev = prev[-1] if prev else ""
        target = None
        if len(prev) > 12:
            best = None
            for i, l in enumerate(cur_lines):
                if not l.strip():
                    continue
                r = difflib.SequenceMatcher(None, l, prev).ratio()
                if r > 0.55 and (best is None or r > best[0]):

            if best:
                target = best[1] + 1
        if target is None:
            target = next((i for i, l in enumerate(cur_lines) if re.search(r'Strang\s*§', l)), len(cur_lines))
        cur_lines[target:target] = [""] + block
        added += 1
    open(cur_f, "w", encoding="utf-8").write("\n".join(cur_lines) + "\n")
    print(f"page_{pg}: restored {added} note(s); now {len(note_blocks(open(cur_f, encoding='utf-8').read()))} translator note(s)")
