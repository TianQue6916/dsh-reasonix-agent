## 🧠 学习引擎：四问锚点（形态 B 主干）

任何「讲清楚 X」都按四问输出，**缺一问即未完成**（铁律 27/28）。顺序固定，先本质后公式。

**Q1 本质** —— 剥掉所有符号与术语后，它到底断言了什么？写一句**可判真假**的话。若只能复述定义，说明还没懂。

**Q2 公式** —— 给**最小充分形式**（不是最一般形式）+ 逐个符号的现实所指。数学一律「本质 → 公式 → 跨学科连接」，先直觉后符号；不掩盖核心思想，不为化简牺牲正确性。

**Q3 现实承重** —— 现实世界里**哪个系统的哪个功能**由它实现？必须给到「组件 + 该功能」的具体锚点，并做**消失测试**：假设这个概念/机制不存在，哪个系统会在哪一步崩、退化成什么复杂度、报什么错。
- 合格：`cache line` 承重于「CPU 取指与访存带宽」；消失 → 每次访存直落 DRAM，Memory Mountain 谷底变成峰值。
- 不合格：「cache 很重要」「广泛用于计算机系统」——名词搬运，未做承重分析。
- 定位不到 → 写 `[未定位]` + 待查方向，**禁止编造场景**（铁律 27）。

**Q4 拓展进阶** —— 四层各给至少一条**可点开的坐标**（课程节号 / arXiv id / 源码 `文件:行` / 教材章节）：
- **L1 上游**：它依赖哪条更基本的事实？抽掉那条事实它是否还成立？
- **L2 平行**：另一个领域里同构的机制（精确到「课程名 + 概念 + 连接路径」，铁律 15）。
- **L3 实现**：真实代码/硬件里它在哪个模块、哪一行（**读源码 > 读博客**）。
- **L4 前沿**：当前开问题、边界失效处、你今天就能做的验证实验。

四问的完整写法、消失测试题库、卡点卡、Anki 生成、学习会话模板 → `references/learning-engine.md`。

## 📡 资料层：一手优先，社区经验优先

检索顺序固定：**本机 PocketWiki + 离线 ZIM → 课程仓库/本地盘区 → 一手社区源（官方 docs / 源码 / 论文 / errata / awesome-list）→ 网络搜索**（铁律 13/23）。

**来源分级**（每条补充内容必须标等级，铁律 29；**学习法主张同样要标证据级别**，[D] 社区口传不得作为理由，见 `references/learning-science.md`）：
- **A 一手**：论文原文（arXiv / DOI）、源码与 commit、官方文档、标准（RFC / ISA manual）、教材 errata、作者主页讲义与 PSet solution。
- **B 二手**：教科书、综述、他人课程讲义。
- **C 三手**：博客、视频、论坛、知乎/B站——**只用于找入口、术语、直觉、"哪里容易错"，任何结论必须回 A 核对**。

**四条社区经验（直接用）**：① 官方 repo 的 `issues` / `errata` / `CHANGELOG` 常比任何教程更早更准；② awesome-list 只用来建「这个领域真实存在哪些实现/课程」的索引，不当结论；③ 论文先读 abstract + 图 + conclusion，再决定要不要读证明；④ 看不懂就去找**同概念的实现**——跑一遍 > 读十遍。

路径、命令、离线源地址、可信度判据、检索失败降级链 → `references/sources.md`。

## 📚 核心流程

### A · 译文流水线（原 8 步，零改动）

1. **2.1 任务上下文确认**——5 个元问题（文档类型/受众/期望效果/格式约束/其他约束）
2. **2.2 全资源搜索**（铁律 13）——PocketWiki + ZIM 优先，再查盘区/主力机/网络
3. **2.3 读取源文件**——`pdftotext` → `-layout`/`-raw` → `pdfplumber` → TextIn 兜底
4. **2.4 搜字幕**——先读目录结构，不做纯关键词匹配
5. **2.5 分析与排版规划**——结构/功能模块/术语/标题层级/标签配色
6. **2.6 翻译主体**——小规模（≤50 页或 ≤500 行英文）主代理直译；大规模走 7
7. **2.7 大规模路径**——25×2 波次：翻译 25 / 页级审计 10 + 写注 3 + 交叉引用 2 / 超强审计 / 格式审计；主代理只切分·派发·合并·回填
8. **2.8 最终审查**（所有规模必做）——超强审计 + 格式审计（均审计+修复一体）→ Reader Testing 盲检 → 错误记忆落盘

每步参数、审计清单、报告模板、判级标准 → `references/workflow-core.md` + `references/workflow-large-scale.md`。

### B · 学习流水线（v4.0 新增，5 步）

1. **定锚**——这一步要回答哪个问题？在方舟体系里是**中轴 / 前置 / 出口**？答不出生态位就先别往下推。
2. **取料**——按 §资料层 顺序检索；命中即注入，缺料先补料再讲，**不许凭印象讲**。
3. **四问**——Q1 本质 → Q2 公式 → Q3 现实承重（+消失测试）→ Q4 四层拓展。
4. **验证**——给一条可复现验证路径（数值实验 / 构造反例 / 跑源码 / 小证明），跑不通就改口。AI 是**可质疑的推导引擎**，不是知识库。
5. **落盘**——锚点卡（Markdown + 双链）+ `[我的卡点]`（卡在哪 / 为什么卡 / 怎么破）+ 复习队列（Anki tsv 可选）。默认路径：主力机 `C:/Users/27063/Desktop/课程文件/锚点卡/<课程>/<概念>.md`，Anki tsv 同目录 `_anki/`（放进课程文件树，才会随课程 repo 一起备份与同步）；双轨表见 `references/runtime-and-appendix.md` §A2。
