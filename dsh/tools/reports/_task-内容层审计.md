## 判据（五条，逐条查）
1. **覆盖完整性**：对照原 PDF 页范围，有没有整段 / 整节 / 整题漏译，有没有跳页。
2. **术语一致性**：同一个 term 在全文是否出现多种译法；括号方向是否统一为 `English（中文）`（反序 `中文（English）` 是违规，铁律 3）。
3. **译者注质量**：是否有合格 `[译注]`（机制 + 可点开落点 + 800–1200 字）；`[译注]` 是否被错套成原书 `[remark]/[theorem]` 标签配色（源混淆）；是否名词搬运。
4. **注水 / 合并 / 断链**：有没有为了「读起来顺」把推导链压成结论；有没有把原文两句并成一句导致逻辑断；页边界处有没有把中文句子切断。
5. **原文自身的错误**：记号不一致、跳步、印错、自相矛盾 —— 译文有没有如实标 `†`，还是替原文圆场。
