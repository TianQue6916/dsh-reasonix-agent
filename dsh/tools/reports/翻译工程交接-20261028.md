## 四、12 条实测的坑（每条都造成过真实损坏）

| # | 坑 | 规避 |
|---|---|---|
| 1 | `bash heredoc` 把 `\` 折成 `\`，矩阵静默塌成一行，**KaTeX 不报错** | 矩阵/对齐公式用 write 工具写文件，禁 heredoc；交付前 grep `bmatrix\|aligned\|cases` |
| 2 | `extract-formulas.py` v1 剥围栏正则吞正文，**漏检 14% 公式** | 已修行级状态机版；改完这类工具必须用已知文件交叉验证计数 |
| 3 | `/tmp` 在 Git Bash 与 Windows python 下不是同一目录 | 临时文件一律写 `C:/Users/27063/AppData/Local/Temp/` |
| 4 | python 就地改写含公式正文，`\binom`/`\beta` 被转义成 `\x08`/`\x07` | 反斜杠命令用 `chr(92)` 拼；改完立刻重跑 KaTeX |
| 5 | `pdftotext -layout` 默认 Latin1，`≤ ∈ α ≠` 全丢 | 加 `-enc UTF-8`；MIT 讲义必须用 PyMuPDF（`fitz`） |
| 6 | `\tag` 只在 display mode 有效 | 统一用行尾 `\qquad \text{(n)}` |
| 7 | `f'(x)^2` 触发 `Double superscript` | 写 `(f'(x))^2` |
| 8 | 同一行混放裸 `<` 与 `>` 会让公式被 HTML 剥离吃掉 | 数学里写 `\lt` / `\gt` |
| 9 | 合并单元格表格文字层整列错位 | 缺失格标 `†` 并说明「按语义推定」 |
| 10 | 扫描件（`get_text()` ≈0 字符 + 每题 1 图）需 OCR | 不进普通翻译队列 |
| 11 | **多 worker 并发写同一文件会静默覆盖**（MacKay p161-180 实际发生过） | 交付后跑「md5 + 页标记连续性 + 跨文件重复」三查，不能只看 KaTeX |
