# 译注判据（worker 派发模板用）

> 来源：Boyd 凸优化 p161-180 / p181-200 两份交付的 9 条译注在审计中被评为「目前最好的一份」，
> 此处把做法抽成可执行判据。每条都写成「有 X 没有 Y 就不合格」，可直接当 checklist 打勾。
> 适用范围：教材 / 讲义 / 论文翻译里的 `[译注]`。不适用于原书自带的 Remark / Note。

---

## 一、八条判据

### 1. 消失测试 —— 有「抽掉它会崩在哪」，没有就不合格
必须能写出一句可被判真假的话：删掉这个概念 / 定理 / 技巧之后，
**哪个具体结论失效、退化成什么方法、误差或复杂度变成多少**。

- 合格：`没有这个恒等式，(4.30) 就转不成 (4.31)，robust LP 与 p.158 的 SOCP 表示全部失效，只剩在 u 上做网格搜索。`
- 不合格：`这个定理很重要，是凸优化的基础。`（无失效对象）

### 2. 落点 —— 有至少一个可点开的坐标，没有就写 `[未定位]`
§号 / 式号 / 课程节号 / 论文题名 + 期刊 / 代码 `文件:行`，任给其一即算。
**禁止**「详见相关资料」「参考有关文献」。

- 合格：`Boyd §8.5.1；§A.1.6；EE364a lecture 4；exercise 4.13/4.28/4.59。`
- 不合格：`更多内容可参阅凸分析相关教材。`

### 3. 锚定本页 —— 必须挂在**本页已经出现**的那一处，说明它「为什么在这里」
译注是解释原文某处的存在理由，不是补课。指向的公式 / 句子 / 脚注必须在同一页或同一节。
若确实需要引入超出本页的内容，必须显式降级为坐标标记：`此处只作坐标，第 N 章再回来读`。
**没有这层锚定的，不算译注，算夹带。**

### 4. 失败模式具体 —— 有「否则你会看到什么」，没有就只是名词搬运
给出可观测现象：报什么错、得出什么保守解、哪个算法不能用了、结果差在哪。
**黑名单句式**：`很重要` / `广泛用于` / `是基础` / `值得注意` / `非常关键`。

### 5. 量的方向感 —— 至少一个方向性判断，且必须是真的
`更保守 / 更松`、`大一个数量级`、`从 O(n!) 降到 O(n²)`、`差 14 页` 都算。
**禁止**空话量词：`显著提升` / `大幅改善` / `效果好很多`。给了就必须站得住，不确定就不给。

### 6. 不越级 —— 挂到读者已掌握的节点，挂不上就标 `[待建桥]`
可挂节点：6.042J 离散（partial order / 图论 / 计数）、CSAPP（存储层次 / 汇编）、
6.006 算法（复杂度 / 图算法）、Strang 线代（特征值 / 算子范数 / 投影）、Thomson 实分析（极限 / 连续）。
**禁止**直接甩群论 / 环论 / 拓扑 / 非标准分析。挂不上不是错，装懂才是错。

### 7. 篇幅 200–400 字，且至少含一个公式或一个数
一句话的「这只是 X」不合格（等于没写）；超过 500 字的是贴论文，压回去。
**至少要有一个 `$...$` 公式或一个具体数字**，否则容易写成散文感想。

### 8. 作者可分辨 —— 一律绿色 `[译注]`，禁用 `[remark]`
```html
<span style="color:#1e8449;">**[译注]** …</span>
```
理由：Boyd 原书自带 Remark，若自写内容用 `[remark]` 且撞同色，读者无法分辨哪句话是作者说的。
**这是交付级红线，不是风格偏好。**

## 二、反面清单（四种当场判不合格）

| 反面样例 | 违反了哪条 | 为什么不行 |
|---|---|---|
| 「这一节介绍了 LP 的各种形式，非常重要」 | 1、4 | 无失效对象、无观测现象，纯名词搬运 |
| 「关于鲁棒优化的更多内容可参考相关文献」 | 2 | 落点不可点开 |
| 「这里用到了对偶范数——顺便说一下，泛函分析里还有更一般的定义」 | 3、6 | 超出本页、越级到未学领域 |
| 「取对数之后效果好很多」 | 5 | 无方向、无机制，无法被反驳 |

## 三、范例（可直接抄结构）

下面这条是 Boyd 书页 p.149 处那条注，8 条判据全过，逐条对照见其后。

````html
<span style="color:#1e8449;">**[译注]** 这一步是全节的技术心脏。**sup 的含义是「对无限多个 $u$ 都成立」**，
直接写下来是无限多条约束，任何算法都吃不下。真正让它可算的是一个恒等式

```math
\sup\{a_i^T u \mid \|u\|_2 \le r\} = r \|a_i\|_2,
```

这个量在凸分析里叫 support function（支撑函数），它恰好等于对偶范数乘以半径，
于是无限约束坍缩成一条 linear inequality。

**消失测试**：没有这个恒等式，(4.30) 就转不成 (4.31)，后面的 robust LP 与 p.158 的 SOCP 表示全部失效，
只剩在 $u$ 上做网格搜索——维数一高就爆。

**落点**：Boyd §8.5.1（Chebyshev center 的正式处理）；支撑函数与对偶范数见 §A.1.6；
线代侧挂 Strang 的 operator norm 定义（同一件事的有限维版本）。</span>
````

**逐条对照**

| 判据 | 这条注怎么满足的 |
|---|---|
| 1 消失测试 | 「转不成 (4.31) → robust LP 与 SOCP 表示全部失效 → 只剩网格搜索，维数一高就爆」 |
| 2 落点 | §8.5.1 + §A.1.6 + Strang operator norm，三处可点开 |
| 3 锚定本页 | 直接锚在 (4.30) 推导这一步，解释「为什么要在这里引入 sup」 |
| 4 失败模式 | 给出可观测退路：网格搜索 + 维数灾难 |
| 5 方向感 | 「无限条约束 → 一条」（数量级从 ∞ 降到 1） |
| 6 不越级 | 只挂 Strang 的 operator norm，未引入泛函分析 |
| 7 篇幅 | 约 260 字，含一个 `$...$` 公式与一个 `$...$` 行内 |
| 8 作者可分辨 | 绿色 `[译注]`，未用 `[remark]` |

## 四、使用方式

派发 worker 时把本文件第一、二节塞进 prompt，末尾加一句硬要求：

> 每块（每份 PDF）至少 1 条译注，按 `译注判据.md` 的 8 条自检；正文里用
> `<span style="color:#1e8449;">**[译注]** …</span>`，禁用 `[remark]`。

交付后抽查方式：`grep -c '\[译注\]'` 数条数，`grep -c '\*\*\[remark\]\*\*'` 必须为 0，
再人工读一遍每条的「消失测试」那一句——**写不出「退化成什么」的一律返工**。
