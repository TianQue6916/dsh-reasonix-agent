## 三、⚠️ 事故：删 `HKCU\Software\Microsoft\Windows\Shell` 造成部分删除 + 不完整还原

这是本轮最重要的**操作教训**，务必记住：

```
删除 HKCU\Software\Microsoft\Windows\Shell
   → ERROR: Delete request is partially completed.     ← 部分删除
还原 shell-user.reg
   → ERROR: Not all data was successfully written to the registry.
最终状态 HKCU\Software\Microsoft\Windows\Shell 存在 = False

善后还原后复检：
  HKCU\Software\Microsoft\Windows\Shell                 exists=True  ✓
  HKCU\...\Local Settings\...\Windows\Shell             exists=True  ✓
  HKCU\...\Shell\Bags / BagMRU / Associations           exists=True  ✓
  与原始导出对比：464 行 → 456 行，差异 8 行
```

**根因**：`reg import` 报 "Some keys are open by the system or other processes" —— `Bags`/`BagMRU` 被 explorer 占用，无法回写。**影响面：某些文件夹的"记住视图设置"可能丢失**；不影响文件、不影响功能。退路是还原点 `before-temp-account-test-1006-0959`。

**教训**：
- 对**被使用中的 hive**（HKCU，且有 explorer 实时写入）做 rename/export-delete-restore **不是安全操作**：删除可能"部分完成"、还原可能部分失败，且失败是**静默降级**（键看起来还在，行数少 8）。
- 破坏性测试前必须记录**行数/子键数量基线**，事后按数量对比才能发现"少了几行"这种隐蔽损伤。
- 结论性教训：**"移除后无变化"的测试收益，必须与该键的损坏风险对价**。当前用户 hive 上的逐键删除应该停手，改为只读对比。

## 四、`RegOverridePredefKey` / 挂载新 hive 路线受挫（记录具体错误码，避免重走）

目标：在**单进程内**把 `HKEY_CURRENT_USER` 重定向到 `dsh_test_temp` 的干净 `NTUSER.DAT`，从而不动系统注册表就二分定位坏键。

1. **`RegLoadKeyW("[HKU]\DHSTEST", "C:\Users\dsh_test_temp\NTUSER.DAT")` → `rc=1314`（`ERROR_PRIVILEGE_NOT_HELD`）**：加载 hive 需要 `SeBackupPrivilege`/`SeRestorePrivilege`，**仅"有管理员身份"不够，必须显式启用特权**。
   该次测试实际未生效（重定向后读 `HKCU\Software\Classes` 子键数仍 = 1548，证明读的仍是原 HKCU），故测出的 WHITE 是基线噪声，**不是**新 hive 的结果 —— 典型的**假阴性/假阳性陷阱**，须用"重定向是否真的换了 hive"（子键数指纹）来自证。
2. **特权启用代码本身失败**：`SeBackupPrivilege / SeRestorePrivilege / SeDebugPrivilege / SeTakeOwnershipPrivilege` 启用全部返回 `False`。
3. **`reg load HKU\DHSTEST "…\dsh_test_temp\NTUSER.DAT"` → "The process cannot access the file because it is being used by another process"**：说明 `dsh_test_temp` 会话**仍挂载着**（用户是切换而非注销）。
4. 决策：**hive 重定向路线投入产出比不划算，放弃**。

## 五、下一步方案（已备退路，未执行）

清理 `HKCU\Software\Classes` 下**第三方写入的子键**，让 Windows 回落到 `HKLM` 默认关联（趋近新用户的"干净"状态）。

- **保留**：`Local Settings`（内含 MuiCache，新用户也有）、`CLSID`（4525 项 COM 注册，删了会影响 WPS 等右键菜单）。
- **顺序**：先删扩展名类键，**每步测一次图标，恢复即停手**。
- **退路**：`before-A\reg\03-HKCU-Classes.reg`（27.9 MB 完整导出）+ 还原点 `before-temp-account-test-1006-0959`。
- **代价**：第三方软件的用户级文件关联需重新运行那些软件重建；不影响文件、不影响系统默认关联。

## 八、写法教训（沿用）

- PowerShell 里 `-replace` 的**正则**（脚本内 `re`、`\`）易报 `InvalidRegularExpression`；`reg export` 的**参数语法**也曾连续出错 —— 先用 `reg query` 验证键存在再导出。
