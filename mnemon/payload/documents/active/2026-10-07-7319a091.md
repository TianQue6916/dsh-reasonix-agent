# 劳动争议病假回函起草：对撞式结构、策略取舍与法条核对

日期：2026-10-07。工作性质：为一起病假 / 医疗期劳动争议起草并定稿一份「回复函」（回公司的「友好协商函」）。

## 一、事由与争点

- 公司发来「友好协商函」，主张：员工「未按公司制度提交正式请假手续及完整医疗佐证材料」；提出「面谈协商、一次性整体了结本次全部劳动争议」；并称「逾期未回复将依法处理」（隐含解除威胁）。
- 我方立场：病假已按公司渠道告知（钉钉 / 短信向人事部门报备、住院后提交住院证），**钉钉提交病假申请时被系统拦截**，提示「非花名册中正式员工不能休病假」——公司后台设置问题，非员工拒绝走流程，已截图留证。
- 医院规定诊断证明与病假条**出院时才能开具**，属客观医疗程序限制，据此主张「先行告知 + 事后补交材料」已履行告知义务。
- 附带争点：8 月工资未发、公司曾要求把病假**按事假**处理、社保单位应缴部分不得转嫁。

## 二、回函结构（逐条对撞，而非逐条辩解）

| 公司函主张 | 回函对应节 |
|---|---|
| 「未按制度提交请假手续及完整医疗佐证」 | 第二节：举证责任推回——钉钉系统拦截导致无法提交（截图已存）；诊断证明出院才开；人事对接人自称「无审批权」却不向上转报 |
| 「愿意面谈协商，一次性整体了结」 | 第五节：不接受。金额、期间、依据均未明确时「一次性了结」= 预先放弃尚未发生的法定权利 |
| 「逾期未回复将依法处理」 | 第三节：医疗期内解除 = 违法解除 → 二倍赔偿金 |
| （工资与社保） | 第四节：拖欠工资 / 病假工资法定下限 / 社保单位应缴部分不得转嫁 |
| （诉求落地） | 第六节：六项书面诉求 + 5 个工作日期限；第七节：投诉举报 + 仲裁 + **时效中断声明**；第八节：明确拒绝当面协商（治疗期不宜）。 |

## 三、三条策略取舍（可复用判断，不是本案特例）

1. **年份错误不写「他们肯定是故意的」。** 当事人明确要求「必须严格指出他们的错误，他们肯定是故意的」，但正式法律文书里指控主观恶意无法举证（无法证明印章背后的心理状态），对方一句「模板笔误」即可化解，反而显得情绪化。替代做法：把**客观矛盾**摆到不可解释——来函把三个日期统一后置一年（2025-09-06、2025-09-25、落款 2025-10-07），而同期医疗文书全部记载为 2026 年；然后只要求「书面说明成因 + 更正后重新出具」。对方解释不了就是它的举证失败，解释得了我方无损失。该节的作用是**否认可信度**，为后续所有争议打底。
2. **未经一手核实的数字一律不写进正式文书。** 会话中出现的「1788 元/月」等来源不明，全部弃用；只写法定表述「不低于当地最低工资标准的 80%」。理由：一个错数会被用来质疑整份函。宁夏现行最低工资数额、贺兰县劳动监察与仲裁的准确联系方式多次检索均未取得可验证一手来源——这是**明知的缺口**，不是遗漏。
3. **「一次性了结」条款在要件未明前不接受**，理由是它会预先处分数额、期间均未确定的法定权利。
