# fluxscope v10–v11：WebGL2 环形拓扑的文件关联与选样（2026-11-01）

## 0. 关系与背景

fluxscope 是自建的 DSH 工具调用实时可视化，早期实现是 canvas 极坐标弧带舞台（命中反解、指针锚点缩放等见 doc `f651fb17-4464-4764-9a19-a38066b95e01`）。v10 起视觉主体换成 **WebGL2 圆环拓扑**：内环是 agent 环（`R3.NR` 个环，`PER` 个/环），外圈是文件环（top 72），中心是核心球，agent→文件的调用画成环间连线（蓝=读 `w=0`，橙=写 `w=1`）。

本文只记录**数据抽取与选样**层面已定位的两个根因：渲染管线本身没问题，环「不亮」是喂给它的数据不对。

## 1. 数据链

```
extract_agents.py  ──►  C:\Users\27063\fluxscope\agents.json  {agents, calls, files}
        │  (HTTP GET /topology，服务端 stat mtime，>180s 就重跑抽取器)
        ▼
loadTopology()  ──►  TP.agents / TP.calls / TP.files / TP.byId / TP.byIdNorm(+buildTopology)
        ▼
buildRing()  ──►  R3.rings / R3.pos(agentId→{ri,i,ang}) / R3.fpos(filePath→{k,ang}) / R3.links[{ri,ka,kf,t,w}]
```

- `R3.links` 按 `t` 升序，超过 2400 条就 `slice(-2400)` 保留最近的一段。
- agent 属性（`timing`/`token`/`group`）和文件格子的命中都要走 `onRing(aid)`：沿 `rec.parent` 向上最多 12 跳直到找到落在环上的祖先（subagent 现在混在 6 个环里，见 §4）。
- 参考规模（一次真实抽取）：`agents=1580 calls=22125 files=72 depth={0:993,1:574,2:13}`，耗时 ~16–19s。

## 2. 根因 A：文件环按「全历史次数」选样，和「最近在动什么」脱节

原排序：

```python
fl.sort(key=lambda x: (-x['n'], -x['t']))   # 全历史调用次数优先
```

后果（实测自检，不是推测）：

```
fluxscope in top72: []
calls with f in last 2h: 124
  ... of which target a top-72 file: 0
```

最近两小时 124 条文件调用，**命中 top-72 的是 0 条**——因为当时真正在动的是 `C:\Temp\100b\**` 那批 MacKay 翻译文件，历史次数只有个位数，全被老的高频文件（`.dsh/PLAN.md` 95 次等）挤掉。

修法：改成**时间优先**（近期活跃 > 历史累计）。修后同一自检变为：

```
 9x  .../MacKay信息论_p221-240.bilingual.md   0.4h ago
 9x  .../MacKay信息论_p201-220.bilingual.md   0.4h ago
 7x  .../MacKay信息论_p161-180.bilingual.md   0.2h ago
```

`links` 活跃连线 **24 → 70**。

**可复用的判据**：任何「取 top-N 元素」的视图都是选样策略的一部分。选样的排序键必须和视图想表达的语义一致；「实时看现在在动什么」的视图若按累计计数排序，会在数据量放大后系统性失明——而且失明时画面只是「安静」，不会报错。用「近期调用中有多少条命中 top-N」这个比值当自检指标，比看画面靠谱。

## 3. 根因 B：bash 命令里的相对路径被丢弃

抽取器从 bash 命令里取文件路径的归一化函数（`_norm_path(t, cwd)`）原先只认绝对路径，而大量命令形如：

```
cd /c/Users/27063/fluxscope && python x.py index.html
```

`index.html` 是相对路径，被直接丢掉 → 文件关联大面积缺失。

修法（思路同 [sp4rk `tools/shellpaths.go` 的 `resolveRelativeToken(token, workDir)`](https://github.com/v0lka/sp4rk/blob/513e4442a49b054deef0459602884651f8ef2b89/tools/shellpaths.go)）：

1. 解析 token 流时维护 `cwd`：遇到 `cd <path>` 就更新（`cwd = _norm_abs(ws[i+1])`，同时 `_norm_abs` 负责 MSYS 风格 `/c/Users/...` → `C:/Users/...`）。
2. 绝对路径解析失败且不以 `-` 开头时，按 `cwd + '/' + raw.lstrip('./')` 解析相对路径。
3. 过滤噪声：glob 通配（`*`/`?`）、含空格或分号的串（会把 `python -c` 的代码块当成路径）、`.min.js`、隐藏文件、`.`/`..` 目录、basename 无扩展名或超长。

抽出的带文件调用 **3654 → 6586**，`links` 进一步到 668–711。

## 4. 自检口径（可闭式核对）

页面暴露 `window.__gldbg`，一行 JSON 就能判断画面是否真的在动：

```js
{ total, events, sess, conn, links, files, agents,
  gldbg: { drawn, recent, linksTot, quads, nanN, maxAbs, o, bufLen, glW, glH, rot } }
```

判读要点：
- `linksTot` 有值但 `drawn/recent` 为 0 → 是**选样/时间窗**问题，不是渲染问题；这一条判据是本轮两次排查的共同入口。
- `nanN` 应为 0；`maxAbs` 出现非有限值说明有除法/归一化被零除（曾用来抓两个跨时钟 bug）。
- `tSample` 是抽样的调用时间戳，可用来交叉验证「近期」窗口是否与 `nowMs` 对齐。

## 5. 踩过的坑

- **用字符串拼接改 Python 源码极易静默损坏**：raw string / 三引号转义会把 `if ...:` 后面的块吞掉，报出来是 `IndentationError: expected an indented block`，而同一行在编辑器里看着正常。改完立刻 `ast.parse` 校验，不要直接跑。本轮出现过 `if not raw ...:` 后缩进块被删、随后修复又留下重复 `return None` 的情况。
- 服务端 `/topology` 用 mtime > 180s 触发重抽：改了抽取器但**没等缓存过期**就看页面，会看到旧数据，容易误判修复无效。
- 文件环与 agent 环用的是两套坐标（`R3.fpos` vs `R3.pos`），连线两端的角度必须分别取，混用会画到错误的格子。
