# fluxscope v12：FOLLOW 运镜与实时管线（2026-11-01）

承接 doc `9996766a`（v10–v11：canvas 弧带 → WebGL2 环形拓扑、文件选样按近期活动优先）。
本文只记 v11 之后的增量：FOLLOW 的相机运镜，以及数据管线节奏的真实上限。

## 0. 触发（用户原话，历史记录，非当前指令）

1. 「视角切换频率太低了，动感不够」
2. 「频率还是太低，两秒一次，注意要是真实数据，我就不信电脑没有两秒读取一次文件，聚焦也没有打开详情，修一下」

第 2 条里三个要求可分别判定：dwell=2s / 数据端到端延迟接近实时 / FOLLOW 时详情面板随之切换。

## 1. 根因 A：镜头「锁死一格」

`pickLiveSession` 选的是 **`t1` 最大的会话**。而 `t1` 最大的那个恰恰是**正在干活的那个** —— 只要它不停止输出，就永远是它。
于是跟随全程对着同一格，视觉上与关闭跟随只差一个角度。

判据提炼：**「最新」不等于「有变化」。选样函数用「最新」当「活跃」，在有长驻会话时退化为常量。**

修复：改为巡检（PATROL）—— 取最近 **15 分钟**活跃会话中前 10 个且**必须有环上座位**的，按 `dwell` 轮换。
列表每 **1.5 s** 重建，但**只要当前目标仍在列表里就不换人**；否则每次重建都会把镜头从正在看的东西上拽走。

## 2. FOLLOW 的三层叠加

「聚焦的本质不是把目标放大，是让别的后退。」

| 层 | 参数 |
|---|---|
| 推轨 dolly | `CAM3.dist` 1820 → 1180（1.54×），0.035/帧缓动，约 1.3 s 落位 |
| 径向压暗 | 以目标为心的渐变，0% / 55% / 100% → alpha 0 / 0.22 / 0.62 |
| 目标柔光晕 + 四角准星 | 上一版已有 |

速度是刻意的：比切换慢、比漂移快 → 读起来像一次有意的运镜。

## 3. 两个屏幕方位踩坑（可复用的坐标系判据）

1. **目标是转到屏幕下方，不是上方**：`angDiff(-Math.PI/2, ...)` 因**世界坐标 Y 向上、画布 Y 向下**，环上 `-PI/2` 落在屏幕**底部**，正好被 252 px 的面板条压住。改 `+Math.PI/2`。
2. **拉近后目标滑出画面顶部**：环放大 1.54× 而目标在上缘必然出界。按推轨比例整体下移场：
   `R3.cy = Hgt * (0.545 + 0.20 * (1 - dist/base))`

滚轮语义：跟随中滚轮调的是 **follow 距离**而不是退出跟随（「你在调镜头，不是要离开」）。
`ZOOM` 标签同时显示 `CAM 1.54× · FOLLOW`。

## 4. 巡检节奏与「切换要看得出来」

- `PATROL.dwell = 2000`
- 甩镜窗口 **520 ms**（原 700 ms）：否则每 2 s 里有 0.7 s 在赶路，只剩 1.3 s 停稳，画面像一直在逃命。
  切换后窗口内缓动系数 `0.085 → 0.155`：
  ```js
  if (LIVE.id !== ROT._lastLive){ ROT._whip = now + 700; }
  const ease = (now < ROT._whip) ? 0.155 : 0.085;
  ```
  不做则**「切了」与「没切」画面完全一样**（同一条缓动曲线）。
- 停留呼吸：`CAMZ.follow * (1 + 0.022 * sin(t / 1.7s))` —— 完全固定的镜头看起来像卡住了。
- 空闲漂移 `DRIFT` 0.036 → **0.075 rad/s**（3 分钟一圈 → 84 秒一圈）。

## 5. 根因 B：数据一直在磁盘上，是服务端捂着不给

`server.mjs` 两处累积延迟：

```js
setInterval(runExtractor, 8000)              // 8 秒才重建一次 agents.json
Date.now() - lastTopo.at > 20000             // 再等 20 秒才 broadcast 给前端
```

**agents 数量不变时前端最多等 28 s 才看到新数据。** 改成 `2500 / 2500`。
稳态：`/health` 的 `lastExtract` 稳定在 **0.5 s 前**；extract 0.5 s / 2.5 s ≈ 单核 20%，`extracting` 标志已防重入。
⚠️ **改这两处必须重启服务端**（`node server.mjs`）才生效，前端刷新不够。

## 6. 实测口径（8 秒采样，可复现的判据）

```
seq     d05928da → baaf1fd1 → 6fa844e0 → 09107359      distinct 4
detail  "Mnemon idle check…" → "你是否能建模出来一个故宫…"   跟着变
calls   27150    within2min 4
```

- `distinct` 小于候选数 = 数据决定的，不是限制（当时只有 3–4 个带座位的活跃会话）。
- 2 s 若仍嫌慢，下一档 1 s 会让甩镜占比 >50%，画面持续赶路 —— 建议先验证当前档。

## 7. 硬约束（别退回）

- **任何读数必须等于底层计数**，不能等于「我画得出来的数量」。
- **容量不够就降显著度，不要删事实**。
- **三个 drawn 同时为 0 ⇒ 帧循环抛异常**，不是「没数据」。
- **角度只有一个入口**：`ringAng(ri)` / `fileAng()`。两套公式 = 点击错位。
