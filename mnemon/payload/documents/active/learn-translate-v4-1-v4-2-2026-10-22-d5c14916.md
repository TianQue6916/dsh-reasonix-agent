## 一、改名：`bilingual-ocw-translator` → `learn-translate`（v4.1）

- 目录、frontmatter `name`、入口命令 `/learn-translate` 全部对齐；**旧名退役、不保留别名**。
- **为什么不留别名**：`skill_search` 按 description 模糊匹配，双入口会重复命中、噪声变大。
- **provider 是实时扫目录的**：`skill_search("learn-translate")` 改名当场命中 ⇒ **不需要重启 dsh**（这是对「改技能要重启」直觉的反证）。
- 验收口径：三端 `sha256` 一致 + `skill_search` 命中 + frontmatter YAML 可解析。

## 二、顺手修的 5 处（按严重度，均为「审的过程中发现」）

1. **铁律 21 是 Reasonix 时代措辞**（「Reasonix 不派任何子代理」）：宿主换成 dsh 后字面照读会**反向执行意图**（在 dsh 里误派内建 subagent）。改为「宿主内建子代理一律不用（Reasonix / dsh 同规），全转主力机 `dsh-remote`」。
   **教训**：铁律里写死的宿主人格名，换宿主后会从「约束」变成「误导」——规则主题应写成宿主无关。
2. **输出路径只有小电脑 Linux 桌面**（`/home/tianque/桌面/...`），主力机实际在用却没写。`§A2` 补主力机五类落盘：翻译产物 / 锚点卡 / Anki tsv / 讨论回复 / 课程 repo。
3. **锚点卡没有落盘路径**（说了「落盘」却不给落哪 = 没有纪律）。我上一轮写的 `Desktop/课程笔记/` **在用户机器上并不存在**——实测 Desktop 只有 `工具箱 / 程序 / 课程文件`。改为 `C:/Users/27063/Desktop/课程文件/锚点卡/<课程>/<概念>.md`，Anki 放同目录 `_anki/`，好处是随课程文件树一起备份同步。
   **教训**：单次 `ls` 就能否证的假设，不要写进技能。
4. **`description` 468 → 342 字符**：它**每轮注入**，原来把「PDF/DOCX/TXT/HTML、教材章节、习题集、字幕」这类细节塞在里面；细节移进正文，触发词一个不丢。
5. **缺「与相邻技能的边界」**：用户有 4 个相邻技能，不写清就抢路由。加边界表——`course-summarizer` 管整本书的全局结构（先有生态位再谈锚点卡）、`learning-method` 只给方法论名词（本技能给可执行判据：消失测试、`[未定位]` 纪律、D+1/3/7/21）、`tool-offline-wiki` 是工具本身、`thinking-modes` 管输出风格（本技能管内容结构）。

另修两处别处的旧名引用：`tool-offline-wiki/SKILL.md`、`dsh-mode/references/plugins-and-models.md`。

## 三、v4.2：`references/learning-science.md`（第 19 个 reference，57 行）

v4.0/v4.1 只融了**检索手法**（issues/errata/CHANGELOG 优先、awesome-list 只当地图、论文三段扫描、`filename:`/`path:` 检索式、「看不懂就找实现——跑一遍 > 读十遍」），**没标学习法本身的证据强弱**——等于把社区口传当理由，正是铁律 29（来源分级）要防的事。

### 证据分级记号

`[MA]` meta-analysis > `[RCT]` > `[EXP]` 受控认知实验 > `[CS]` 经典奠基 > `[OBS]` > **`[D]` 社区口传（不得作为理由）**。
字段设计借自社区：`education-agent-skills` 的 `spaced-practice-scheduler` 把 `evidence_strength` 做成 skill 的一等字段（"strong" + evidence_sources）。

### 九条学习法的判级与反直觉结论

| 学习法 | 判定 | 依据 | 对技能的实际改动 |
|---|---|---|---|
| 自测 retrieval practice | [MA] | Roediger & Karpicke 2006；Rowland 2014 meta：带反馈 g≈0.73 vs 不带 g≈0.39 | 复习**必须给反馈**（原来只说「测本质 + 消失测试」，没说要对答案、说错在哪） |
| 间隔重复 | [MA] | Cepeda et al. 2006，254 项研究：**最优间隔随保持期增长** | D+1/3/7/21 从「定律」降级为「**默认启发式**」，目标越远间隔拉长 |
| 合意困难 | [EXP] | Bjork 1994 | 允许闭卷自推时的卡顿；当场顺畅 ≠ 学会 |
| 交错练习 | [EXP] **有争议** | Rohrer 系列，效果与迁移距离相关 | 默认交错，但**不许声称「交错一定更好」** |
| 费曼技巧 | **[D]** | **无一手学术文献**，常被误挂到费曼本人 | 外壳留着（讲给外行听），理由重挂到 retrieval practice + self-explanation |
| 卡片盒 Zettelkasten | [D]→[OBS] | Luhmann 卡片盒 + Ahrens 书，**无对照实验** | 双链是检索辅助，**不是记忆法** |
| 艾宾浩斯曲线 | [CS] **有硬伤** | n=1（他自己）+ 无意义音节 | 不把指数衰减套到概念学习，只借「间隔优于集中」（已被 [MA] 独立验证） |
| 学习风格（视觉/听觉型） | **[MA] 无证据** | Pashler et al. 2008（89.1% 教师仍相信） | 列为**禁用句式**：不许用「你是视觉型学习者」解释困难 |
| Anki SM-2 | **[D] 工程实践** | Wozniak 1987 实现 / 1990 硕士论文 | 当**调度工具**用，不当**学习理论**；不宣称「Anki 排的表就是科学最优顺序」 |

## 五、可复用的元教训

1. **「融入社区经验」要分两层验**：手法层（怎么写）与证据层（凭什么这么写）。只做手法层 = 把 C 级当 A 级用。
2. **skill 的 `description` 是常驻成本**，细节应进正文与 references；但触发词不能丢。
3. **改名前先查别名代价**：不保留别名、不留重定向描述，靠 `skill_search` 实时扫描即可平滑切换。
4. **同一份目录在多个路径下出现时，先比 inode 再谈「几端」**。
