## 三、自我纠错：一个被二手材料混用的效应量

原写法：「带反馈 g≈0.73 vs 不带 g≈0.39」，见 `references/changelog.md:29` 与 `references/learning-engine.md:120`。

核查后判定**来源存疑**：0.73 同时是 Hattie 2009 的 feedback 综合效应量，量纲与定义同 Rowland 2014 的分组亚组不同，网络二手材料把两者混用。已统一改为「方向已核（带反馈更好），具体值须读原文」。

**教训（可复用的判据）**：数字若在二手材料中出现而原文亚组未核，宁可写方向不写数值——这正是技能里给 `[D]` 级定的规矩，规则先约束自己。仍待原文核的两项：① Rowland 2014 feedback 亚组的精确 g 与 CI；② Cepeda 2006 的「10–20%」在不同材料/保持期下的边界；③ Rohrer 交错的 2022+ 独立复现。

## 四、交错练习：结论被约束改写

原「默认交错」→ 现「**晚交错、按需交错**」。两条硬约束（learning-wiki 的 interleaved-practice / interleaving 条目）：

- 题型高度可区分、永远不会混淆时，blocked practice 反而优于交错——没有可判别的东西；
- 绝对新手在获得任何策略之前交错会**超载工作记忆**。

适用边界：已能执行程序但会混淆「何时用哪个」的学习者；数学选公式、科学分类、临床诊断、语法。

## 五、查不到的，不许包装成科学结论

「四问 / 推导优先教学法」本身**无直接实证**。检索式 `first principles learning method empirical study`、`derivation-first instruction physics` 均空。标 `[D]/[待证]`，其合理性挂在「先证后信」协议上，而非文献。

## 六、针对当前学业阶段的学习模式建议（七条，带依据强度）

背景：6.431 概率论 + CS144 双 P0；Boyd 凸优化前 5 章 / Cover 信息论前 6 章周末；实分析压底。诊断结论：**不缺输入质量，缺「输出的硬配额」**。

1. **把一半输入预算换成可验收产出块**（每周两门 P0 各一次）。6.431：闭卷 90 分钟一道完整 PSet 题 + 一道改假设的变式（迁移判据）；CS144：一个 checkpoint 的 acceptance test 全绿 + 一篇 lab log，log 每行严格写「症状 → 假设 → 实验 → 结论」。lab log 比 lab 本身更可复用，是判断卡点的唯一证据。
2. **复习间隔按「距目标天数」反推**，不用固定的 D+1/3/7/21：quiz（≈4 周）首复 3–6 天、期末（≈9–10 周）首复 7–13 天，之后 ×2 递增、上限 30 天；已学完课程 20–30 天只测「本质一句 + 承重」。
3. **数学不做 Anki 抽卡**，做白纸复现 + 变式库：每周 3 个定理，四件套 = 陈述（含全部前提）/ 主证明骨架 3–5 步 / 一个去掉前提就崩的反例 / 它否掉了哪个原本直觉。Anki 只放「术语→一句本质」「反例↔失效前提」两类卡；白纸复现后必须对原书（反馈增强自测效应）。
4. **6.431 与实分析物理隔离**（`[判断]`，非实证）：Bertsekas 是工程概率，不需要测度论；实分析只占每周 1 个块、只走 TBB 证明骨架、不追 Rudin 习题——它是 AGI 逻辑线的底料，不是本学期分数来源。
5. **CS144 提前给 checkpoint 4（TCP）留缓冲**：先读 RFC 9293 相关段再写代码；每周固定 2 × 90 分钟，不许挤占数学日；卡住超 40 分钟先写 lab log 再决定是否重攻。
6. **卡点每周只重攻 3 个**，其余降级归档为「已知缺口 + 触发条件」——缺口有触发条件就不是负债，是待兑现支票。
7. **笔记标题写成完整断言句**（Matuschak：标题像 API，declarative titles）：写 `cache line 承重于突发传输效率`，不写 `cache line`。
