# Minecraft 故宫蓝图：模型源调查与体素化可行性（2026-10-31）

承接 [dc5438d0](documents/active/minecraft-nbt-dc5438d0.md) 的「3D 模型 → 体素 → .nbt」链路，这次处理的是**故宫整体**这一具体标的：先找现成建模，再评估做成蓝图/存档的规模。

## 1. 现成建模的取源结果

### Sketchfab（唯一确认存在可下载 mesh 的源）

公开搜索 API 无需 auth，命中三个相关作品，全部 `isDownloadable: True`、**CC Attribution**（可改可商用，署名即可）：

| 名称 | 面数 | 顶点 | uid |
|---|---|---|---|
| Forbidden city model - 故宫模型 | 167,309 | 86,360 | `5d300689fcae47ed980b38f680f59e02` |
| Hall of Supreme Harmony, Forbidden City（太和殿） | 699,256 | 349,096 | `a950d33d13cc48b6b1d35af3bd6d5451` |
| The Forbidden City In Beijing（整体低模） | 10,388 | 5,811 | `9822899391ae4bb2b50f150abfc68c78` |

**自动下载失败，且不是网络问题，是两重墙：**

- `GET /v3/models/{uid}/download` → **401**，下载需登录态 token；
- 从 embed 页可抓到 `media.sketchfab.com/models/{uid}/.../file.binz`（元数据仅 1,469 B，真正几何在 `modelSize` 指向的另一个文件里），但 **`.binz` 是 Sketchfab 私有 osgjs 二进制**，依次试过 zlib、raw-deflate、gzip、bz2、lzma、xz、brotli、zstd 全部失败，文件头 `160a5b74...` 不属任何标准压缩魔数；`file.osgjs` 返回 `AccessDenied`。

结论：**必须由用户浏览器登录后点 Download（Original 或 glTF）**，再将 zip 放到 `C:\Users\27063\mcopt\`，走已有 `mesh2nbt.py`（自测：立方体+球 332 面 → 977 体素）转 `.nbt`。

### 社区 / 搜索源可达性（本机实测）

- `planetminecraft.com`、`minecraft-schematics.com` → **403**（Cloudflare 拦命令行）；
- `mcmod.cn` → 000 连不上；`minecraftxz.com` → 200 但页面 JS 渲染，搜「故宫」命中 0；
- Bing 中文分词被吃（`我的世界+故宫+存档` 只匹配「我」）；DuckDuckGo 连接失败；B 站搜索 API 返回 HTML（需 wbi 签名）。
- 社区确实有紫禁城项目（B 站实况、PMC 作品），但多为**服务器存档而非可下载 `.schem`**，版本与体积不明。

### 中国官方渠道：没有可下载的 3D 模型

| 站点 | 状态 | 内容 |
|---|---|---|
| `www.dpm.org.cn` | 200 | 官网；全景故宫是 720° 图片 |
| `digicol.dpm.org.cn` | 200 | 数字文物库，10 万+ 文物**照片**，无 3D 下载 |
| `www.vr.dpm.org.cn` | 000 | V故宫，VR 实时渲染 |

即故宫博物院公开的是**全景拍摄 + WebGL 漫游**，不发 mesh 文件。此前的「官方可能有建模」假设不成立。

## 3. 故宫适合参数化生成的结构论据

与「空间站丑」的教训相反，故宫几乎是可编码的：

```
中轴对称    主体沿南北中轴排列 → 生一半镜像另一半
台基       三层汉白玉须弥座，工字形 = 纯矩形堆叠
屋顶       庑殿顶(四坡) / 歇山顶(九脊) → 参数化斜面，无自由曲面
院落       前殿后寝四合院，重复模式强
城墙       961×753 矩形，高 10 m，厚 8 m，四角楼
护城河     宽 52 m 环绕一周
```

可选路线：A 用户浏览器下载 Sketchfab 模型（真实扫描细节，质量高一个量级，代价是登录）／B 按公开尺寸程序生成（全自动、可分级，但细部是近似）／C MagicaVoxel 手搭（8704 间房人力不现实）。当时建议 **B 从太和殿单体做起**（1.2 万方块，0.2 s 粘贴），确认再接中轴主段。
