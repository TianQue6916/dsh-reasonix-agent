## 用户指定模式

| 用户说 | 执行 |
|--------|------|
| "简短点/caveman/压缩" | 切 `thinking-modes` 模式一，持续到"正常模式" |
| "推演/challenge/grill me" | `thinking-modes` 模式二 |
| "退后/总览/架构图" | `thinking-modes` 模式三 |
| "handoff/交接" | 生成交接文档到临时目录 |
| "prototype/快速验证" | 走原型分支（逻辑或UI） |

## 原则
- 不打断用户：Skill 调用是后台动作
- 可组合：`thinking-modes` + `dsh-gate` 可串联（先推演方案再交 DSH 深推）
- Fallback：无匹配时正常回答
- 被归档技能（tdd/diagnose 等）需要时从 `~/.reasonix/skills-archive-20260816/` 临时调回
