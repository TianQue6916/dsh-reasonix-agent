D:\Toolbox\ 内新增了"工具箱.lnk"快捷方式，双击打开 D:\Toolbox\ 文件夹本身。

快捷方式列表：
- `D:\Toolbox\工具箱.lnk` → D:\Toolbox\（文件夹自身快捷方式）
- `D:\Toolbox\Codex.lnk` → OpenAI Codex Desktop App
- `D:\Toolbox\PDFMathTranslate\` → PDFMathTranslate 便携版
