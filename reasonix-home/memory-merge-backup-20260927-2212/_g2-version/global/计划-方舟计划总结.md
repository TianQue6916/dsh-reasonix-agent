### 三、学习方式诊断与校准

#### 1. 核心问题

- 不是“不擅长做题”，是大脑拒绝运行未经审查的代码。
- 数学（6.042）需要“从公理出发走一遍推导”，计算机（CSAPP）需要“用gdb看、用Lab拆”。
- “三到五成掌握度”是构建主义协议的正常输出：只保留骨架，丢弃孤立事实。解决方案：用实体教材+打印作为“外挂血肉”，大脑只存指针。

#### 2. 环境匹配

- 上课时间（强制在场）：做低认知负荷的笔头工作（抄定义、画概念图）。
- 安静环境（图书馆/深夜）：听视频课、推证明题、做Lab。
- 嘈杂环境：推进概念学习，不做深度构建。

#### 3. “应用”滞后感

- 用Bomb Lab、LeetCode位运算、打印植入的Trick作为低成本外部裁判。

### 五、AI工具矩阵（方舟外部接口层）

#### 1. 最终AI需求规格（P0优先级）

- **防降智**：API必须显式锁定 `deepseek-v4-pro` + `reasoning_effort: max`，拒绝动态路由。
- **多模态文件处理**：支持PDF、Word、TXT、图片OCR，可建知识库。
- **跨终端统一**：电脑（Win/Mac）、手机（iOS/Android）、平板（iPadOS）三端使用。
- **联网搜索**（P1）：可通过SerpApi/Bing插件扩展。
- **成本控制**：月成本≤15元，按量计费。

#### 2. 最终技术方案

- **后端**：DeepSeek API ( `deepseek-v4-pro`)，月成本5-15元（缓存命中率高）。
- **电脑端知识库中枢**：AnythingLLM（免费，本地RAG，支持文件解析+向量库+联网搜索可选）。
- **移动端轻量前端**：Chatbox AI（全平台，配置同一API Key）。
- **架构**：电脑端处理文件→提取文本→组装Prompt→调API；手机/平板直接对话或单次上传。

#### 3. 缓存命中率优势

- 你的使用模式（固定System Prompt + 长对话历史 + 不重置会话）是DeepSeek硬盘缓存的“黄金用例”。缓存命中率可达85%-95%，成本降低90%，首token延迟降至500ms。

#### 4. 其他AI工具决策

- 不订阅任何“合成迷你”（GPT-4o Mini缩水版）。
- GPT-5.5/Gemini 3.1 Pro：数学能力更强，但当前阶段DeepSeek V4足够，无需付费。
- 小米MiMo-V2.5-Pro：长程Agent能力优秀，但非当前必需。
- 网页版DeepSeek存在高峰期“降智”风险，已决定迁移至API。
