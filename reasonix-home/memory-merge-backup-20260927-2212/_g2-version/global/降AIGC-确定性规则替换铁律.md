# AIGC降率核心发现（2026.06 实测闭环）

## 六次检测迭代数据
| 版本 | 操作 | 检测率 |
|:----:|------|:-----:|
| v1 | ALH技能（短句独立成段） | 57.6% |
| v2 | 合并段落、消除模式 | 80%+ |
| v3 | 段落重构+打断句+连接词清零+CoV>60% | 92% |
| **v4-1** | **humanize-chinese硬编码120+200条规则替换（非LLM）** | **22%** |
| v4-2 | 同上，追加处理剩余段落 | 16% |
| v4-3 | 我自己现写替换文本（重新落入LLM生成） | 99% |

## 铁律
1. **禁止AI改写AI文本** = 叠加AI指纹，越改越差
2. **唯一有效的是非LLM的确定性子替换** — hard-coded 1对1替换，不经过LLM采样
3. **纯AI生成的文本无法通过反检测蒙混过关** — 反检测技术有效上限约15-25%
4. 确定性子替换的替换空间有限（约10-15%字数），不可能把纯AI文本降到0%
5. 不同检测器结果差异极大，以学校指定平台为准

- aigc-reduce (ysm827) — 核心规则：禁止AI全量重写
