# 微信 bot 发送文件给用户（bot.control API）— 2026-09-20 实测打通

## 现象
用户微信里让 bot 把生成的 PDF 发过去，bot 回复“无法发送文件”。

## 真相：bot 有能力，只是通道被关着
reasonix bot 二进制内嵌文档（挖自 `reasonix-bot.exe` 字符串）：
> The optional `[bot.control]` section exposes a local loopback HTTP API and is disabled by default…
> endpoints are `GET /status`、`GET /metrics`、**`POST /send` for sending text or media through a configured connection**

相关字符串：`connection_id and chat_id are required`、`media must be between 1 byte and 25 MB`、
`/ilink/bot/sendmessage`（微信适配器发送接口）、`bot media attachment failed`。

## 打通步骤（已落地）
1. `%APPDATA%\reasonix-bot\config.toml` 的 `[bot.control] enabled = false → true`（备份 `.bak-20260920-botcontrol`）
2. 生成 token 写入 `%APPDATA%\reasonix-bot\.env` 的 `REASONIX_BOT_CONTROL_TOKEN`
3. 提权重启 `reasonix-bot.exe`；启动日得 `bot control server started addr=127.0.0.1:37913`
4. 调用验证：`GET /status` 返回 adapter `id=weixin`（domain/platform 均为 weixin）
5. 发送成功：**`200 {"message_id":"7507336027534169480"}`**（12.4MB PDF，media 传本地绝对路径）

## 正确契约（关键在 chat_id）
```json
POST http://127.0.0.1:37913/send
Authorization: Bearer $REASONIX_BOT_CONTROL_TOKEN

{
  "connection_id": "weixin",
  "domain": "weixin",
  "chat_id": "o9cq802gbUa4ccZXIxmu2hVNkvYc@im.wechat",
  "chat_type": "dm",
  "media": "C:\\完整\\路径\\file.pdf",
  "text": "附带说明"
}
```

## 四个坑（踩了 4 次才通）
1. **`chat_id` 必须是平台原始 ID**（`o9cq...@im.wechat`，即 `[bot.allowlist] weixin_users` 那串）。
   日志里的 `chat=fee92717dad2` 是**内部会话 id**，用了会返回
   `502 sendmessage error ret=-3 errcode=0: invalid arguments`——**连纯文本也报同一个错**，很容易误判成 media 格式问题（我当时先后试了 path / file:// URL / data URL 全部同一错误）。
2. `connection_id` 必须是 `weixin`；`weixin-weixin` 会报 `SendToAdapter: no adapter found for connection`。
3. `media` 直接传本地绝对路径，无需 `file://`/base64。
4. 前提：`tool_approval_mode = danger-full-access`，否则 Windows 沙箱把 PowerShell 锁成 ConstrainedLanguage，curl 都跑不起来。

## 已做的知识固化
写入 bot 自己的 memory：
`%APPDATA%\reasonix-bot\memory\global\weixin-bot-send-file-via-control-api.md`
（含 curl 示例 + 四个坑），使 bot 后续能自主发文件。

## 另一个真问题：max_steps
`bot-win-err.log` 有：`turn error err="paused after 25 tool-call rounds (bot.max_steps) — the work so far is saved; send another message to continue, or set bot.max_steps higher or to 0 for no limit"`。
即 `[bot] max_steps = 25` 对“写 HTML→转 PDF→发送”这类多步任务是瓶颈，turn 会在中途暂停（表现得很像“没做完/不回复”）。建议调到 60 或 0。

## 环境变量泄露提示
token、`weixin/accounts/*.json` 里的 bot token、以及 allowlist 里的用户 ID 都属敏感信息；
本次写入 bot memory 的文档只含 `chat_id`（已在 config allowlist 中，非新增泄露）。
