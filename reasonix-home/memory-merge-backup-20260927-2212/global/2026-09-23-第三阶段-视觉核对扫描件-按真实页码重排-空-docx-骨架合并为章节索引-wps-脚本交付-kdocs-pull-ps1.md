# 2026-09-23 第三阶段：视觉核对 + 碎片合并 + WPS 脚本交付

## 视觉核对方法（已跑通）
`header_sheet.py`：用 `page.get_pixmap(clip=顶部 46%)` 截每页上半部 → PIL 拼图（4 列×N 行，宽 640px）→ 存 **JPEG quality=72**（PNG 会超 view_image 的 3MiB 上限！）→ `view_image` 一次看 8 页的真实页眉/节号。
实测效果：一次看清 8 页的页码（502/503/505/507/506/509…）与节号（8.1.1/8.1.2/8.1.3/8.2/8.2.2…），**当场确认了两件事**：
- OCR 提取的页眉页码是**可靠的**（视觉与 OCR 一致）；
- 扫描页顺序确实乱（p6=507 排在 p7=506 前）。

## 按真实页码重排（sort_by_pagenum.py）
关键改进：**限定合理页码区间**再取值，否则中文正文里的数字会被 OCR 当成页码（ch2 曾被误读为 0/100/111/123/345）。
- ch8 → 限 (500,545)、第2章 → 限 (20,60)、mcs ch18 → 限 (730,775)
- 有页者按页码排，无页者继承前一页码（相对顺序保留）；可信率 <50% 则不排序
- 实测：第2章 23→48 单调递增、第8章 502→537、第18章 740→765，均明显改善（个别 None 页位仍由 OCR 误读导致）
