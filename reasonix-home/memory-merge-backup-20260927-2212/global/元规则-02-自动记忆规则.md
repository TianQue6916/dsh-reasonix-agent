# 规则：完成重要操作后自动 remember

**规则**：每次完成以下类型的操作后，必须自动调用 `remember` 保存结果，不等用户提醒。

**触发场景**：
- 安装/卸载软件 → 存版本、路径、配置方式
- 配置 API Key / 环境变量 → 存配置内容（不含 key 明文，存位置和方式）
- 批量文件操作（>5个文件）→ 存操作摘要
- 项目结构变更 → 存变更摘要
- 任何需要"下次还记得"的信息

**格式**：
- type: reference（工具类）或 project（项目类）
- description: 一句话说清存了什么
- content: 关键事实，让未来的我能直接引用，不用重新推导

**Why**：用户指出我经常丢失对话历史、不保存关键信息。这个规则解决"做完不存档"的问题。
