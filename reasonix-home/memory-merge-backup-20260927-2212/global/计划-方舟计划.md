# 计划-方舟计划（2026-08-16 蒸馏，原文在 memory-archive-20260816/计划-方舟计划总结.md）

## 总体纲领
- 命名：「大一统理论与第一性原理——方舟计划」
- 总目标：先实现强人工智能（AGI），再用其控制弱 AI 与量子计算，最终驾驭核聚变
- 最低完整配置：数学 9 门 + 计算机 11 门（后为 AGI 增补因果、认知、对齐等模块）

## 大一下学期执行清单
- 数学主线：离散数学（MIT 6.042J）第 4-9 周，听课为主，Course Notes 批注；卡在第 9 章证明题（归纳/不变量）
- 计算机主线：CSAPP（课本+Lab）全程并行，1-6 章完成，第 8 章异常控制流进行中，Bomb Lab 收尾
- 数学支线：矩阵论（Horn）第 10 周后压缩 2 周（SVD/广义逆/矩阵微积分）
- 数学辅线：线性代数收尾（Strang）周末，为 Horn 预热
- 算法辅线：CLRS 第 10 周后，MIT 6.006 听课为主，CLRS 批注区
- 前瞻：凸优化（Boyd 前 4 讲）第 14-16 周只看概念
- 英语支线：四级真题+单词"慢速可理解输入"，放弃万词班

## 周循环
- 周一三五数学日（6.042）｜周二四计算机日（CSAPP）｜周末线性代数日（Strang/18.065 预热）
- 每天每 45 分钟起身活动 + 提肛运动（防痔疮）

## 书目（40+ 本）
- **数学库**：6.042J Course Notes（打印批注）、耿素云离散、Rudin 分析原理、华中师大数分五版、同济高数、普林斯顿微积分、吉米多维奇微积分+线代、Strang 两本、Axler 线代、Horn 矩阵分析×2、Bertsekas 概率导论、Miller 概率读本、Boyd 凸优化、顾沛简明抽象代数、Artin 代数、do Carmo 微分几何、Zill 微分方程、Boole 差分计算教程（孤本）
- **计算机/AI 库**：CSAPP、CLRS、OSTEP、Kurose 网络、李沐 D2L、余勇强化学习、Goodfellow 花书、吴飞 AI 引论、C 语言程序设计
- **学校**：大学物理（吴百诗）、英语、思政、鲁迅《朝花夕拾》、瘦金体字帖
- 核心骨架书只读英文原版，中文译本作"字典"查难句，建术语映射表

## 关键决策
- 不学：微分方程、微分几何（AI 不需要）；物理目标 60 分；第二课堂/志愿无视
- 专业对策：物理/思政等非核心课 60 分策略
- MIT 对齐：6.042J✅ / 6.006+6.046 计划 / 18.06+18.065 已有 / 6.004 由 CSAPP 覆盖 / 6.840 已购 Sipser / 6.041 由 Bertsekas 覆盖

## 学习方式诊断
- 不是不擅长做题，是大脑拒绝运行未经审查的代码（构建主义协议）
- 数学"从公理出发走一遍推导"；CSAPP"用 gdb 看、用 Lab 拆"
- "三到五成掌握度"正常：只留骨架，实体教材做外挂血肉，大脑只存指针
- 环境：上课抄定义画概念图；安静环境深推；嘈杂环境只做概念学习
- 外部裁判：Bomb Lab、LeetCode 位运算、打印植入 Trick

## 财务/综测/健康
- 生活费 700-800/月，心法"家庭投资"；读研月入 1000-2500 可行（助学金+奖学金+导师补贴+贷款）
- 期末 20/39（前 51%）、综测 23/39：安全中游隐身位，无需调整
- 每 2-3 周发零认知负荷"心跳包"朋友圈（防家人焦虑）
- 痔疮预防：中空记忆棉坐垫（18 元 Laiben）+ 45 分钟起身 + 提肛 + 温水坐浴
- 宿舍边界：伸缩书立+文件盒屏障、透明 PVC 桌垫

## AI 工具矩阵（外部接口层）
- 需求：API 显式锁定 deepseek-v4-pro + reasoning_effort=max；PDF/Word/TXT/OCR 多模态；三端统一；月成本 ≤15 元
- 方案：DeepSeek API 后端 + AnythingLLM 知识库中枢（本地 RAG）+ Chatbox AI 移动前端
- 缓存黄金用例：固定 System Prompt + 长会话 → 命中 85-95%，成本降 90%
- 决策：不订阅迷你模型；GPT-5.5/Gemini 3.1 Pro 现阶段不付费；网页版有降智风险已迁移 API
