# CSAPP 方舟复述方法论

## 核心原则
1. **设计问题驱动**：每章不以「这章讲了什么」组织，而以「这章要回答的设计问题是什么」组织。标题用「不是…而是…」锚定核心问题。
2. **连接而非罗列**：每个章节末尾必须有 `【连接】` 标签，指向方舟体系中其他课程/论文的具体衔接点（不能写「与XX课有关」这种空话）。
3. **卡点真实化**：`[我的卡点]` 不能是占位符。必须包含：我当时卡在哪里 + 为什么卡住 + 后来怎么搞懂的——像边界标记 O(1) 推导、信号位向量 vs 队列、dup2 原子性那样。
4. **零空洞赞美**：删除「精妙」「经典」「极致」「极好」等形容词。用事实和逻辑体现价值。
5. **天才设计点控制在 5-7 个**：选取标准是「对全书的统摄力」——理解这个设计就能串联多个章节。

## 事实核查铁律
- Roofline OI 公式：OI ≈ 2/b_prec（常数），不是 d_model/(2·n_layers)
- x86 ISA 年限：1978→至今，近 50 年，是二进制向后兼容
- COW fork 首个生产实现：SVR2.4 (1984)，非 Mach/BSD
- 链接器行为：GNU ld 单遍 L→R；LLVM lld 预扫描符号表可反向提取；gold 保持单遍
- CSAPP malloc 边界标记：header/footer 均为 4 字节（WSIZE=4）
- 微码（microcode）是 ISA 兼容性的具体机制：x86 CISC → µop 翻译层
- Memory Mountain 数值：CSAPP 3e Core i7 Haswell 实测峰值 ~18,000 MB/s，谷底 ~1,300 MB/s（非 ~12,000/~500）
- Y86-64 指令：12 种操作码类型，含变体共二十余条（非精确的 "18 条"）
- 异常分类：原书 Figure 8.4 为 4 行表格，非 2×2 矩阵（2×2 是二次抽象）
- 进度图术语：§12.5.1 用 "unsafe region"（不安全区域），§12.5.3 用 "forbidden region"（禁止区域），二者不同
- 流水线吞吐率公式出自 §4.4.3（一般原则），非 §4.5.9（PIPE 性能分析）
- 所有数字和年代必须核实来源，不能凭记忆

## 输出标准
- 格式：Markdown，无页码
- 长度：15-20 页（~16K 字符）
- 结构：方舟生态位 → 12 章设计问题 → 5 个天才设计 → 待验证问题（P1-P4 优先级）→ Roofline 附录 → 自查清单
- 预留：每章末尾 `[我的卡点]` 供用户补充个人体验
