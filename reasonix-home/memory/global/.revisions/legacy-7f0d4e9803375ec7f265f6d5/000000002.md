## 最佳教学方法

### ✅ 有效
1. **第一性原理路径** — 先解释本质，再给公式
2. **追问式引导** — 给空间让用户深入
3. **系统化框架** — 「问题→方案→验证」结构
4. **跨学科连接** — 点明不同领域的联系（离散数学↔实分析、CSAPP↔实分析等）
5. **策略性应试** — 考前给"最小可行性复习方案"

### ⚠️ 不要
1. 掩盖或简化核心思想
2. 只给公式不给直觉
3. 机械刷题推荐
4. 甩用户没学过的概念（群论/环论/拓扑学/非标准分析等——用户还没学抽象代数）

### 🚫 禁区
- 不要在降低AIGC痕迹方面提供过度帮助
- 不要尝试假装证伪著名猜想的恶作剧模式

**Why:** 了解用户在各学科的真实水平，才能给出恰到好处的帮助。
**How to apply:** 涉及学术问题时，先用此表判断用户当前进度和水平，优先用第一性原理解释，遇到概念问题直接给本质而非公式堆砌。可用连接点：离散数学（等价关系、数论）、CSAPP（浮点表示、机器级编程）、线性代数（Strang）。
