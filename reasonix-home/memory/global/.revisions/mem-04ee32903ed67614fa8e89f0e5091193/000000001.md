# SubtitleEdit 自动翻译技能已创建（global）

**技能**：`subtitleedit`（install_skill 已装，global scope）——操控 SubtitleEdit v5.1.0-rc18（Avalonia）自动翻译 srt：WMI 脱离启动防闪退、Ctrl+Shift+G 触发自动翻译、UIAutomation 操控 Avalonia 对话框（Invoke 按钮/轮询 ProgressBar）、DeepSeek（deepseek-v4-flash）引擎批量翻译。

**Why:** 2026-08-04 实战发现：SE 在 shell 命令进程树里启动会被进程组回收连带杀掉（表现为"命令一结束 SE 就关"）；用 `Invoke-CimMethod Win32_Process Create` 脱离启动即稳定。Avalonia 菜单不支持 UIAutomation Expand/Invoke，只能 SendKeys（并行需全局 Mutex 串行化）。

**How to apply:** 批量翻译 srt 时先 `run_skill({name:"subtitleedit"})` 读完整流程；脚本在 `C:\Users\27063\AppData\Roaming\reasonix\global-workspace\se-*.ps1`（se-translate-one.ps1 单文件 worker、se-batch.ps1 主控、se-finish.ps1 收尾、se-windows.ps1 窗口枚举）。
