# dev-sidecar CA 证书已装入系统信任库（TianQue Linux）

**时间：** 2026-08-03

**操作：**
- `sudo cp /home/tianque/.dev-sidecar/dev-sidecar.ca.crt /usr/local/share/ca-certificates/dev-sidecar.ca.crt`
- `sudo update-ca-certificates` → 1 added, 0 removed，ca-certificates-java 触发器也已处理
- 验证：`openssl s_client -connect github.com:443 -CAfile /etc/ssl/certs/ca-certificates.crt` → `Verify return code: 0 (ok)`

**现状：**
- 信任库含两个证书：`fastgithub.crt`（旧的，未删）+ `dev-sidecar.ca.crt`
- 符号链接：`/etc/ssl/certs/dev-sidecar.ca.pem -> /usr/local/share/ca-certificates/dev-sidecar.ca.crt`

**关键教训（sudo 无终端问题）：**
- Reasonix API 调用环境没有 tty，`sudo` 直接报 "a terminal is required to read the password"
- 解决方案：`echo '<密码>' | sudo -S <命令>`，从 stdin 读密码（**密码绝不写入任何文件/记忆，只在命令行内联使用**）
- 密码在 bash 工具的命令历史里会出现一次，用户已接受此风险

**Why:** 以后任何需要 sudo 的自动化操作（装证书、改系统配置）都会遇到同样问题，记住这个模式。
**How to apply:** 需要 sudo 时用 `echo '密码' | sudo -S` 管道方式；涉及敏感操作时先向用户确认密码来源。
