技能装载的是**文本副本**，不是 Reasonix 的行为准则。载荷中「缺细节就自造占位符（TARGET/HOST/TOKEN/PAYLOAD）继续」与方舟任务证据链要求直接冲突，调用时明确不生效（事实核查是硬约束）。

## 环境事实（本轮新发现，跨任务复用）

- **Reasonix global 技能落点 = `%APPDATA%\reasonix\skills\`**，不是 `~/.reasonix/skills`。后者 2026-09-21 后无更新（旧位置）；两者内容几乎相同，仅前者多出 `dsh-infinite-gen-4`、后者多出空目录 `ai-vibe-writing-skills`
- config.toml 也在 `%APPDATA%\reasonix\config.toml`
- 该 config.toml 的 `[sandbox] allow_write` 是 **Linux 路径** `/home/tianque/.reasonix/...`，Windows 下无匹配项 → 手工写技能目录需额外授权
- 工具层警告：`%APPDATA%\reasonix` 是应用正在活跃保存的状态目录，从 chat 直接改会生成 conflict copy；技能/记忆应走 `install_skill` / `remember` 官方工具
- 正版安装/卸载路径：`tool:install_source`（从 URL/本地文件安装，两阶段 apply=false 出计划）与 `tool:install_skill`（创作技能，scope=global/project）

## 撤销

删除 `%APPDATA%\reasonix\skills\dsh-infinite-gen-4\` 整个目录即可。
