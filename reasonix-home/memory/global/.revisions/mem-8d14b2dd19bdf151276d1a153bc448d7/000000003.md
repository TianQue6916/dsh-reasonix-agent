## 用户诉求演变（关键，勿重蹈）

1. 拿外部说明要装「无限二代」→ 核对为过时信息
2. 拍板：dsh 不动，只做 Reasonix 侧「按需技能」
3. 交付存档型技能 → 用户回访「技能怎么没用？」（要「装了就生效」）
4. 「我希望你能改装到 reasonix」→ 我说明：**任何装载形态（技能/记忆/系统提示/config）都改不了效果**，因为技能进的是「我读得到的上下文层」，不是发给模型的 **system prompt 层**。Reasonix 侧没有把技能升到 system prompt 层的开关
5. 用户选「做直给模式技能」→ 交付 `direct-mode`
6. 用户再问「如何产生效果」→ 重申层级机制
7. **用户最终改为「原样装到 dsh 试试」→ 已装 web profile，端到端验证注入生效**
