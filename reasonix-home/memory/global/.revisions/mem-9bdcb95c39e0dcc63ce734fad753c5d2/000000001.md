# dsh 0.1.5-rc.2 升级档案（Windows 主力机，2026-09-20）

## 结论一句话
CLI 调用方式**零变化**（dsh-gate 无需改），但**插件默认挂载 / 会话日志文件名 / session 对象 API** 三处变了，其中 session API 变化会让 anchored-standard 锚定**静默失效**（必须打补丁）。

## 升级动作
`npm i -g @deepseek-ai/dsh@0.1.5-rc.2`（npm latest；alpha 通道当时 0.1.6-alpha.2 未采用，用户拍板 latest）。
备份：`~/.dsh/_backup-20260920-upgrade/`（settings.yaml、.env、整个 .agent-presets、两个 profile 的 yml、npm 全局清单、以及一次性工具脚本 `dump-session.mjs` / `scan-zstd.mjs`）。

## 兼容性核查（升级前实测）
- **CLI 参数未变**：`--profile` / `--patch` / `web` / `plugin` / `--dump-config` 全兼容；新增 sdk / sdk-minimal / acp profile。
- **包清单**：0.1.1 的 196 个 `@deepseek-ai/*` 包，0.1.5 只少 4 个（`dsh-client-runtime`、`dsh-host-apiproxy`、`dsh-tool-subagent-report`、`node-addon-landlock-run`），其余 240 个健在；`dsh-llm-pi-ai` / `dsh-web-search-deepseek` / `dsh-tool-str-replace-editor` 均在。
- **settings schema 未变**：`id: settings` + `config.path`（dsh-gate 的 patch 注入点）、`persona` 字段、`llm-pi-ai` provider 路由、`fallbacks`、`agent-loop.maxParallelToolCalls` 全部照旧生效（gate 实跑证实）。
- **变了的三处**：① `str_replace_editor` 不再默认挂载（官方改推 read/write/edit）；② 会话文件 `session.jsonl.zstd` → `session.v3.jsonl.zstd`；③ `session.events`（数组）被移除，改为 `snapshotEvents()` + `log`；另 `tool-subagent-report` 并入 `dsh-tool-subagent`。

## 三处必改（已做）
1. `~/.dsh/profiles/headless/cordis.patch.yml`：`insert:` 尾部补挂 `@deepseek-ai/dsh-tool-str-replace-editor`（maxOutputChars: 16000）。**不补的后果**：tool-bootstrap 的 keep 集里工具名缺失 → warnOnce 后把**全量 26 工具目录**暴露给首轮，锚定失效且无报错。
2. `~/.dsh/.agent-presets/anchored-standard/compaction-epoch.mjs`：新增导出 `sessionEvents(session)`（优先 snapshotEvents() → 旧 events 数组 → 可迭代 log → 空数组兜底），`scan()` 改用它；`tool-bootstrap.mjs` 的 `unlockedFor()`、`instruction-hint.mjs` 的 `hintIsDurable()` 同步改 import + 使用。
   - **回归根因**：`for (const event of session.events)` 在 0.1.5 抛 TypeError，被 tool-bootstrap 的 catch 吞掉后返回全量目录。修前首轮 26 工具，修后 2 工具。
3. junction 维护：`~/.dsh/profiles/node_modules/@deepseek-ai/*` 全是指向*当前 dsh 安装目录*的 junction，**任何 dsh 实例启动都会重建**——用临时目录的 dsh 跑一次会把生产 profile 的 249 个链接全改指临时目录（本次踩到）。修法：用生产 `dsh --profile headless ...` 跑一次自动改回。另清理 9 个无主 junction（升级后 packages 消失）。

## 验证证据
- headless 首轮 tools = `pwsh, str_replace_editor`（2 个，与 0.1.1 一致）；带工具任务实跑成功（pwsh echo 返回 ANCHOR-OK）。
- `dsh-gate-conc.ps1` 同步调用 4s 返回、状态 ✅ 完成、通知正常（升级后复测两次）。
- web profile：3081/3082 端口监听 + 401 授权围栏 + token URL 正常，192 个插件 id 全解析。
- `sessionEvents()` 单元测试四形态通过；epoch 语义正确。

## 回滚
`npm i -g @deepseek-ai/dsh@0.1.1-rc.2` + 从备份恢复 settings.yaml / .agent-presets / profiles 的 yml（sessionEvents 补丁对 0.1.1 向后兼容，可不回退）。

## 待办（Linux 天阙机）
升级时 Linux（100.79.96.82）**offline（已 7 天未上线）**，双机版本暂不一致（Linux 仍 0.1.1-rc.2）。上线后需：`npm i -g @deepseek-ai/dsh@0.1.5-rc.2` + 补挂 str_replace_editor + 打同一个 sessionEvents 补丁 + 重建 junction + 跑锚定验证（首轮 26 工具 = 未打补丁）。

## 细节档案
`dsh-mode` 技能第十一节（含完整兼容性表格与坑位清单）；`dsh-gate` 技能 v2.3.0（会话文件名已更新）。
