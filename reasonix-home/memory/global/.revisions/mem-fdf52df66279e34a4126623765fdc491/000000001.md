## 交付物（Windows 天阙九泉）
- `D:\Toolbox\goat-gateway\goat-tray.ps1` — 主程序（隐藏宿主启动、单实例、定时刷新）
- `D:\Toolbox\goat-gateway\whalegirl-widget.cs` — 自绘控件（深蓝圆角卡片 + 鲸鱼娘图 + 气泡内嵌入额度数据）
- `D:\Toolbox\goat-gateway\start-goat-tray.vbs` — wscript 隐藏启动（避开 Windows Terminal 使 -WindowStyle Hidden 失效的坑）
- `assets\whalegirl.png`（鲸鱼娘本体）、`assets\whale.ico`（托盘/快捷方式图标）
- 桌面快捷方式「鲸鱼娘 GOAT 额度.lnk」；计划任务 `GoatQuotaTray`（AtLogOn / Interactive / 隐藏）

## 用法与交互
- 启动：双击桌面图标 / `wscript start-goat-tray.vbs`
- 左键拖动（位置存 `%LOCALAPPDATA%\goat-tray-pos.json`）；单击刷新；双击托盘显隐
- 右键菜单：立即刷新 / 取消置顶 / 大小：大中小（340/275/225）/ 退出
- 单实例：`Local\GoatQuotaTray` 互斥
- 自检：`powershell -File goat-tray.ps1 -Snapshot out.png` → 渲染成 PNG 后退出

## 数据流
只读 `%TEMP%\goat-usage-cache.json`（GOAT 网关看门狗每 ~4 分钟用 goat-usage.ps1 -Force 预热）；缓存超 240s 才后台隐藏刷新——挂件本身从不阻塞在网络请求上。阈值色：<70% 绿 / 70-90% 橙 / >=90% 红。

## 抠图方法（可复用）
白底透明不用 flood fill：**逐行找首尾非白像素，把两侧白像素透明**（O(W*H) 且不会穿透气泡边框）；气泡区域用“每行最长白色连续段（阈值 0.35W）”聚出 bbox——DSniang02 实测（512 基准）x=47..405 y=31..221 → 归一化 x 0.092..0.791 y 0.061..0.432。

## 踩过的坑
1. **PS 5.1 读含中文的 .ps1/.cs 必须 UTF-8 with BOM**，否则中文乱码/编译失败
2. `Add-Type -Path x.cs` 加载含 WinForms/Drawing 的 C# 需 `-ReferencedAssemblies 'System.Drawing','System.Windows.Forms'`；`System.Drawing.Drawing2D` 是命名空间不是程序集，不能 `Add-Type -AssemblyName`
3. `Color.FromArgb(a,r,g,b)` 参数顺序——写成 `FromArgb(255,255,255,18)` 会得到**不透明亮黄**（曾把进度条背景全画成黄色）
4. 脚本内联 param 默认值里用 `$PSScriptRoot` 在 `-File` 调用下为空 → 改为体内赋值（否则 statusline 报 Join-Path empty string）
5. **我的 bash 沙箱看不到用户桌面的窗口**（EnumWindows 只拿到隔离 window station 内 457 个无标题窗口，MainWindowHandle=0），但截屏（CopyFromScreen）与**计划任务**启动的进程都在真实会话——GUI 验证要用 `-Snapshot` + DrawToBitmap，不要在沙箱里直接起 GUI 然后找窗口
6. 网络：`github.com` 直连不通（000），必须走系统代理 dev-sidecar `http://127.0.0.1:31181` + `curl -k`（MITM 证书）；git 加 `-c http.proxy=... -c http.sslVerify=false`；Bing/konachan/danbooru 等图库被 Cloudflare 挡或不通；marketplace.visualstudio.com、ghproxy.net、gitee 直连可用
