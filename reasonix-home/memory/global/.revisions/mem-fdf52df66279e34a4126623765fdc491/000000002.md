## 动画（用户明确要求“不要只是一张图”）
C# 内部 `Timer` 130ms，每 tick：
1. **帧循环**：ChatGPT/Gemini 各 6 帧 idle 循环（DeepSeek 单帧）
2. **浮动**：`sin(phase + i*1.1) * 2.5px` 错相位
3. **数字滚动**：`_shown += (_target - _shown) * 0.28` 插值
4. **弹跳**：`Pulse()` 置 `_bounce=1`，每 tick `*= 0.72` 衰减，缩放 `1+0.06*bounce`
验证法（可复用）：`-Snapshot a.png -SnapDelay 200` 与 `-SnapDelay 1400` 两次跑，PIL `ImageChops` 对比 → 实测差异 **10.13%** 像素且 bbox 正好是角色区。

## 交互（已按用户反馈修正）
- **双击角色 = 立即刷新**（之前错误地绑成了显隐）；**单击 = 弹一下**；托盘双击 = 显隐
- 右键菜单：立即刷新 / 取消置顶 / 大小（620/520/430，高度按 352/620 比例）/ 退出
- 拖动记位置（`%LOCALAPPDATA%\goat-tray-pos.json`）；单实例 `Local\GoatQuotaTray`

## spritesheet 规范（openpet-ai-girls / codex pet）
尺寸 **1536x1872 = 8 列 x 9 行**，帧 **192x208**。行的非空帧数：`[6,8,8,4,5,8,6,6,6]`（第1行=站立待机/idle，第2-3行=行走）。切帧要点：**先算 6 帧的联合 bbox 再统一裁剪**（逐帧单独 bbox 会让动画抖动），得到 `*-idle-trim.png`（chatgpt 帧99x196 / gemini 帧116x198）。

## 素材处理（Pillow 12.0.0，可用）
抠白底不用 flood fill：**逐行找首尾非白像素，两侧白像素透明**（不会穿透闭合轮廓）；`getbbox()` 后按目标高度等比缩放。

## 数据真实性与局限
只有 Command Code GOAT 有可用额度接口（见 [[commandcode-goat-额度查询端点与看板工具]]）；OpenAI / Google 官方**无余额查询 API**，所以 GPT/Gemini 两位只是形象伴侣，不接数据。
