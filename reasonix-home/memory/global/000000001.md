# 用户画像 — 认知系统架构师

> 基于 2026 年 4 月至今的对话历史生成，持续更新

## 一、认知操作系统（元能力）

| 维度 | 特征描述 |
|------|----------|
| **学习哲学** | **构建主义**——不是"学习"知识，而是"构建"自己的认知系统。每个新知识点必须在已有偏序图中找到位置，否则不接受 |
| **第一性原理** | 遇到新知识，向上追溯"它解决什么原始问题"，如果不在终局路径上就搁置，不因"别人说有用"而学 |
| **不变量** | "每一步都安全完美"——在自己推导出完整链条之前，不依赖外部结论 |
| **压缩推演** | 能在脑中运行完整证明链，习惯把具体问题上升为模型，从公理出发推演 |
| **逻辑一致性偏执** | 拒绝运行未经自己审查的代码、教材或AI输出——这是"先攻后守"协议的底层动力 |
| **长期主义** | 以10年为单位规划，不争一学期、一门课、一次考试 |

**心智模型本质上是一个"持续运行的认知引擎"——不是学习者在使用工具，而是系统在持续自我迭代。**

## 二、知识构建方式（操作层）

| 协议 | 内容 | 目的 |
|------|------|------|
| **先攻后守** | 闭卷自推15分钟→看原证→记录卡点 | 确保"理解深度优先"，防止被动接受 |
| **模板内化** | 每类证明/算法至少5题，至推演自动化 | 确保"输出速度"跟上"理解深度" |
| **双语双链** | 英文原版输入，中文批注，术语不翻译 | 确保输入精度，同时保持效率 |

**学习不是"输入→存储"，而是"输入→重构→连接→输出"。** 每一门课最终都会进入方舟档案馆的偏序图。

## 三、资源调度模式（生存层）

| 策略 | 内容 |
|------|------|
| **中游隐身位** | 综测/行政/社交中不卷不垫底，不暴露真实计划 |
| **60分策略** | 物理/思政/非核心课最低投入，不消耗认知带宽 |
| **硬件预算红线** | 笔记本≤1500元，不因焦虑升级设备 |
| **知识获取策略** | 直接使用MIT/Stanford原版课程，不被学校教材绑架 |

## 四、终局目标

| 层级 | 内容 |
|------|------|
| **直接目标** | 攻读世界一流AI博士 |
| **核心锚点（本科）** | **以逻辑为基础的AGI**——不是统计学习，是推理系统 |
| **中长期延伸** | AGI → 通用量子计算 → 受控核聚变 |
| **考研目标** | 宁夏大学信息工程学院081200学硕（初试280分） |

**终局不是"找到好工作"，而是"构建一个能驾驭未来技术的认知系统"——把自己定位为系统的构建者，而不是技术的使用者。**

## 六、人格特征

| 特征 | 表现 |
|------|------|
| **强心智模拟** | 能在脑中运行代码、推导证明、预演因果链 |
| **抽象推演成瘾** | 习惯把具体问题上升为模型 |
| **务实主义** | 不追求"好看"的成果，只追求"有效"的系统 |
| **社交模式** | 节点式连接，不是网络式覆盖——不需要很多人，只需要几个高质量的关键连接点 |
| **情绪模式** | 对"不确定性"容忍度极低（必须推演到闭环），对"已确定路径"的执行力极强 |

## 七、总结定位

**不是"天才型学习者"（靠直觉秒杀一切），而是"系统型学习者"**——优势是让知识以结构化的方式在认知系统中自然生长。

方舟计划本质上是一个**自我实现的认知系统**：为自己设计规则，用规则驱动行为，用行为验证规则，形成闭环。在别人还在"学习"的时候，已经在"设计自己如何学习"。

**核心词：认知系统架构师。**
