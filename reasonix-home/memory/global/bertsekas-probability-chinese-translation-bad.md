# 《概率导论》中译本质量差 → 6.431 直接读英文原版

来源：2026-08-02 DeepSeek 网页版对话（web search 汇总读者反馈），归档页 `DS_概率导论翻译质量差`。

## 事实
- Bertsekas & Tsitsiklis《概率导论》(Introduction to Probability) **中文版批评声占绝对主导**：
  - 概念性错译（例："掷两次骰子" 被译成 "掷两个骰子"）
  - 漏译关键逻辑甚至整段，导致推理链断裂
  - 机械直译，丢掉了原著「直观、简洁」的风格
- 注意别与 Blitzstein & Hwang《概率论导论》中文版混淆（那本是英文导读性质，另一本书）
- 若必须用中译本：需对照英文原版 + 找勘误讨论

## 与用户的接口
- 他的 P0 是 6.431 概率论（Bertsekas），且本人协议就是「英文原版输入 + 中文批注、术语不翻译」
- → **直接安排英文原版路线**，不要推荐中译本，也不要在讲解里复述中译本的措辞

**How to apply:** 讲概率论一律用原著英文术语（sample space / conditional probability / independence / Bayes' rule / random variable / PMF / PDF / expectation），中文只做注解与直觉说明。
