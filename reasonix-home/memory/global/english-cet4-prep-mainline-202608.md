# 英语（CET-4）是他大二上的隐藏主线

来源：DeepSeek `英语学习` 会话（2026-08-24 起，累计 **892 条消息 / 438 次提问**，是本轮新增里最长的一条），归档页 `DS_英语学习.md`。

## 基线与他自己的目标
- 高考英语 **90 分**（他自评"并不是很好"）；目标 **四级 500+**
- 需要的不是泛泛的"多背单词"，而是**可对照的替换清单**：基础表达 ↔ 高级表达并排、范文升华句、加分短语、结构拆解

## 他实际在用的方法（已经跑起来的）
- 拿真题范文做"升华清单"：把基础表达逐条升级为高分表达，并写出**比参考答案更好的范文**
- 范文 → 逐句解析 + 中文标注（他明确要求"每一个英语后面括号标注汉语意思"）
- 严格控字数（会自己检查"你写出来超过 180 词了"）
- 8 月底还查了四级成绩查询入口、外研社/教务网登录方式；"宁夏大学开学时间确认"同期

**How to apply:** 涉及英语任务时按「英文原句 + 中文括号注」的双语格式输出；给替换对照表而不是抽象建议；四级写作按 120–180 词硬约束。这条线和概率论/信号与系统并列为大二上的真实负担，排学习计划时别只算专业课。
