# AI Vibe Writing Skill — 个性化写作助手

基于开源项目 [donghuixin/AI-Vibe-Writing-Skills](https://github.com/donghuixin/AI-Vibe-Writing-Skills) 的写作方法论封装。核心思想：不是让 AI "写得更像AI"，而是让 AI "学会你"。

## 三大核心机制

### 1. 风格迁移 (Style Transfer)

**目标**：从 3-5 篇你过去的优秀写作中提取你的 "写作DNA"。

提取维度：
- **词汇偏好**：正式 vs 口语化，专业术语密度
- **句式结构**：平均句子长度，长短句比例
- **修辞手法**：比喻使用频率，引用习惯
- **段落节奏**：段落长度，过渡方式
- **标点习惯**：逗号/分号/破折号使用模式

**操作流程**：

```markdown
1. 收集3-5篇你的个人写作样本（论文、博客、报告等）
2. 分析以下风格维度：
   - 词汇选择偏好
   - 典型句式结构
   - 段落组织方式
   - 论证展开模式
3. 生成个人写作风格画像（Style Profile）
4. 应用到新的写作任务中
```

**风格画像模板**：

```markdown
## 风格画像

词汇级别: [正式/半正式/口语化]
平均句长: ___ 词
偏好句式: [简单句为主/复合句为主/混合]
段落风格: [短段落/长段落/混合]
论证方式: [演绎/归纳/类比]
修辞特点: [简洁直接/比喻丰富/数据驱动]
过渡风格: [显式过渡/隐式过渡]
特有词汇: [___、___、___]
禁忌词汇: [___、___、___]
```

### 2. 规格驱动写作 (Spec-Driven Writing)

每次写作前建立明确的文档规格表和完成标准（DoD）。

**文档规格表模板**：

```markdown
## 文档规格

目标受众: [___]
写作目的: [告知/说服/娱乐/指导]
篇幅要求: ___ 字
风格要求: [___]
核心论点: [___]
必含要点:
- [ ] ___
- [ ] ___
禁用表达:
- [ ] ___
- [ ] ___
```

**Definition of Done 模板**：

```markdown
- [ ] 所有段落有明确的主题句
- [ ] 每个观点有论据支持
- [ ] 无 AI 常用词汇（delve, testament, nuanced 等）
- [ ] 无空洞过渡词（Moreover, Furthermore）
- [ ] 句子长度方差 > 0.5 (差异足够大)
- [ ] 已读出声检查自然度
- [ ] 交付前人工审阅
```

### 3. 错误记忆 (Error Memory)

记录并避免已犯的错误。每次写作完成后，记录 AI 痕迹问题和改进。

**错误记录格式**：

```markdown
## 错误记忆

### 错误类型: [AI词汇/句式模板/过渡词/其他]
具体表现: ___
上下文: ___
改正方案: ___
复查结果: [已修复/待观察]

### 错误类型: [___]
...
```

## 三阶段工作流

### Phase 1: 学习阶段

```markdown
1. 用户提供 3-5 篇个人写作样本
2. 分析风格维度，生成风格画像
3. 建立禁用/偏好词汇表
4. 保存到风格记忆
```

### Phase 2: 写作阶段

```markdown
1. 根据文档规格表确定写作参数
2. 按风格画像进行风格匹配写作
3. 实时检查 DoD 完成标准
4. 记录可能的问题到错误日志
```

### Phase 3: 审校阶段

```markdown
1. 对照 DoD 逐项检查
2. 扫描 24 种 AI 模式（配合 humanizer）
3. 手动检查句子自然度
4. 更新错误记忆
5. 交付最终稿
```

## 与 unslop + humanizer 组合使用（最强降AI率流水线）

```markdown
Step 1: ai-vibe-writing → 用风格迁移写出初稿
Step 2: unslop --deterministic --mode full → 自动化清洗AI痕迹
Step 3: humanizer 规则 → 手动逐条检查 24 种模式
Step 4: 迭代修正 → 更新错误记忆
```
