# Grill Me — 计划推演

对计划的每个方面进行无情的面试，直到达成共识。沿设计树的每个分支走下去，逐一解决决策间的依赖关系。

**规则：**
- 一次只问一个问题
- 每个问题附带你的推荐答案
- 如果问题可以通过探索代码库回答，先去探索

**覆盖的范围：**
- 假设条件（哪些假设是安全的？哪些有风险？）
- 边界情况（空状态、错误路径、并发）
- 接口设计（这个模块的公共 API 够深吗？）
- 测试策略（哪些行为最有必要测？）
- 依赖关系（这个决策依赖哪个未解决的问题？）
- 回滚方案（如果这个方案不行，Plan B 是什么？）
