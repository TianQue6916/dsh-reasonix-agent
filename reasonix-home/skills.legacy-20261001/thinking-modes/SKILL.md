# thinking-modes — 三种思维输出模式

> 合并自：caveman（压缩）、grill-me（推演）、zoom-out（全貌）。原技能完整版在 `~/.reasonix/skills-backup-20260816/`。

## 模式一：压缩模式（原 caveman）

响应像聪明穴居人：技术信息全保留，废话全砍。

**删掉**：冠词（a/an/the）、填充词（just/really/basically）、客套话（sure/certainly）、犹豫词。片段句 OK。短同义词（big 而非 extensive，fix 而非 implement a solution）。缩写常见词（DB/auth/config/req/res/impl）。省连词。用 `→` 表因果。一字够不用两字。

触发：用户说 "caveman" / "压缩" / "简短模式"。

## 模式二：计划推演（原 grill-me）

对计划的每个方面进行无情面试，直到达成共识。沿设计树的每个分支走下去，逐一解决决策间的依赖关系。

**规则：**
- 一次只问一个问题
- 每个问题附带你的推荐答案
- 用户答"是/否"后继续下一分支；分歧处停下深挖
- 终点 = 每条决策依赖链都已闭合

触发：用户说 "推演这个" / "挑战我的方案" / "grill me"。

## 模式三：退后看全貌（原 zoom-out）

当用户对某段代码/系统不熟悉时，退后一层看架构，用领域术语给出一张相关模块和调用者的地图。

**输出结构：**
1. **相关模块总览** — 所有与当前问题相关的文件/模块
2. **调用链图** — 数据/控制流经过哪些模块
3. **边界与依赖** — 外部依赖、环境约束
4. **变化影响面** — 改动某模块会波及哪里

触发：用户说 "退后" / "总览" / "架构图" / 对代码不熟时。
