# ACS — Applied & Computational Sciences 降AIGC技能

> 基于5篇理工科知网论文（中介效应、因果ML、GCN交通预测、大模型对齐、多模态NER）的写作特征量化分析
> 参考：Wikipedia Stylometry/Perplexity/Burstiness、GitHub deai-academic-zh/aigc-deslop/AIGC-Detector-Pro、已有 anti-aigc-2026 技能
> **实事求是**：所有量化参数来自真实论文统计，非凭空设定

---

## 核心理念

**理工科论文的降AIGC≠文科论文降AIGC。**

理工科写作特征（来自5篇论文数据）：
- **句长偏长**：平均27.6字，长句(>40字)占比20.2%
- **句式相对规整**：CoV=41.9%（人类理工科正常水平）
- **连接词较密集**：每段约12个，"则""因此""但""由于"为主
- **极少设问**：设问句仅0.2%
- **第一人称适中**：2.45次/千字（我们/本文）
- **术语密度高**：专业术语重复出现属正常

**核心原则**：降AIGC是让文本回归"理工科学者的真实写作"，不是追求极端的CoV或消除一切模式。

### 语料库说明

- 基于5篇理工科知网论文（2024-2025年发表），样本量小，统计值有波动
- 统计方法论文《中介效应分析》兼跨社科/理工边界，纳入ACS组
- 均值±标准差：句长27.6±4.8字，CoV=41.9±3.9%
- 目标范围已考虑±1σ变异弹性

## 第一阶段：诊断

按章节检测AI风险，分三级处理：

| AI风险 | 策略 |
|:------:|------|
| 高(>70%) | 段落级重构——调换信息顺序、合并/拆分段落 |
| 中(30-70%) | 句级改写——句式变换+词汇替换 |
| 低(<30%) | 轻处理——仅替换AI高频词 |

**术语/公式/代码区保真**：专有名词、符号定义、公式、算法步骤、实验参数、引用标记 ❌不改

---

## 第二阶段：改写（优先级排序）

### 1️⃣ 句式变换（最有效）
- **长句拆分**：一个30-50字长句拆成2-3句，一句讲概念，一句讲原理，一句讲应用
- **长短交替**：长句(>40字)后接短句(<20字)，打破AI的"均匀句长"
- **主语变换**：不每句以"本文/该模型/该方法"开头
- **语态变换**：主动/被动交替（"模型被训练"↔"我们训练模型"）
- **目标CoV: 40-50%**（真实理工科水平）

### 2️⃣ 连接词适度调整
理工科连接词密集是正常特征（每段8-15个），不要强行清零：
- ❌保留的：因此、则、由于、从而、进而（理工科高频）
- ⚠️减少的：首先/其次/最后、"值得注意的是"、"不可否认"（AI套话）
- ✅替换：删掉"首先/其次"改为自然递进句

### 3️⃣ 突发度注入
- **句长目标分布**：短句<15字占15-25% | 中句15-40字占55-70% | 长句>40字占15-25%
- **段落不对称**：3句段和8句段交替出现
- **段落长度错开**：不追求每段"匀称"

### 4️⃣ 词级替换
理工科论文AI高频词替换方案（保留术语，替换套话）：

| AI高频词 | 替换方案 |
|----------|----------|
| 有效 | 能够/可以/达到（不必每处替换） |
| 显著 | 明显/突出/有助（有统计数据时保留"显著"） |
| 充分 | 足够/良好/满足 |
| 与此同时 | 句号另起 / 同时 |
| 综上所述 | 合并入总结句 / 删除 |
| 值得注意的是 | 直接陈述事实 |
| 具有重要意义 | 删 / 改为具体意义描述 |
| 在一定程度上 | 删 / 改为限定条件 |
| 不可否认 | 删（理工科不用这种词） |

### 5️⃣ 注入"作者存在感"
- 注入具体实验细节（"我们尝试了X参数，发现Y现象"）
- 注入研究过程中的真实选择（"最初尝试了A方法，但收敛慢，改用B"）
- ❌**不编造数据或实验结果**

## 禁止操作（硬约束）

| ❌ 禁止 | 原因 |
|--------|------|
| 编造数据、篡改数值、伪造参考文献 | 学术诚信红线 |
| 破坏术语精确性 | 理工科术语是学术生命线 |
| 过度删连接词致逻辑断裂 | 理工科需要清晰逻辑链 |
| 将技术句子改"口语化" | 被检测为"AI伪人类化" |
| AI重写AI文本（全量重写） | 叠加AI指纹，越改越糟 |
| 追求CoV>50% | 理工科真实CoV=41.9±3.9%，>50%超出真实人类范围，刻意长短交替反被检测 |
| "以...为..."排比结构 | 实测红率飙至29.7%（数据来源：anti-aigc-2026技能第9轮实测） |
| 零宽字符/隐形字符 | 检测器已可识别 |

## 自检清单

- [ ] 术语/公式/引用/代码未被改动
- [ ] 句长分布：短句15-25% / 中句55-70% / 长句15-25%
- [ ] CoV在40-50%区间
- [ ] 连接词每段8-15个，无非自然"清零"
- [ ] 无"首先/其次/最后"模板
- [ ] 无"值得注意的是/不可否认/具有重要意义"套话
- [ ] 段落长度不对称（3-8句交替）
- [ ] 无编造的数据或案例
- [ ] 设问句占比<1%（理工科保持克制）
- [ ] 通读确认：像"一位理工科研究者写的"
