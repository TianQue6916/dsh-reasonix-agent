# Anti-AIGC 2026 — 降AI率实战技能

> 基于10轮AIGC检测迭代（2026.06）实证数据编制
> 最优版本: 红3.8% + 橙13.8% ⚫黑65.3%

## 核心理念

**AIGC检测器看的是统计特征，不是具体词汇。**
检测器判断依据：困惑度、突发性、句长变异系数、段落对称性、连接词密度。

## 两阶段工作流

### 阶段一：诊断（分章节检测）

先分段检测，按AI率分三类处理：

| AI率 | 策略 |
|:----:|------|
| >80% | 整段重构逻辑，不在原句上改 |
| 50-80% | 保留框架，改句式+删连接词 |
| <50% | 轻处理或跳过 |

**术语密集区（方法论/模型/数据）保真** — 检测器知道术语不是AI特征，少修改。

### 阶段二：改写（按优先级执行）

#### 1. 段落重构（效果最大）
- 一段拆两段，检测器对段落边界敏感
- 打乱段落内信息顺序（AI习惯"宏观→微观→意义"，改成"问题→方法→背景"）
- 段落长度故意不对称（3句接8句）

#### 2. 删连接词
- **每段0-1个连接词**
- 删掉"因此/同时/此外/综上所述/不可否认/值得注意的是"
- 能用句号解决的不用连接词硬连

#### 3. 制造句长变异
- **短句(<15字)占比>20%** 
- **句长变异系数CoV≥60%**
- 长的（50-80字）、中的（20-50字）、短的（5-15字）交替出现

#### 4. 词级替换
- Tier1（必须替换）：有效、充分、显著、与此同时、综上所述、不可否认、值得注意的是、基于此、换言之、由此可见
- 替换方案：有效→管用/顶事、充分→足够/充足、显著→明显/突出、与此同时→直接跳过

#### 5. 句式变换
- 定义句拆两句（一句说是什么，一句说怎么用）
- 设问打断节奏（"为什么？""问题出在哪？"）
- 主语变换（不要每句同一个主语开头）

## 禁止操作（已验证有害）
- ❌ 口语化过度（"门儿都没有""最烫手的山芋"）→ 被判定为AI伪人类化
- ❌ "以...为..."排比结构 → 红率飙至29.7%
- ❌ AI改写AI文本 → 越改写AI指纹越重
- ❌ 追求"完美学术风格" → 高质量文本假阳性率更高

## 统计目标

```
短句(<15字)占比: >20%
句长变异系数 CoV: ≥60%
连接词密度: 每段≤1个
正文汉字: ≥4000
Tier1禁用词: 清零
总修改率: >40%
```

## 检查清单

- [ ] 每段拆过或重排过信息顺序
- [ ] 连接词≤1个/段
- [ ] 短句占比>20%
- [ ] Tier1词全部替换
- [ ] 术语密集区保留
- [ ] 无"以...为..."排比结构
- [ ] 无过度口语化
- [ ] CoV≥60%验证
- [ ] 全文通读确认自然度
