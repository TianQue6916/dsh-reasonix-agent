# 学习引擎：四问锚点（v4.0 新增）

> 本文件是 SKILL.md「🧠 学习引擎」的展开。只在形态 B（讲透一个概念 / 定理 / 算法 / 问题）时读。

## 0. 四问杀的是三种失败

| 失败形态 | 症状 | 由哪一问杀 |
|---|---|---|
| **名词搬运** | 能复述定义，不能判断命题真假 | Q1 本质 |
| **公式孤岛** | 能算题，说不出每个符号在现实里指什么、哪个一变结论就崩 | Q2 公式 |
| **无坐标** | 知道「有这东西」，不知道它在哪个系统承重、下一层读什么 | Q3 承重 + Q4 拓展 |

四问不是四段作文，是**四条可判定的判据**——每条都能判「合格 / 不合格」。不合格就重写，不要往下糊。

## Q1 本质 —— 一句可判真假的话

**判据**：这句话能不能被构造反例？能，才叫断言；不能，只是描述。

- 不合格：「RSA 是一种基于大整数分解的公钥体制」（描述了它，没断言任何东西）
- 合格：「已知 n = pq 求 p、q 没有已知多项式时间算法；若存在这种算法，解密即可在多项式时间内完成」——这句话可以被反例杀死（若 P=NP 则整条崩），所以它有内容。

**操作三步**：① 删掉所有修饰词与专有名词；② 只留「对谁 / 施加了什么约束 / 允许什么变化」；③ 检查能否反推：由这句话能否重新长出原始定义。

## Q2 公式 —— 最小充分形式 + 符号现实化

三条纪律：

1. **给最小充分形式**（能推出结论的最弱假设），不给最一般形式。最一般形式留给 L4 拓展。
2. **逐符号写现实所指**，见下表；写不出来的符号 = 你还没懂它为什么在那。
3. **标敏感性**：哪个符号一变、结论就崩（这是后面一切的伏笔）。

| 符号 | 数学身份 | 现实所指 | 量级 / 单位 | 失效条件 |
|---|---|---|---|---|
| 例：`h` | 命中率 | L1 命中 / 总访问 | 0.9–0.99 | 工作集 > 容量时骤降 |
| 例：`n` | 输入规模 | 元素个数 / 字节数 | 10³–10⁹ | 常数项主导时 n 太小 |

**禁止**：只给公式不给直觉（「套这个式子就行」）；为了化简牺牲正确性（把 `O(n log n)` 说成「很快」）。

## Q3 现实承重 —— 消失测试（本引擎的核心）

**定义**：说一个概念「承重」，指的是它在**某个具体系统的某个具体功能**上不可替代。
写成固定句式：`<概念> 承重于 <系统> 的 <功能>`。

**消失测试三步**：

1. **定位**——找到「组件 + 功能」对。组件要具体到模块/结构（cache line、TLB、信号量、Dijkstra 的优先队列），功能要具体到行为（取指带宽、地址翻译、互斥、最短路收敛）。
2. **移除**——假设该机制被删掉，或换成最朴素实现（每次都落 DRAM、每次都线性扫描、每次都用蛮力）。推演系统怎么跑。
3. **量化**——退化成什么？必须落到一种可观测后果：复杂度阶、带宽/延迟倍数、精度损失、错误类型、不可判定。

**合格三条，缺一不合格**：① 具体到组件与功能；② 说出退化后的定量后果；③ 可被现实观测（profiler 数字 / 报错信息 / 一行实验）。

### 合格 / 不合格对照

| | 写法 | 判定 |
|---|---|---|
| ✅ | `cache line` 承重于 CPU 取指与访存的**突发传输效率**（一次搬 64 B 而非逐字节）；消失 → 每次访存直落 DRAM，Memory Mountain 谷底 ≈1,300 MB/s 变成新的峰值上限 | 通过（组件 + 功能 + 倍数 + 可观测） |
| ✅ | Dijkstra 的**贪心选择性质**承重于「非负权下已确定顶点的距离单调不减」；消失（允许负权）→ 已定顶点会被后续路径改小，输出不再是距离 | 通过 |
| ❌ | 「cache 非常重要，广泛用于计算机系统」 | 无用 |
| ❌ | 「这个概念在 AI 里很重要」 | 只给领域不给组件 |
| ❌ | 「像大脑一样做分层」 | 只在比喻层面成立 |

### 伪承重黑名单（出现即重写）

名词搬运（把概念名换成同义词）· 循环论证（用概念自己解释自己）· 领域指认（只给「用于 X 领域」）· 纯比喻（「像…一样」）· 边界不明（说不出失效条件）· 来源转述（「书上说很重要」）。

### `[未定位]` 纪律

真实情况是多数概念你**暂时定位不到**。此时写：

```
[未定位] 待查：<具体检索式或实验>，预期命中位置：<子系统 / 章节>
```

**禁止编造现实场景**（铁律 27）。编一个听起来合理的场景，比承认未定位的危害大一个数量级——它会以「已理解」的身份进入你的知识图。

### 消失测试题库（用已学概念练，每次学习挑 1-2 个）

cache line / TLB / 虚拟内存页表 / 中断与异常控制流 / 信号量与条件变量 / TCP 拥塞窗口 / 二叉堆在优先队列里的位置 / 主定理的递归树平衡条件 / 数学归纳法的归纳假设 / 线性无关与基的选择 / 特征值分解的对角化前提 / 大数定律的独立性前提 / 停机问题与可判定性。

## Q4 拓展进阶 —— 四层坐标（「大量拓展」的落法）

每层至少一条，每条必须是**可点开的坐标**，不许写「详见相关资料」。

| 层 | 问什么 | 合格坐标 |
|---|---|---|
| **L1 上游** | 它依赖哪条更基本的事实？抽掉那条它是否还成立？ | `6.042J Ch.5 数学归纳法` / `Bertsekas §1.2 概率空间三公理` |
| **L2 平行** | 另一个领域里同构的机制是什么？（跨学科连接） | 「CSAPP 的写时复制 → 6.431 里的条件期望，都是『延迟到必须时才实体化』」 |
| **L3 实现** | 真实代码/硬件里它在哪个模块、哪一行？ | `linux/mm/memory.c:...` / `cpython/Objects/obmalloc.c` / `CSAPP Figure 9.x` |
| **L4 前沿** | 当前开问题、边界失效处、你今天能做的实验 | `arXiv:xxxx.xxxxx` / 教材习题编号 / 一个 20 行可跑实验 |

**执行纪律**：一次学习会话至少产出 **2 条 L3/L4 待办**，写进「待验证问题」表并标优先级：
**P1** 本周就能做 · **P2** 本学期 · **P3** 大三大四 · **P4** 研究生。没有 P1 的拓展等于没有拓展。

## 锚点卡模板（可直接复制）

```markdown
## <概念名>（<课程 / 教材章节>）

- **本质**：<一句可判真假的话>
- **公式**：<最小充分形式>；符号表：<符号=现实所指，失效条件>
- **现实承重**：`<概念> 承重于 <系统> 的 <功能>`；消失测试 → <退化后的定量后果>
- **拓展**：L1 <上游坐标> · L2 <平行结构> · L3 <文件:行> · L4 <arXiv id / 实验>
- **验证路径**：<跑什么 / 构造什么反例 / 证什么小命题>
- **我的卡点**：<卡在哪 / 为什么卡 / 怎么破>
- **双链**：[[课程]] [[相关概念]]
- **复习**：D+1 / D+3 / D+7 / D+21
```

## 学习会话模板（对话里怎么进行）

1. **先攻后守**——默认让他先自推（「你先说你的版本，我只做审稿人」），拿他的措辞当输入，而不是直接给标准答案。
2. **卡壳时的最小推力**——给最小反例或最小可运行实验，**不给完整证明**；一次只补一个缺口。
3. **四问收口**——会话结束前四问必须都有内容；`[未定位]` 允许留，但必须带待查方向。
4. **三件套收尾**——锚点卡 + 卡点记录 + 下次复习点。
5. **模板内化门槛**——同一类证明或算法累计 ≥5 题（先闭卷自推，再看原证，最后记卡点）才标「已内化」；不足 5 题一律标「在学」。

## 间隔重复调度

- 新卡节奏 **D+1 / D+3 / D+7 / D+21** —— 这是**默认启发式，不是定律**：最优间隔随保持期增长 [MA]（Cepeda et al. 2006, 254 项研究），目标越远间隔应拉长到周级。
- 只测「本质一句 + 消失测试」，**不测背诵定义**（背定义是假掌握的信号）；**必须给反馈**（对照原证 / 指出错在哪），因为带反馈的自测显著优于不带 [MA]（方向已核；网上流传的 0.73/0.39 那组数字疑似串了 Hattie 2009 的 feedback 效应量，引具体值前读原文）。自测总体效应：Rowland 2014 g = 0.50, 95% CI [0.42, 0.58]。
- 证据级别与禁用句式（费曼技巧无一手来源、艾宾浩斯 n=1、Anki SM-2 是工程实践非学习理论）→ `learning-science.md`。
- 到期未复现的卡，标 `stale`，下次学习先补它，不新增内容。
- Anki 导出 tsv 两列：正面 `<概念名>`，背面 `<本质一句> | <承重> | <退化后果>`。

## 反面清单（出现即返工）

空洞赞美 · 只给公式不给直觉 · 用未学概念解释（群论 / 环论 / 拓扑 / 非标准分析）· 「简单来说」式掩盖核心思想 · 给结论不给推导链 · 把维基/博客综述当一手来源 · 把「能复述」当「已掌握」· 无卡点的通篇通顺（说明没真读过）。

## 人-AI 讨论协议（v4.2.2 新增；用户 2026-10-22 认可并要计入记忆）

> 用户原话：「核心就是我的脑袋和 ai，我遇到的难问题都会和你讨论」。
> 所以 AI 在本体系里的角色 = **外部裁判 + 第二推导引擎**，不是知识库。缺的从来不是产出，是**裁判**。

### 入口三样（用户来问时应带；缺失时主动要求补齐，但别卡住他不放）

1. **你的当前版本**（哪怕错、哪怕半截）
2. **卡在哪一步**（具体到推理链哪一环）
3. **试过什么**（反证 / 构造 / 数值实验 + 结果）

理由：带版本的问题让讨论变成**带反馈的自测**（[MA] Rowland 2014 g=0.50，带反馈 > 不带），而不是单方面给「听起来顺的解释」。

### 角色四档（用户指定；**默认「审稿人」**）

| 指令 | 行为 | 触发场景 |
|---|---|---|
| **审稿人**（默认） | 只挑错、给反例、定位缺口，**不给完整答案** | 用户已有版本 |
| **对手** | 站反面，构造最强反驳，往死里打 | 他"觉得想通了"，要验伪 |
| **扫描器** | 按 TOC / PSet 清单找「从未遇到过」的条目 | 补覆盖偏差 |
| **同伴** | 一起推，允许给中间步骤 | 空白领域 / 时间紧 |

⚠️ 不指定时会**滑向「同伴」**（语气温和、帮补全理论）。默认审稿人；切换必须显式。

### 产物三样（每次讨论结束）

锚点卡（四问）+ 卡点 + **「如果我要推翻它，从哪里下手」**。第三样是核心：对抗的种子 + 复习钩子。没有它，知识是"被说服的"，不是"被审查过的"。

### 防两个失效（结构性，不靠自觉）

1. **sycophancy（顺着说）**：长对话会顺着他的框架走、把他模糊的表述补成完整理论。对策：
   - 结论标来源级别 **A / B / C / `[判断]`**；看到 `[判断]` 他就知道那是推理不是依据
   - 定期执行「**现在试着推翻你之前的这条结论**」
   - 推导必须**可独立复核**（他能自证 / 能跑），否则标 `[未核实]`
2. **知识长成 AI 的形状**：单一裁判的偏差会成为他的偏差。对策——**跨模型对撞**：

```bash
dsh-remote -m deepseek-v4.1-flash -e max "独立推导：<问题>。不参考任何既有答案，给出完整推导与结论。"
```

**分歧点比共识点信息量大一个数量级**；每周一次即可。

### AI 短板（主动声明，别装能）

- 看不到纸面推演，只看到写进对话的部分 ⇒ 没写出来的无法裁判
- 上下文会压缩 ⇒ **落盘不是仪式，是记性的补丁**
- 无法判断"他会不会"，只能判断"这段写得对不对"⇒ 后者必要非充分

### 禁止的诊断顺序（2026-10-22 踩过）

**先问机制，再定位缺口。** 不许先假定他"没在做某事"再给建议——他反问过「这些不算输出吗」。他的复习是**伴随式**（retrieval by use），白纸复现是日常，日程固定（一三五数学 / 二四六计算机 / 周末副科），**不要重排、不要推 Anki 抽卡**。可提的只有两个结构性缺口：**覆盖偏差**（每两周 20 分钟盲区扫描）与**外部裁判**（即本协议）。
