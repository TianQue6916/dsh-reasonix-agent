# 课程资料库与打印稿流程（2026-08-02 实测）

来源：`DS_课程资料整理概览.md`（vision 会话，37 张截图逐个识别）。

用户在送打印前的资料库形如 `8.2 曹 05 > 天阙九泉 300元 曹 05`（"300元" 即那次打印的量）。同目录下有一份打印要求文本：**`a4黑白双面不订 每个文件夹分开放好.txt`**。

## 覆盖课程与内容
- **6.046J 算法设计**：Lec 01–24 讲义、Rec 01–11、Problem Set 01–10（题目 + Solutions 齐全）、补充材料（fft / knapsack / maxflow / minqueue / skiplist / apsp / btree_combine / async_bfs / applications 等）、Quiz 1、Quiz 2、Final Exam（均含解答）、`00-课程计划.pdf`
- **CS144 计算机网络**：Unit1 Internet-and-IP（1-0…1-12）、Unit2 Transport（2-0…2-12）、Unit3 Packet-Switching（3-1…3-11）、Unit4 Congestion-Control、Unit5 Applications-and-NATs、Unit6 Routing、Unit7 Lower-Layers、Unit8 Security；Lab 0–6（网络热身 / 拼接子串 / TCP 接收端 / 发送端 / 连接 / IP 路由器 / 网络接口）；抓包练习、期中期末练习（含答案）；教材 Peterson-Davie《计算机网络-系统方法》
- **EE364a 凸优化**：讲义 01–16（Introduction、凸集、凸函数、凸优化问题、对偶、近似、统计估计、无约束/等式约束最小化、内点法…）+ 补充材料
- **《概率导论》**、**MacKay《信息论》**
- 统一结构：`01-讲义笔记 / 02-习题课Recitation / 03-习题集(PS) / 04-复习资料 / 05-教材`

**How to apply:** 需要材料清单/某课重点时按这套结构给路径与文件清单；涉及"打印"需求默认 A4 黑白、双面、不装订、按课程分开放。要送打印的文件不要发 Word 给打印店，直接 `xxx.py` 或 PDF，并提醒店员用记事本/原格式打开（2026-08-02 的 `DS_Python文件打印疑问` 结论）。
