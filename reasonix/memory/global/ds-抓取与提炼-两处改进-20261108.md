## 1. `bulk_fetch.cjs`：message_id 级并集（`~/deepseek-scrape/bulk_fetch.cjs`）

**动机**：原来按会话级 mtime 判定「本轮已抓」，写盘是整段覆盖。若上游按页返回（社区插件 `dsh-deepseek-import` 提到「DeepSeek loads long conversations page by page, merge by message identity」），新抓的条数可能少于旧档 → 覆盖会**丢掉尾部**。已确认 raw 每条 message 都带 `message_id` + `parent_id`。

**实现**（新增两个 helper + 改三处）：
- `msgsOf(f)`：安全读 `data.biz_data.chat_messages`
- `mergeById(oldMsgs, newMsgs)`：以 `message_id` 为键 Map 合并（新的覆盖旧的，处理「消息被编辑」），按 `inserted_at` 字典序稳定排序
- 写盘前：`dst` 存在就读旧档 → `mergeById(before, fresh)` → 回写 `j.data.biz_data.chat_messages = merged`；`fresh.length < before.length` 时打 `truncated` 标记
- 统计加 `merged: {added, kept, truncatedSessions}`，日志打「新增 N / 沿用 M」

**真机验证**（造旧档 600 条 + fake index 强制重抓，会话 `11223553-21ff-4a1a-b235-cf5875df33b0`）：
```
旧档 600 条 + 新抓 728 条
→ ✅ ok 1 · 消息 728（新增 128 / 沿用 600）
→ 合并后消息数 728（期望 728）唯一 id 728
```
单测（截断场景 / 增量场景 / 顺序 / 编辑覆盖）另跑一遍全过。

## 2. 顺手修的两个既有 bug（不是这次引入的）

- **`TARGET_RAW` 自定义时 ENOENT 崩**：原代码只 `mkdirSync(NEW_RAW)`，没建 `TARGET_RAW` → 写盘 `ENOENT ... _t_raw\xxx.json`。已加 `if (TARGET_RAW !== NEW_RAW) fs.mkdirSync(TARGET_RAW, {recursive:true})`。
- **首次抓时 `added` 恒为 0**：初始值原写 `added = 0`，导致「第一次抓 728 条」日志显示「新增 0」。已改 `added = fresh.length`（无旧档时全部算新增）。

## 3. `ds_distill.py`：prompt 加「已有条目」+ conflict 纪律（`~/.dsh/storages/tools/ds_distill.py`）

**动机**：第一轮 343 条 → 扩充轮发现的 4 处推翻（离散「零素材」/ CSAPP Ch3-5-6-7 缺口 / 物理「无投入」/ 算法 counting sort L0）**全靠 subagent 偶然撞见与旧条目矛盾**，是运气不是方法。

**实现**：
- `plan` 生成 prompt 时读 `_distill/<slug>.json`，把已有条目的首行（截 44 字）列成「## 已有条目（共 N 条，**不要重复**；矛盾时必须标 conflict）」，最多 80 条
- 纪律新增第 6 条：矛盾时**不要静默选一边**，写一条 `"conflict": true` 的 insight，`content` 写成「旧：<原判断> → 新：<新证据>（依据 …）」，`evidence` 给两处位置，`importance` 4–5
- 纪律新增第 7 条：重复的不重写；同主题更深的证据注明「深化 #<原条目前缀>」

**验证**：`ds_distill.py plan --all` 重生成 14 个 prompt，抽查 `algorithms.md` 有「## 已有条目（共 36 条…）」+ 纪律 6/7 ✓

## 4. 两条工程教训

- **bash heredoc 里写 `\\n` 会被吃掉反斜杠**：往 Python 源码里注入含 `"\n"` 的字符串时，`<<'PYEOF'`（quoted heredoc）也没保住 → 源码变成真换行 → `SyntaxError: unterminated string literal`。**改源码用 `str_replace_editor`，或在 Python 里用 `chr(10)` 拼接，别靠反斜杠转义。**
- **改完必须真跑一遍**：`bulk_fetch.cjs` 的 mkdir bug 只有真正写盘才暴露（语法检查和单测都发现不了）。
