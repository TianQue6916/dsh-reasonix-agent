- 实验性：Playwright/Chrome DevTools/Stagehand 浏览器后端、Computer Use、Auto review 模式、语音转写

## 桌面端（Desktop）实况
- 仓库内 `apps/desktop` = `@deepseek-ai/dsh-desktop`（private，不发 npm）＝ Electron 壳套整套 dsh Web；`apps/desktop-host` ＝ 配套 Node 宿主
- 官方 README 关键事实：appId `com.deepseek.harness`；**默认端口 19387**（Web 是 3080）；Windows NSIS 安装器 + 代码签名 + `electron-updater` 自动更新；托盘常驻；关窗后台续跑；内嵌 Platform（账号/额度/引导）
- **支持目标只有 macOS arm64/x64 + Windows x64，Linux 不在支持列表**
- **版本策略：桌面端与 `@deepseek-ai/dsh` 强制同版本号**（Electron shell / dsh runtime / pnpm 作为一个签名更新单元）
- 分发：打包后上传私有 COS 桶（DOWNLOAD_PROD_COS_*），成功后打 `desktop-v<version>` tag；但 GitHub 无 `desktop-v*` tag、release 资产为空、官网无下载入口 → **目前属内测/受邀渠道，无公开下载**
- 0.1.7-rc.2 release notes 有『修复部分桌面安装包启动失败』『桌面端首次使用引导』→ 安装包已在小范围流通
