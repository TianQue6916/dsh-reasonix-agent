## 结论（2026-11-16 实测）

「自动 git 有点奇怪」= 三条链路同时静默断了，各自断在不同处。

### ① ~/.dsh 本地 autocommit（2026-11-11 17:25 → 11-16 13:45 零提交）
- 根因：2026-10-31 加的 `.git/hooks/pre-commit` 会拒绝「暂存区混 ≥2 个主题域」；
  `dsh-autocommit.ps1` v1 却每 5 分钟 `git add -A`（必然混 5~7 个域）→ hook 每次都拒。
  v1 用 `2>$null` 吞掉 commit 失败，**照样往日志写一行「commit auto: … head=4f8d196」**，
  HEAD 五天没动。5765 个文件（dsh-runtimes 273 MB / tmp/wincu057 一个 npm 包 220 万行 /
  certs/ca.key / ds-harness-remote 的 server-credentials.json）卡在暂存区。
- 证据：`logs/dsh-autocommit.log` 302 KB，全是 head=4f8d196 的假成功行。
- 连带：日记的 `autocommits: 128` 是假的 —— `journal/aggregate.py:load_autocommit()`
  按「日志行里出现日期」计数，不是在数 git commit。
- 修法（v2）：与 hook 共用同一张域表（preset/scratch/session/runtime/toolkit/docs/misc），
  分域多次提交；比 HEAD 是否前进，没前进记 `!! FAIL` 并写 `logs/dsh-autocommit.status`；
  文件清单走 `git status -uall` + `--pathspec-from-file`。
  两个实际踩到的坑：PS 5.1 的 `Set-Content -Encoding UTF8` 会写 BOM，git 把 BOM 当路径首字符 →
  一个都 add 不上；`Get-Domain` 里 `-replace '\', '/'` 是无效正则（应 `.Replace()`）。
- 治理：`.gitignore` 增 dsh-runtimes/ tmp/ certs/ .learn/run/ *.apk ds-harness-remote/ llm-latency/，
  再把 5765 文件按域拆成 7 个 commit 补齐。

### ② 双机同步 sync_dsh.py（skills 停更三周）
- 根因：`EXTRA_PAIRS` 里 Windows 侧 skills 真身还写着 `%APPDATA%\reasonix\skills`，
  而 11 月初已搬到 `C:\Users\27063\ai-skills`（`~/.dsh/skills` 是 junction）。
  APPDATA 那份是 Nov 2 的残留（缺 aigc、带一个 .bak）→ 同步搬的是旧副本，
  且 `--verify` 报「0 差异」，因为两边比的都是过时数据。
- 修法：EXTRA_PAIRS 改指 `C:\Users\27063\ai-skills`；EXCLUDE_DIRS 增
  edge-aigc / certs / dsh-runtimes / ds-harness-remote / llm-latency
  （edge-aigc 一个目录就吃掉 62 个冲突里的 98 条路径，两边都在写 Cache/DIPS）。

### ③ GitHub 备份 backup-to-github.ps1（2026-11-07 → 11-16 一次没推上去）
- 根因 A：`dsh` target 的 XD 没排 edge-aigc / dsh-runtimes / certs，
  于是第三方 JS 里的示例串（pdf.worker.min.mjs、content.js、ts.worker.js、
  wallet.bundle.js、pnpm.mjs）被当成疑似密钥，脱敏闸门「5 个文件仍含疑似密钥」→ exit 3。
- 根因 B：开头 `git pull --ff-only` 输出被 Out-Null 吞掉；远端一旦被别处推进过就永远
  分叉，push 每次 non-fast-forward。备份仓是**镜像不是分支历史** →
  改成 fetch + `reset --soft origin/master`。
- 修法后实测：`兜底校验通过：无残留密钥` → 提交 314 文件 → `已推送到 GitHub`，
  remote master == local HEAD。

## 落点
- Windows `~/.dsh`：本地 git（无 remote，推送走 dsh-reasonix-agent 的 dsh/ 子目录）
- Linux `~/.dsh`：`/home/tianque/.dsh`，cron `20 * * * * dsh_autocommit.sh` + `15 * * * * sync_dsh_cron.sh`
- 镜像仓：`C:\Users\27063\Desktop\reasonix-ops\repo`（= D:\Desktop\工具箱\reasonix-ops\repo）→ TianQue6916/dsh-reasonix-agent（public，强制脱敏）
- 日记仓：`~/.dsh/journal` → TianQue6916/diary（11-16 时已是最新）
