## 结论（2026-11-16 实测，三轮修复后稳定）

「自动 git 有点奇怪」= 三条链路同时静默断开，各自断在不同处。

### ① ~/.dsh 本地 autocommit（11-11 17:25 → 11-16 13:45 零提交）
- 根因：10-31 加的 `.git/hooks/pre-commit` 拒绝「暂存区混 ≥2 主题域」；`dsh-autocommit.ps1` v1 每 5 分钟 `git add -A`（必然混 5~7 域）→ hook 每次拒。v1 用 `2>$null` 吞掉失败，**照样写一行 `commit auto: … head=4f8d196`**，HEAD 五天没动。5765 文件卡在暂存区（dsh-runtimes 273 MB / tmp/wincu057 一个 npm 包 220 万行 / certs/ca.key / ds-harness-remote 的 server-credentials.json）。
- 修法（v2）：与 hook 共用同一张域表（preset/scratch/session/runtime/toolkit/docs/misc），分域多次提交；比对 HEAD 是否前进，没前进记 `!! FAIL` + 写 `logs/dsh-autocommit.status`；文件清单走 `git status -uall` + `--pathspec-from-file`。
- 两个实测坑：PS 5.1 的 `Set-Content -Encoding UTF8` 写 BOM，git 把 BOM 当首个路径字符 → 一个都 add 不上；`Get-Domain` 里 `-replace '\', '/'` 是无效正则（应 `.Replace()`）。
- 连带：日记的 `autocommits: 128` 是假的 —— `journal/aggregate.py:load_autocommit()` 按「日志行含日期」计数，现在只数真提交行。

### ② 双机同步 sync_dsh.py
- 根因：`EXTRA_PAIRS` 的 Windows skills 真身还指 `%APPDATA%\reasonix\skills`，11 月初已搬到 `~\ai-skills`（`~/.dsh/skills` 是 junction）。旧副本缺 aigc、带 .bak，`--verify` 因此永远报「0 差异」。
- 修法：改指 `C:\Users\27063\ai-skills`；EXCLUDE_DIRS 增 edge-aigc / certs / dsh-runtimes / ds-harness-remote / llm-latency；EXCLUDE_FILES 增 dsh_autocommit.sh（与已排的 .ps1 对称）；EXCLUDE_SUFFIXES 增 .apk/.part。
- 效果：冲突 62 → 12，edge-aigc 的 98 条路径归零；剩 12 条是 `~/.reasonix/memory/global/*.md`（两边都在写 memory，设计上保留双份）+ 1 个 dop 补丁，属正常。

### ③ GitHub 备份 backup-to-github.ps1（11-07 → 11-16 一次没推上去）
- 根因 A：`dsh` target 的 XD 没排 edge-aigc/dsh-runtimes/certs → 第三方 JS 里的 `AKIA…` 样例串（pdf.worker.min.mjs、content.js、ts.worker.js、wallet.bundle.js、pnpm.mjs）触发脱敏闸门 exit 3。
- 根因 B：开头 `git pull --ff-only` 输出被 Out-Null 吞掉，远端被别处推进一次就永久分叉 → push 永远 non-fast-forward。备份仓是**镜像不是分支历史** ⇒ 改 fetch + `reset --soft origin/master`。
- 修完实测：`兜底校验通过：无残留密钥` → 提交 → `已推送到 GitHub`，remote master == local HEAD（16:13 为 efce862）。

## 2026-11-16 收尾三件（用户答「都可以，按以往经验」）
- **A .gitignore 双机统一**：以 Windows 版为基线，并入 Linux 独有的 `_conflict-archive-*/`、`out/`、`peers/`、`backups/`。双机 sha256 同 `638b109d5eacc348`。验证：15:16 那轮同步的冲突清单里不再出现 .gitignore（14:18 那轮还有 3 条）。
- **B skill 退役**：`bilingual-ocw-translator` 是 `learn-translate` 的前身（frontmatter 自述「原名 bilingual-ocw-translator」）⇒ 双机移进 `.retired/bilingual-ocw-translator.retired-20261116`，skills 双机各 99 项。`~/.reasonix/skills` 下无该技能（只有 `bilingual-translator`，早已是无 SKILL.md 的空壳）。
- **C public 保持不动**：`dsh-reasonix-agent` 仍 public。依据 = 历史设计就是 public + 强制脱敏（脱敏表覆盖 sk-/ghp_/AKIA/私钥/wpa_passphrase），改可见性是不可逆外部操作，不擅自动。要知道的是：备份里有 `reasonix/memory` 全部条目（414 条），谁想看都看得到。
- 顺手清掉：`skills.junctions-legacy-20261001/`（125 个指向 `.reasonix/skills` 的 POSIX symlink 快照）停跟踪 + 进 .gitignore —— Windows git 解析不了 `/c/...` 链接目标，每条命令都报 `could not open directory`。
