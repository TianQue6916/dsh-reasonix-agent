## 画像与教学偏好之外的一条硬事实（工程侧，2026-11-16 定案）

### dsh 双端（Windows「天阙九泉」/ Linux「TianQue」）同步的真实机制
- **不是 git**：`~/.dsh` 是本地 git 仓库但**无 remote**（`git remote -v` 空），commit 永远不离开本机。
- **是 `~/.dsh/storages/tools/sync_dsh.py`**：SSH + paramiko，从 Linux 侧发起（cron 08:30/12:30/21:30，`~/.dsh/logs/sync_dsh.log`）。Windows 有 OpenSSH server，凭据在 `~/.reasonix/global-workspace/sync/sync_reasonix.py`（`USER=27063 / PASS=TQJQ6916`，HOST=100.84.67.49）。Linux 可免密 SSH 到 Windows（`ssh 27063@100.84.67.49`）。
- 冲突策略：**保留双份**（`<name>.conflict.<host>.<hash>.bak`），绝不覆盖；「size 相同即视为相同」，等长改动不传播。
- `TOOL_FILES` 规定「本地为源、覆盖远端」⇒ `sync_dsh.py` 的**权威副本在 Linux 侧**，改完要 scp 回 Windows 保持两边一致。

### 三个排除规则（踩过三次，都是这里）
1. `_MACHINE_LOCAL_RE` 排除 `profiles/<p>/package.json`、`pnpm-workspace.yaml`、`pnpm-lock.yaml`、`cordis.patch.yml` —— **插件声明永远不跨机**，两端各写各的。要两端插件一致，只能在两台机器上各改一次。
2. `EXCLUDE_FILES`（basename 匹配）曾含 `'cordis.patch.yml'`，把 `plugins/*/cordis.patch.yml`（bundle overlay）一起排掉 → 对端 dsh 启动报 `skipping profile bundle: ... ENOENT`，插件面板只剩骨架。**2026-11-16 已修**为按路径排除（`^(cordis\.patch\.yml|profiles/[^/]+/(...))$`），`plugins/**/cordis.patch.yml` 现在随源码走。
3. `EXCLUDE_DIRS` 含 `node_modules`、`.git` —— 派生物各端本地 `pnpm install` 重建（改完 package.json 后 dsh 约 1 分钟自动 install 收敛）。

### 面板/后端配套（额度面板）
- 8790 的 `quota-http.mjs` 两端是**两套实现**：Windows 49569 B（11-14，`execFile('powershell', ['goat-usage.ps1'])`）、Linux 5958 B（10-26，只有 /quota /balance /health）。
- 新面板要 `/cache`、`/connectivity`，Linux 旧后端双双 404 ⇒ Linux 面板长期残缺。
- **修法（已实施）**：Linux 停 `goat-quota-http.service`，改 `goat-quota-tunnel.service`（`ssh -N -L 127.0.0.1:8790:127.0.0.1:8790 27063@100.84.67.49`），两端共用一个后端，quota/cache/connectivity 全 200。代价：Windows 关机时 Linux 面板空。
- Linux 的三个实例：**3080** 是用户手动 `dsh web`（他实际在浏览器看的）、3081 是 `systemctl --user dsh-web.service`、3082 是 `dsh-tunnel.service`（→Windows 3080）。改代码后 3080 也要重启，不然他看不到。
