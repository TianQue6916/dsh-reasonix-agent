## 图分布（`LNotes/LNotes 8..11.pdf`，page 612×792pt）
- **lec08**（7 页, drawings 154，全部零宽零高 132）：**唯一"图"是 ASCII 下划线排版** —— p3 B3–B7 `[87.7,171.2,247.2,220.4]`（d0–d3 层结构）、B9–B13 `[87.7,291.7,408.6,352.9]`（Q=[0..9]→树）。clip 内 `drawings=0`，只能靠 text block 定位。p1 是表格（`cluster` C0 72,633.4–492.1,726.6 + 右栏至 x=567.4），md 已 Markdown 重建。
- **lec09**（5 页）：只有 p1 三张 graph 图 C0/C1/C2 = `[94.7,476,162.7,544]` / `[236.4,...]` / `[378.2,...,531.2,544]`，标签 y0=468.4。**p4 是 BFS 页但原书无示意图**（配图在 slides）。p2 的 Ex1/2/3 邻接表是纯文本矩阵（drawings=1 零宽）。
- **lec10**（5 页）：p1 G1/G2 = `[93.3,501.7,237.8,586.7]`/`[331.4,...,475.9,586.7]`，标签 y0=488.4；**p3 在 Full-BFS/DFS 处重印同一对图**，标签 y0=324.5，G1 被拆成 **3 簇**（C0 229.9–255.4 / C1 110.8–195.9 / C2）。
- **lec11**（5 页）：p1 带权 G1/G2 = `[93.3,632.1,297.4,717.1]`/`[331.4,...,535.5,717.1]`，标签 y0=618.8，28 个权值标注全是 text span；p2 SSSP 表 `[89.6,619.6,490.3,726.8]`。**G1 与 G2 唯一差别是 b–c 边（权 −1）方向相反**：G1 c→b 构成负权环 b→f→g→c→b（−4+2+1−1=−2），G2 b→c 为 DAG。

## 方法（可复用）
1. clip = 「图标题行 text block 的 y0」∪「区域内全部 `get_drawings()` bbox 并集」。**不要用单簇 bbox**（lec10 p3 把一张图拆 3 簇）。
2. 有效图阈值 `w>=20 ∧ h>=10`，否则字形轮廓/页边 8.8pt 方块成假图。
3. `cluster_drawings` 平台区间 lec11 p2 为 [3,12]（t≤2 表格碎裂），其余页 [1,12]；t=3/6/8 的 bbox 左缘差 **0.0pt**（无 LN18 那种 8.9pt 残框）。
4. `get_pixmap(dpi=300, clip=)` 左界要外扩到 ~79pt 才能吸收 PDF 左栏行号（1–5 在 x≈81.6–84.0）。
5. 审计脚本 `_wb/lald/ln_fig_w3/audit.py`：检查 straddling / near_out(12pt) / 跨边界 text span，本四份 11/11 全 0。
