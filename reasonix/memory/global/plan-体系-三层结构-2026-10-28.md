## 三层结构（2026-10-28 定稿）

```
~/.dsh/
├── PLAN.md                     # 全局：铁律 + relay + 当前目标 + 任务索引 + 已知未决（~6 KB）
├── PLAN.d/                     # 任务级：一个任务一个目录
│   ├── INDEX.md                #   总索引（导航用）
│   ├── translate/              #   {PLAN.md = 计划列表, archive.md = 原始档案 verbatim}
│   ├── rules-tools/
│   ├── machine-env/
│   ├── dsh-client-icon/
│   ├── dsh-file-write/
│   ├── dsh-remote/
│   └── dsh-roadmap/
└── plans/<session-id>.md       # 会话级：plan-anchor 自动建、每步注入（≤30 行）
```

层级职责不重叠：
- **会话级** = 「我这个会话现在要干什么」，短、活、每步重注入。
- **任务级** = 「这条任务线的全部历史与结论」，长、静态、按需 read。
- **全局 PLAN.md** = 铁律 + 导航 + 跨任务待办，不承载具体任务内容。

## 目录内的两个文件（不要合并）

- `PLAN.md`：计划列表，`[x]` 已完成 / `[ ]` 待办 / `[~]` 无明确状态；末尾有「档案目录」表（archive.md 行号 → 标题）。
- `archive.md`：原始内容 **verbatim，一个字不改**。切分按行号搬移，验证方式：各 archive 字节和 + keep 段 + 丢弃的容器标题 == 原文总行数。

## 为什么拆（问题陈述）

原 `PLAN.md` 325,818 B / 2721 行，其中 **`## 进行中` 一段独占 1837 行 / 251,644 B** —— 把 87 KB「还在跑的翻译工程」和 100 KB「早已修完的 D 盘写入排查」塞在同一段里。用户原话：「plam 里面怎么多个会话混合了? 分开」。

`## 进行中` 这个容器标题本身是混合的根源，已删除。

## 二次切分修正的错位

原 `## ` 段落边界会把相邻块带错，任务级切分后归位：
- `★ 已完成：/compress 全局化`、`★ 子 agent 并发上限调到 32` → rules-tools
- `★ 渲染崩溃 / thinking-guard / 待办清单`、`★ 待办总账` → dsh-roadmap
- 结果：`dsh-remote/archive.md` 从 23.8 KB **降到 3.0 KB**（那 20 KB 本来就不是远程化的事）。
