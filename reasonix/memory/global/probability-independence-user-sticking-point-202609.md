# 概率论：independence 的直觉卡点（2026-09-20）

来源：`DS_理论中独立理解.md`（09-20）：「在理论中独立究竟如何理解」→ 澄清后说明「我指的是**概率论**中的独立」→ 要求「如何用图画出来，就是用维恩图」。同批还有 `DS_六门非前十总分前十概率.md`（09-24，54 人班里「六门都不前十但总分前十」的概率，他反复要求"根据前提算，不得估算"）。

## 教学判断
- 他的默认提问方式是把"定义"当成需要被**构造出来**的东西：先问 独立 到底在说什么，再要图（几何/集合直观），最后才接受公式。直接甩 `P(A∩B)=P(A)P(B)` 会被当成逃避。
- 对 independence 有效的路径（按他的偏好排序）：
  1. 先在同一 sample space 上画 **Ω 的矩形化**：把 Ω 分解成 A / Aᶜ × B / Bᶜ 四格，独立性 = 四格面积成比例（等价于 B 在 A 与 Aᶜ 中的占比相同）
  2. 再讲 Ω 的**乘积结构**：独立 ⟺ 联合分布 = 边缘分布之积 ⟺ Ω 可写成 Ω₁×Ω₂ 上的乘积测度（要到 6.431 的 product space 才顺）
  3. 最后点破维恩图的天花板：维恩图只能画"集合关系"，画不出"测度是否相乘"——独立是**测度性质**，不是集合性质；这正好解释他为什么会觉得图对不上
- 反例要留着：同一 Ω 上两事件不独立、以及「两两独立但整体不独立」（经典构造），后者是 6.431 的必修陷阱。

**How to apply:** 讲概率论时一律先给构造/直观（维恩图或矩形化），再给公式，最后给反例；他会在 500 词级的追问里持续校准定义边界。
