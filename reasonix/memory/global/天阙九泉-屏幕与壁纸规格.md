## 屏幕（2026-11-19 实测）

`Get-CimInstance Win32_VideoController` + `root\wmi WmiMonitorID`：

| 项 | 值 |
|---|---|
| 内屏（主） | **2560×1600，16:10，240 Hz**，面板 BOE **NE160QDM-NZL**（16 英寸） |
| 副屏 | 1920×1200，16:10（USB Mobile Monitor 便携屏） |
| 虚拟显示适配器 | ExtensoDesk / GameViewer / Parsec |
| GPU | Intel UHD Graphics（内屏）+ NVIDIA RTX 5070 Laptop GPU |

**壁纸比例 = 16:10，不是 16:9。** 这一点之前反复踩坑：16:9 的图在这块屏上要么上下被裁、要么留黑边。
输出尺寸惯例 **5120×3200**（2×），源图不够时按 `min(5120, 原宽)` 输出、绝不上采样。
