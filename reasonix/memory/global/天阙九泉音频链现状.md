## 机器
MECHREVO KUANGSHI Series / RPL_HX / BIOS N.1.21MRO16（2025-07-24），2.0 双扬声器（channel mask 0x3，无独立低音）。

## 默认播放 endpoint
`{0.0.0.00000000}.{f6efbfd6-f7de-4e7d-a8db-088f89875e09}` = 扬声器 (Senary Audio)，三个 role 一致，state=1。未误走虚拟设备。

## 音频格式
DeviceFormat blob 的 WAVEFORMATEX **从偏移 8 开始**（前 8 字节是头）：
tag@8=0xFFFE, ch@10, rate@12, blockAlign@20, bits@22(32 容器), validBits@26(24), mask@28(0x3)。
⇒ 24-bit 有效位 / 32-bit 容器 / 48000 Hz / 2ch。

## 效果栈
Nahimic APO 4（A-Volute 4.11.6.2）+ Senary Audio Effects（SenaryAPO 1.23.0.0）双栈；常驻进程 Nahimic3 / NahimicAPO4Volume / NahimicService / NahimicSvc32 / NahimicSvc64 / SenaryAudioApp；`C:\Windows\System32\NahimicAPO4.dll`(7.1MB)；配置 `C:\ProgramData\A-Volute\A-Volute.Nahimic\`。

## 2026-11-18 已执行的动作
对三个 endpoint 写入 `PKEY_AudioEndpoint_Disable_SysFx`（`{1da5d803-d492-4edd-8c23-e0c0ffee7f0e},5`）= 1，并重启 Audiosrv：
- `{f6efbfd6-...}` Senary Audio 内置扬声器
- `{4045b7ff-1110-428a-ae79-f0d760d1653f}` HUAWEI FreeBuds Pro 2+（A2DP，MAC 98:2F:F8:C7:01:E3）
- `{3a2f7a3f-353e-47be-9fb8-266b0f360fee}` Senary Audio 3.5mm 耳机（未插入，预设）
用户已在 Nahimic 应用里手动关闭全局效果。

**写入方法（重要）**：`MMDevices\Audio\Render\{guid}\Properties` 的 ACL 只给 `BUILTIN\Administrators` 的 `SetValue`（无 KEY_CREATE_SUB_KEY），因此：
- `Set-ItemProperty` / `Get-Acl` 后 OpenSubKey(writable) / `RegOpenKeyEx(KEY_SET_VALUE)` 全失败（"Requested registry access is not allowed" / rc=2）
- 唯一可行：`[Microsoft.Win32.RegistryKey]::OpenBaseKey(LocalMachine, Registry64).OpenSubKey($sub, [RegistryKeyPermissionCheck]::ReadWriteSubTree, [RegistryRights]::SetValue)`
- 脚本：`C:\Users\27063\.dsh\.learn\run\audio-optimize.ps1`（需 `Start-Process -Verb RunAs` 提权，走 `$env:windir\System32\WindowsPowerShell\v1.0\powershell.exe` 保证 64 位）

**回滚**：`C:\Users\27063\.dsh\.learn\run\endpoint-<guid>.reg`，或把该值删掉即恢复增强。

## 剩余瓶颈
- 蓝牙 A2DP 端点格式 = 16bit/48kHz（Windows 原生 SBC/AAC 上限，要 LDAC 需第三方 A2DP driver）
- HFP 端点 `{ff7d8cf8-41d6-45f9-a165-76234d3a78a4}` = **16000Hz 1ch**（电话音质，开麦克风时会被抢占）
- Equalizer APO 未安装（`C:\Program Files\EqualizerAPO` 不存在）
- `audiodg.exe` 是 PPL 进程，模块枚举被拒，无法用模块列表证明 APO 已卸载
