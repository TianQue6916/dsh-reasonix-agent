## 审出的 11 处错误（v3 已修）

优先看这几条**图内文字**的错，它们是上一版漏检的主因：

1. **图 2 图内标题「三个数都合法」+ x 轴「三种合法的 SPNE tie-break」** —— 硬错。0 是 (L,A) 路径的收益，但玩家 0 在根上会偏离到 R 拿 3，所以 (L,A) 不是 SPNE，0 不属于任何均衡收益。均衡收益只有 10（玩家 1 倒向 B）与 3（倒向 A 时玩家 0 改走 R）。
2. **图 3 图内标题「按 i 或 j 递增会读到未定义格」** —— 错一半。j 递增本身合法（算 (i,j) 时 (i,j−1) 同行已算完），**只有 i 递增会缺依赖**；正确安全顺序是「L 递增」或「i 递减 + j 递增」。md §7 图注与表格重复了同一错误。
3. **图 1 图内「任一分支总和恒为 10」** —— 歧义，易读成叶子相加（3+8=11）。正确说法：每个终止节点上 $u_0+u_1=10$。

其余：
4. 标题「三个常见误述」/ §1「三处命题」/ 目录 / §10「三处错误汇总」四处计数互相打架（表里实际 4 条）。
5. 定义 2.1 称「五元组」却只列 4 个分量 → 补 $(u_i)_{i\in N}$。
6. §3 证明用 `$V_i(h,a)$` 但从未定义 → 补 `V_i(h,a) := V_i((h,a))`。
7. §5 图 2 图注把 0 说成「同一个 SPNE 集合」内的收益 → 改写。
8. §5 表格 0 行加注「非均衡」。
9. §11 实测输出块缺 `[2]` 段（真实脚本输出是 [1][2][3][4]），而 §7 引用「脚本实测 [2]」→ 按真实输出逐字补回。

## 工具坑（这次踩了两次）

**heredoc 会把 `\\` 折成 `\`** ⇒ python 里写的 `\\n` 变成真换行，`assert old in s` 未命中，且**assert 在写盘前触发 ⇒ 整批修改全部丢弃**（1-6 处白改，第二轮才发现）。规避：
- 含反斜杠的字串用 `BS = chr(92)` 拼接，不要写字面反斜杠；
- 定位优先「行级 + startswith/包含子串」，不要拿整段长文本当 old_str；
- 每次落盘前打印命中清单，失败立刻可见。
