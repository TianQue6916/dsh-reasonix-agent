## 数学/事实层的教训（这类错比格式错严重一个量级）

1. **把独立条件捆成一句 = 必错**。v1 写「值唯一 —— 仅当无 tie」，实际是四个独立命题：值唯一（前提零和）/ 策略存在（前提有限+完美信息）/ 策略唯一（前提无 tie）/ tie 后果（前提非零和+tie）。**纠正方式：一条定理里有几个前提就拆几条命题**。
2. **别把两个统计混着写**。v1 把「奇数 n 先手拿不到一半（28/300 次）」误记成「值随 tie-break 变化 28 次」，而后者实测是 **0 次**。⇒ 每写一个数字，回到脚本输出里逐字核对。
3. **优先级/方向别写反**。von Neumann 1928 是一般零和（允许混合策略）；「完美信息下纯策略足够」是 Zermelo 1913 / Kuhn 1953。v1 把前者说成后者的特化，反了。
4. **定义要能被反例检验**。v1 的子博弈判据写成「祖先只有一个行动」，既非充分也非必要；正解是「信息集单点」（完美信息下自动成立）。⇒ 写完定义立刻问：构造一个反例打死它。

## matplotlib 出图的工程坑（本机）

- 字体：`Microsoft YaHei` 可用（`Noto Sans CJK SC` / `Source Han Sans SC` 都没有）。`svg.fonttype='path'` 保证 SVG 里中文不丢。
- **缺字形会在图上变方块**：本机 YaHei 没有 `⇒`(U+21D2)，`plt.savefig` 会 Warning `Glyph 8658 missing`。⇒ 出图前把 `⇒ ⇐ √ ≈` 之类换成 `→ ←`，或先 grep 替换。
- **`re.sub` 的 repl 参数会把 `\n` 当转义**：用 `re.sub(pattern, new_code, s)` 塞 python 源码会破坏其中的 `"...\n..."` 字面量。改用 `s[:m.start()] + text + s[m.end():]` 切片拼接。
- **bash heredoc 里 `\\` 会被压成 `\`**（实测 Git Bash）：于是 python 源码里的 `\\forall` 变成 `\forall`，被 python 解释成 `\f`(formfeed)+`orall`，字符串匹配失败。⇒ 凡要匹配/写入 LaTeX 反斜杠，**不要写字面量**，改用行级处理（`t.startswith("$$")` 后切片）或 `chr(92)` 拼接。
