## 三处对第一轮的修正（重要）

1. **离散数学「本体零素材」被强推翻**：他 2026-02~06 以 **6.042《Mathematics for Computer Science》为主纲、做题驱动**过了一遍本体（命题逻辑 / 一阶逻辑 / 集合 / 关系 / 偏序 / 数论 / 组合入口 / 图论本体），多数 **L1**、少数 **L2**；**只有格（lattice）与布尔代数仍为零**。第一轮的「零素材」是因为只读到 3 个图论应用侧页面。
2. **算法 counting/radix sort 实为 L0 不是 L1**；且 problem session 5 曾**否认需要 priority queue**，与第一轮「已掌握 Dijkstra 弹出机制」矛盾 → 该项应降级。

## 新的结构性发现

- **双轨口径**：他视 6.042 为唯一真理源，把屈婉玲《离散数学 第2版》当「考试方言」，反复用「6.042 没有这个说法」裁判教材术语（桥、Huffman、Hasse、商集、偏序的界），并要求从英文重新翻译。**风险**：这条判据会把「没学过」误判成「不存在」。
- **自造 SSSP**（待验证，importance 5）：他用 BFS 分层 + V−1 步 + 每条边只遍历一次 自造最短路算法，AI **两次自认反例不足**，最终判为 DAG 松弛的推广，前提是负权边不得从步数多的点指回步数少的点（DS_算法导论.md L91269–L91833）。这是他迄今最强的独立构造。
- **Johnson 势**：换三个电场/海拔类比都不收，只接受不变量「新代价 = 原代价 + h(A) − h(B)」（L98647–L99672）。
- **高数**：「定积分就是不定积分加个上下限」（原话「没有变量你怎么代入的上下限？傻逼」）——N-L 公式与 Riemann 和定义的顺序颠倒；二重积分换序被当成要变号（把有向面积元外积反交换律套到无向 Riemann 积分上）。
- **Python 语言本体补上了**：类与 self、super()/MRO（连追五轮自答「原来是递归思想」）、源文件 GBK/ANSI 与 `open()` encoding、`socketserver.UnixStreamServer` 是平台问题不是缺包。
