- **小电脑（Ubuntu 24.04.5 / Windows 双系统，主机名 TianQue）**：系统盘 **INTEL SSDPEKKF010T8L**（TLC，S/N `PHHP937609F91P0D`，FW `L15P`）。
- **主力机（天阙九泉 / 机械革命 KUANGSHI）**：原装盘 **KINGSTON OM8TAP41024K1-A00**（QLC）。
