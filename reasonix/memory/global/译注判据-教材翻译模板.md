## 八条判据（每条都是「有 X 没有 Y 就不合格」）
1. **消失测试**：写不出「抽掉后哪个结论失效 / 退化成什么方法 / 误差或复杂度变成多少」→ 不合格。
2. **落点**：§号 / 式号 / 课程节号 / 文献题名至少一个可点开；没有就写 `[未定位]`，禁「详见相关资料」。
3. **锚定本页**：必须挂在**本页已出现**的公式/句子/脚注上，说明「它为什么在这里」；要引入本页之外的内容必须显式降级为「此处只作坐标，第 N 章再回来读」。
4. **失败模式具体**：给得出「否则你会看到什么」。黑名单：`很重要` / `广泛用于` / `是基础` / `值得注意` / `非常关键`。
5. **量的方向感**：至少一个真实的方向性判断（更保守、大一个数量级、O(n!)→O(n²)）；禁「显著提升」。
6. **不越级**：挂 6.042J / CSAPP / 6.006 / Strang / Thomson 已有节点；挂不上写 `[待建桥]`；禁群论/环论/拓扑/非标准分析。
7. **篇幅 200–400 字，且至少含一个公式或一个数**。
8. **作者可分辨**：一律 `<span style="color:#1e8449;">**[译注]** …</span>`，**禁用 `[remark]`**（与 Boyd 原书 Remark 撞色会让读者分不清作者）。

## 抽查命令
`grep -c '\[译注\]'` 数条数；`grep -c '\*\*\[remark\]\*\*'` 必须为 0；然后人工只读每条「消失测试」那一句，写不出「退化成什么」的直接返工。
