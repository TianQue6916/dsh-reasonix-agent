## 判定方法（可复用）
- 超分产物 = 与原片同目录的 `<原名>.realcugan.mkv`（3x，480p 源）或 `.realesrgan.mkv`（4x，720p 源）；`.1`/`.2` 后缀是重试副本，0 字节或几百字节的是失败残留。
- 分辨率探测：写纯 Python 容器解析上传到远端跑，`mp4probe2.py`（moov/trak/mdia/minf/stbl/stsd 取 avc1 width/height）＋ fallback EBML（`PixelWidth` 0xB0 / 0xBA）。注意 `avc1` 后 width 偏移是 **+32**（不是 +24）。全量 486 文件约 40 秒。
- 产出：`~/.dsh/.learn/run/{report.md, todo_final.csv, res_all.tsv}`（本机 Windows）。
