## 文本层符号损坏（pdftotext/fitz plain 抽取，累计表）
- **`!` 是「三义符号」**（p161-180 块新发现，推翻了前两块「`!` 一律= `→`」的判据）：
  ① 规则行 `#!` 或单独 `!` = `→`；② `Fn!1`、`1! 5` = 减号 `-`；③ `7 ! 3 ! 3` = 乘号 `·`。
  ⇒ 必须靠上下文 + `pdftoppm -r 130` 逐处定夺。
- **`≤` 丢成空白**（`0  k  n` = `0 ≤ k ≤ n`）；`j` = `|`（`3 j s` = `3 | s`）；`¤` = `≠`；
  `WD` = `:=`、`WWD` = `::=`；`C` = `+`、`D` = `=`；`#` = `-`；`2`/`8`/`9` = `∈`/`∀`/`∃`；
  `Œ…ç` = `⟨…⟩`；`d…e` = `⌈…⌉`；圆括号丢成 `.` 与 `/`；上标与下标整体丢失；`±` = 双空格；`\overline{}` 100% 丢失。
