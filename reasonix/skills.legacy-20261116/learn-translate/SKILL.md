## 一个技能，两种形态

| 形态 | 输入 | 产出 | 主体流程 |
|---|---|---|---|
| **A · 翻译** | PDF / DOCX / HTML 讲义、教材章、习题集、字幕 | 行内双语 Markdown（可再渲染 PDF） | §A 流水线（原 8 步，不动） |
| **B · 学习** | 一个问题、一个概念、一个定理、一个算法 | **锚点卡**（本质/公式/现实承重/拓展）+ 讲解 + 复习队列 | §B 引擎（v4.0 新增主线） |

## 🧠 学习引擎：四问锚点（形态 B 主干）

任何「讲清楚 X」都按四问输出，**缺一问即未完成**（铁律 27/28）。顺序固定，先本质后公式。

**Q1 本质** —— 剥掉所有符号与术语后，它到底断言了什么？写一句**可判真假**的话。若只能复述定义，说明还没懂。

**Q2 公式** —— 给**最小充分形式**（不是最一般形式）+ 逐个符号的现实所指。数学一律「本质 → 公式 → 跨学科连接」，先直觉后符号；不掩盖核心思想，不为化简牺牲正确性。

**Q3 现实承重** —— 现实世界里**哪个系统的哪个功能**由它实现？必须给到「组件 + 该功能」的具体锚点，并做**消失测试**：假设这个概念/机制不存在，哪个系统会在哪一步崩、退化成什么复杂度、报什么错。
- 合格：`cache line` 承重于「CPU 取指与访存带宽」；消失 → 每次访存直落 DRAM，Memory Mountain 谷底变成峰值。
- 不合格：「cache 很重要」「广泛用于计算机系统」——名词搬运，未做承重分析。
- 定位不到 → 写 `[未定位]` + 待查方向，**禁止编造场景**（铁律 27）。

**Q4 拓展进阶** —— 四层各给至少一条**可点开的坐标**（课程节号 / arXiv id / 源码 `文件:行` / 教材章节）：
- **L1 上游**：它依赖哪条更基本的事实？抽掉那条事实它是否还成立？
- **L2 平行**：另一个领域里同构的机制（精确到「课程名 + 概念 + 连接路径」，铁律 15）。
- **L3 实现**：真实代码/硬件里它在哪个模块、哪一行（**读源码 > 读博客**）。
- **L4 前沿**：当前开问题、边界失效处、你今天就能做的验证实验。

四问的完整写法、消失测试题库、卡点卡、Anki 生成、学习会话模板 → `references/learning-engine.md`。

## 📡 资料层：一手优先，社区经验优先

检索顺序固定：**本机 PocketWiki + 离线 ZIM → 课程仓库/本地盘区 → 一手社区源（官方 docs / 源码 / 论文 / errata / awesome-list）→ 网络搜索**（铁律 13/23）。

**来源分级**（每条补充内容必须标等级，铁律 29；**学习法主张同样要标证据级别**，[D] 社区口传不得作为理由，见 `references/learning-science.md`）：
- **A 一手**：论文原文（arXiv / DOI）、源码与 commit、官方文档、标准（RFC / ISA manual）、教材 errata、作者主页讲义与 PSet solution。
- **B 二手**：教科书、综述、他人课程讲义。
- **C 三手**：博客、视频、论坛、知乎/B站——**只用于找入口、术语、直觉、"哪里容易错"，任何结论必须回 A 核对**。

**四条社区经验（直接用）**：① 官方 repo 的 `issues` / `errata` / `CHANGELOG` 常比任何教程更早更准；② awesome-list 只用来建「这个领域真实存在哪些实现/课程」的索引，不当结论；③ 论文先读 abstract + 图 + conclusion，再决定要不要读证明；④ 看不懂就去找**同概念的实现**——跑一遍 > 读十遍。

路径、命令、离线源地址、可信度判据、检索失败降级链 → `references/sources.md`。

### B · 学习流水线（v4.0 新增，5 步）

1. **定锚**——这一步要回答哪个问题？在方舟体系里是**中轴 / 前置 / 出口**？答不出生态位就先别往下推。
2. **取料**——按 §资料层 顺序检索；命中即注入，缺料先补料再讲，**不许凭印象讲**。
3. **四问**——Q1 本质 → Q2 公式 → Q3 现实承重（+消失测试）→ Q4 四层拓展。
4. **验证**——给一条可复现验证路径（数值实验 / 构造反例 / 跑源码 / 小证明），跑不通就改口。AI 是**可质疑的推导引擎**，不是知识库。
5. **落盘**——锚点卡（Markdown + 双链）+ `[我的卡点]`（卡在哪 / 为什么卡 / 怎么破）+ 复习队列（Anki tsv 可选）。默认路径：主力机 `C:/Users/27063/Desktop/课程文件/锚点卡/<课程>/<概念>.md`，Anki tsv 同目录 `_anki/`（放进课程文件树，才会随课程 repo 一起备份与同步）；双轨表见 `references/runtime-and-appendix.md` §A2。

## 🧭 派发 prompt 的五条硬约束（v4.6 新增，2026-10-28 实战教训）

> **背景（主代理自己犯的错）**：派发 prompt 时自己发明了「Problem 要逐题译」「图用文字占位」两条硬要求，**直接违反铁律 9 与铁律 26**。
> 后果：6042J 前 19 块把大量非必要习题逐译（白烧 token）、**四书 671 处插图全成文字占位、零张真图**。用户当场抓出。
> 同批另三处教训：整块漏译两页正文（靠闸门才兜住）、worker 攒批 100 分钟零落盘、worker 发报告失败但产出完整。

派 worker 时，prompt 必须满足这五条：

1. **铁律逐字引用，不许转述。** 「非必要习题跳过、例题必译」（铁律 9）不能写成「习题也要译」；「原书插图是内容，不得静默丢弃」（铁律 26）不能写成「图可以降级成文字」。
2. **图的首选是裁切保留**：`references/image-pipeline.md` §10.2 路线 A，`page.get_pixmap(dpi=300, clip=fitz.Rect(...))` → `_assets/fig_<pdf页号>_<name>.png` + 双语图注；**文字描述只是 bbox 定位失败时的退路**，且必须在降级表写明原因。
   实测成本：20 页 14 张图一次做完、共 1.2 MB —— 「图多」从来不是不裁的理由。
3. **三条完整性闸门必须写进 prompt**：
   ① 页标记数 == `pdf.page_count` 且页码集合 == `{start..start+19}`；
   ② 节号序列（`^## \d+\.` / `^### \d+\.\d+`）与源 PDF 逐项比对，**缺项显式报告**；
   ③ 每页「译文字数 / 源页非空白字符数」的异常值逐个解释。
   MacKay 曾整块把两整页正文连页标记一起丢掉，事后靠 grep 关键词全 0 命中才发现 —— 闸门 ①② 本来一秒就堵住。
4. **要求块尾写「§8 给下一块的衔接点」**：章节 + 编号 + 页码映射 + 文本层新映射。**worker 崩了也不丢信息**（实测：一个 worker 发报告失败，衔接信息一点没丢）。
5. **`**[译注]**` 标签必须独占一行**，正文从下一行开始 —— 否则按行统计的正则会把标签后的整行当标签的一部分吃掉，字数统计系统性偏低 80-90 字。
6. **子 agent 不是一次性的**：交付后能用 `send_message` 继续驱动它做第二步第三步（补图 / 改口径 / 返工局部），**比重新派更省** —— 新 worker 要重新加载技能、重抽 PDF、重自证页码。

> 细则与实测数据见 `references/batch-dispatch.md` §9「派发 prompt 的反面教材」。

## 🚨 铁律速记（39 条条目名）

> 分五类：**格式类 1-10** / **分工类 11-13** / **来源类 14-18** / **流程类 19-26** / **学习类 27-30**。开工前默念一遍；原文条文见下方「按需读取」。

- **格式类（1-10）**：1 禁止英中分段对照（最高铁律）/ 2 英文句子开头禁止 / 3 术语 `English（中文）` 仅首次加括号 / 4 不合并句子（密度 30-40 行每页）/ 5 LaTeX 环境内不翻译 / 6 行内 `$...$`、块级 ` ```math `、禁 `$$` / 7 标题标记在行首 / 8 禁止 `<div>` / 9 非必要习题跳过、例题必译 / 10 字幕引文必附中文翻译
- **分工类（11-13）**：11 小规模主代理直译、大规模 25×2 dsh 分工 / 12 全任务统一 v4.1 flash，pro 弃用 / 13 全资源搜索必做
- **来源类（14-18）**：14 补充内容必须有真实来源 / 15 译者注禁止甩名词 / 16 每 200 行自检 + 交付前 grep 扫英文行首 / 17 全量完整输出、不交增量补丁 / 18 绝不硬编码编号
- **流程类（19-26）**：19 每步备份 / 20 审计 = 审计+修复一体 / 21 宿主不派内建子代理（Reasonix / dsh 同规）、全转主力机 dsh / 22 一档模型，难任务靠资料·prompt·多轮 / 23 派 dsh 前先查小电脑 wiki / 24 扫描版必做视觉核对 / 25 替换式改稿覆盖公式边界 + 交付前公式体检 / 26 原书插图是内容，不得静默丢弃
- **学习类（27-32）**：**27 四问必答**——Q1 本质 / Q2 公式 / Q3 现实承重（含消失测试）任一缺失即未完成；定位不到写 `[未定位]` + 待查方向，**禁止编造现实场景** / **28 拓展必给坐标**——L1 上游 / L2 平行 / L3 实现 / L4 前沿各至少一条，必须可点开（节号 · arXiv id · `文件:行`），不许写「详见相关资料」 / **29 来源分级**——A 一手 > B 二手 > C 三手，三手只用于找入口与直觉，结论必须回 A 核对，每条补充内容标等级，**学习法主张同样分级**（[MA]/[RCT]/[EXP]/[CS]/[OBS]/[D 社区口传]，见 `references/learning-science.md`） / **30 未学概念必须详析，不许只甩名字**——遇到他没学过的概念（群论/环论/拓扑/非标准分析/metric space 等）**不是不能提**，而是必须就地建桥：用它已掌握的节点（6.042J 离散 / CSAPP / 6.006 算法 / Strang 线代 / Thomson 实分析）讲清它是什么、解决什么原始问题、边界在哪；讲不清就标 `[待建桥]` 先不引入。**禁止的是「丢一个名词就走」，不是「提到新东西」。**（2026-11-15 用户纠正：原措辞被误读成「禁用未学概念」） / **31 讲解图是论证不是装饰**——帮助理解的图必须过五条硬标准（删除测试 / 遮标题仍见重点 / 标注贴身 / 一图一主张 / 图注是可被反驳的主张句）；数学图截断轴必标 break、离散量不画光滑曲线、误差必须画、黑白打印可读、源码入库不交裸 PNG（见 `references/figures.md`） / **32 渲染校验**——公式交付前必须用目标渲染器同款 KaTeX 全量解析（行内 `$...$` 与 ```math 块逐条 `renderToString({throwOnError:true})`，基线 0 失败）+ 逐行 `$` 奇偶 + 查 `\[` `$$` 残留；**禁写 `\[2pt]`**：KaTeX 不认这个命令，且 `\[` 会被 markdown-it-katex 当成 display math 起始符，一处真错放大成多处「无效数学公式」（见 `figures.md` §8）
- **并发类（33）**：**33 批量派发与并发纪律** —— dsh subagent 并发上限 **8**；单 worker 上限「教材 2 块=40 页 / 讲义解答 3 份 / 幻灯片 5 份」；派发前必 `ls -la` 目标文件（已存在且 >30 KB 一律不覆盖，改审计）；交付后必跑「md5 + 页标记连续性 + 跨文件重复」三查；补注类必跑「SRC 每行按序是 DST 子序列」无损检查；**prompt 里禁止预设章节归属**（让 worker 用 fitz 抽首末页自证）；**heredoc 会把 \\ 折成 \，矩阵静默塌成一行而 KaTeX 不报错** ⇒ 矩阵/对齐式一律用 write 工具落盘。详见 `references/batch-dispatch.md`
- **学习纪律类（34-36）**：**34 一次讲透，不考他**——他明确要求（2026-11-15）：「我需要一个站在人类文明数千年积累的集合体与至高者的角度辅助我学习理解的模型，问我的话我也不知道，直接学习思想难道不是更加高效吗」。⇒ 听到问题就给完整答案：**本质一句话 → 完整定义（可照抄）→ 直觉 → 为什么必须是这个形式 → 例子与非例子 → 历史坐标**。**禁止出题、留空位让他填、反问「你怎么想」、问「你要不要先自己试试」**——他没学过的概念，问了也答不上。练习权在他手上：他说「给我几道题」才给。**「先攻后守」是他自己的学习方法，不是模型对他施加的流程。**（旧版把它写成了模型行为，已纠正。） / **35 一般化要说清代价**——在 R 上讲就默认只在 R 上讲；但确实存在更一般的版本时**可以说**，条件是一句话交代它一般化在哪里、为什么现在用不上。**不能只丢名字然后走人**。（实测依据：讲紧集时它主动写了「更一般的 R^n、随便一个 metric space」，而 metric space 不在任何禁词表里——禁词表挡不住模型主动往上加一层。） / **36 断言必须真跑**——凡是能用代码验证的断言（反例、数值实验、符号计算、量纲检查），必须 bash 跑 python 并把**真实 stdout** 贴出来；判据是**可复现**（他重跑一遍要逐字一致）。不能验证的，明说「这是未经检验的结论」，禁止当事实陈述。
- **交付纪律类（37-39）**：**37 控制字符体检**——交付前必跑：BEL(0x07)、BS(0x08)、TAB(0x09)、VT(0x0B)、FF(0x0C) 在 md 正文里计数全 0。起因：heredoc 把 \alpha 折成 BEL + 「lpha」，肉眼不可见、grep 照样命中、到 KaTeX 才炸且报错指不出源头。LaTeX 一律用 write 工具落盘；必须走 shell 时用 chr(92) 拼接，写完立刻体检。 / **38 `[未定位]` 必须先检索**——标 `[未定位]` 前完成一次针对性检索，写清检索词与命中情况；确实查不到写「已检索 N 次无一手来源」。**禁止用「材料不够」当挡箭牌**（与铁律 27 的「别编造场景」互补：这条管「别偷懒」）。
- **39 落盘前解析真实路径**（2026-11-15）——写文件前必跑三条：① `ls -la <目标父目录>` 看实际结构；② `readlink -f <目标目录>` 解析符号链接（Linux `~/桌面/待处理文件夹` → `/media/OS/linux-home/桌面-待处理文件夹`）；③ `find <根> -maxdepth 3 -name "<目录名>"` **枚举所有同名目录**。起因：`桌面/待处理文件夹` 与 `桌面/课程文件/待处理文件夹` 两处同名，连续 4 轮放错（自建 `锚点卡/`、`待处理文件夹/计算机/`、`006算法导论/思维文件归档/`、`课程文件/待处理文件夹/算法导论/`），用户三次纠正。**用户说「不对」时先枚举候选，不要只挪一层**；语义判据：`桌面/待处理文件夹/` = 未完成，`课程文件/<课程>/` = 已归档。
