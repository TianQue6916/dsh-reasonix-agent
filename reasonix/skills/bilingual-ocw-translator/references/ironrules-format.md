# 第 1 章 🚨 铁律（不可违反）

> 所有 🚨 规则集中于此。**每次开工前默念一遍。** 每条都来自实战教训（prob7sol / Strang 50 页 / PS01 / lec16 / lec18 / lec19 / L12），违反任一铁律的交付视为不合格。
> 铁律分四类：**格式类（1-10）**、**分工类（11-13）**、**来源类（14-18）**、**流程类（19-26）**。历史教训溯源见 HISTORY.md 8.2。

## 格式类铁律

### 铁律 1：禁止英中分段对照（最高铁律）

输出必须是**中文主体 + 英文术语行内嵌入**的单行双语格式。**绝对禁止**「先写完整英文段落、再写中文翻译段落」的对照模式。

```
❌ In a weighted directed graph G = (V, E), the weighted eccentricity ε(u) of a vertex u ∈ V is...
   在带权有向图 G = (V, E) 中，顶点 u ∈ V 的 weighted eccentricity（带权离心率）ε(u)...

✅ 在带权有向图 G = (V, E) 中，vertex（顶点）u ∈ V 的 weighted eccentricity（带权离心率）ε(u) 是其到最远 vertex v 的最短带权距离。
```

**识别方法**：输出中任何一行以英文单词开头、长度超 10 词且后面紧跟一行中文翻译，即违规。正确的输出中**没有完整的英文原句**。

### 铁律 2：英文句子开头禁止

**每句话第一个字必须是中文**，不能以英文单词开句。
`❌ A sequence（序列）就是...` → `✅ 一个 sequence（序列）就是...`

### 铁律 3：术语格式 English（中文），仅首次加括号

格式：**`English term（中文翻译）`**——英文术语先出现，中文翻译括号紧随。同一术语**首次出现**时加括号，**后续出现省略括号**（避免冗余）。
`❌ 用 real numbers（实数）来研究 real numbers（实数）` → `✅ 用 real numbers（实数）来研究实数的性质`

### 铁律 4：不合并句子（逐句翻译）

原文**每一句都对应至少一句中文翻译**，不得将 3-5 句压缩为 1 句。逐句阅读 → 逐句翻译 → 逐句输出。
**密度标准**：每页 30-40 行译文、平均每行 6-7 个中文字——低于此密度即为概括式伪翻译。

### 铁律 5：LaTeX 环境内不翻译

`$...$`、` ```math ` fenced block、`\begin{}...\end{}` 环境内的任何文本（包括 `\text{}` 内的内容）保持英文原样，不做翻译。

### 铁律 6：行内 `$...$`，块级 ` ```math `，禁止 `$$`

- 所有数学公式必须用 LaTeX：`$O(n \log n)$`、`$\delta(s,v)$`、`$x_n$`、`$\{a,b,c\}$`、`$\le$` 等，**不得用文字代替**（`❌ O(|V|³)`）
- **禁止 `$$...$$`**（MarkText 渲染异常）；块级公式用 fenced math block：
  ````markdown
  ```math
  公式
  ```
  ````
- 数集用 `\mathbb{}`（$\mathbb{R}, \mathbb{Q}, \mathbb{Z}, \mathbb{N}$）；变量用斜体（$x, m, n, h$）
- **禁止 Unicode 上下标字符**（₀₁₂₃₄₅₆₇₈₉、⁰¹²³⁴⁵⁶⁷⁸⁹）——内置字体不含 glyph，渲染成黑块；一律用 LaTeX `$x_n$`/`$x^n$`
- 定理陈述独立成命题，证明以 $\square$ 结尾

### 铁律 7：标题标记在行首

`#` `##` `###` `####` 等 heading markers 必须位于行首，前面不能有 `<span>` 或其他 HTML tag，否则 Markdown 解析器不识别为标题。
`✅ ### <span ...>**[problem]**</span> Title` | `❌ <span ...>**[problem]**</span> ### Title`

### 铁律 8：禁止 `<div>`

`<div>` 在 MarkText 中不渲染（显示"空的HTML块"）。用标题层级实现视觉区分，`>` blockquote 虚化次要内容。

### 铁律 9：教材的非必要习题直接跳过，例题必须翻译

- **例题（Examples）必须完整行内双语翻译**——例题是核心教学载体，其描述、推导、结论全部按标准格式翻译
- **教材的非必要习题（Exercises）直接跳过**——不保留原文、不收录进翻译稿。常规练习题与正文核心论证无关，翻译稿中省略（如需练习请读原书；练习时阅读英文原题是必要的学术技能）。仅当习题被正文核心论证直接引用、不翻译会破坏正文可读性时（**必要习题**），才保留英文原题并允许最小翻译
- 被收录的必要习题答案保持英文原文，只有过程性描述可做最小翻译（如"Proof（证明）"标签本身）
- Notes、Theorems/Proofs/Definitions、正文段落**完整行内双语翻译**

### 铁律 10：字幕引文必须附带中文翻译

注中引用视频字幕（🎥 标注的教授原话）时，**每条引文必须附带中文翻译**，禁止只写英文原文。

```
✅ 🎥 *Demaine 强调*："Because we memoize, we'll only solve each subproblem once."（翻译：因为我们做了记忆化，每个子问题只会被求解一次。）
❌ 🎥 *Demaine 强调*："Because we memoize, we'll only solve each subproblem once."
```

- 格式：`🎥 *教授名在视频中[教学动作]*："English original text"（翻译：中文翻译）`；引文较长可改用破折号——即「中文翻译」
- 一条注内多条引文**每条**都要单独翻译；翻译可意译，可在翻译后追加括号解释，但不得以解释替代翻译
- dsh 任务 prompt 必须包含本规则
