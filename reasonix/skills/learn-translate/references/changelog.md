## v4.2（2026-10-22）：补「学习科学的证据分级」——社区经验真正落地

**触发**：用户追问「社区学习经验是否有融入?」。自查结论：**只融了一半**。v4.0/v4.1 融进去的是**检索手法**（issues/errata/CHANGELOG 优先、awesome-list 只当地图、论文三段扫描、`filename:` 检索式、看不懂就找实现），那是"怎么找资料"；而「间隔重复 / 自测 / 费曼 / 卡片盒 / 艾宾浩斯 / Anki SM-2」这些**学习法本身有多少证据**，一条都没标——等于把社区口传当成了理由。

**新增 `references/learning-science.md`（57 行）**：
1. 证据分级记号 **[MA] / [RCT] / [EXP] / [CS] / [OBS] / [D 社区口传]**，借鉴社区 repo `GarethManning/education-agent-skills` 的 `evidence_strength` 字段设计。
2. 九条学习法逐条给「证据级别 + 一手来源 + 本技能的落地决定」：
   - 自测效应 [MA]（Roediger & Karpicke 2006；Rowland 2014：**带反馈 g≈0.73 vs 不带 g≈0.39**）
   - 间隔 [MA]（Cepeda et al. 2006，**254 项研究**，最优间隔随保持期增长）
   - 合意困难 [EXP]（Bjork 1994）
   - 交错练习 [EXP]（数学场景有争议，标"取舍不是定论"）
   - **费曼技巧 [D]**——无一手学术来源，常被误挂到费曼本人；外壳可留，理由必须重挂到 retrieval practice + self-explanation
   - **Zettelkasten [D]→[OBS]**——Luhmann 卡片盒 + Ahrens 书，无对照实验；只能当检索辅助
   - **艾宾浩斯 [CS] 有硬伤**——n=1（他自己）、材料是无意义音节；只借"间隔优于集中"这个已被 [MA] 独立验证的结论
   - **learning styles [MA] 无证据**（Pashler et al. 2008）→ 列为**禁用句式**
   - **SM-2 [D] 工程实践**（Wozniak 1990 硕士论文）→ 当调度工具，不当学习理论
3. 三条硬规矩 + 四处「原来怎么写 / 现在改成」对照 + 待核清单（含"四问本身属工程假设，标 [D]/[待证]"）。

**连带修正**：`learning-engine.md` 的间隔重复段改成「启发式不是定律」并补「必须给反馈」；铁律 29 扩到「学习法主张同样分级」；核心契约 14 同步；快速上手 / 按需读取各加一行入口。

**教训（认知层面，不只是数据）**："社区经验"有两个层次——**检索手法**（工程共识，见效快）与**主张的证据强弱**（能被反例杀死）。只做前者，等于把 C 级内容当成 A 级用，而这正是铁律 29 要防的事。

## 同步纪律（2026-09-30 补）

双机同步器 `~/.reasonix/global-workspace/sync/sync_reasonix.py` 的规则是：**同名不同内容 → 双方都保留（各自主文件不动），对方版本另存 `.conflict.<host>.<hash>.bak`**；**仅一方有 → 向另一方补齐**。后果：

1. **冲突永远不会自动收敛**——两端会长期各留一份主文件（本技能在 Windows `.reasonix` 侧曾冻结在 2026-09-10 的 v3.2，而 Linux / Windows Roaming 侧已到 v3.6，差 937 行）。
2. 🚨 **删除/停用必须在三端同时做**：若只在 Windows 删掉 `SKILL.md`，而 Linux 仍留着，下一次 cron 会「仅一方有 → 补齐」把文件补回来，停用失效。
3. 判断谁新谁旧**不能**看 `revision` / `updated_at` / `mtime`（mtime 是同步落盘时间）；**唯一可靠判据是剥掉 frontmatter 比正文**。
4. 正确做法：**先让三端字节一致**（size 相同即被判定 same，冲突不再产生），再做任何增删。
