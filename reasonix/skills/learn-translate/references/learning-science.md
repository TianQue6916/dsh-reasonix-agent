# 学习科学的证据分级（v4.2.1：数字已核）

> 回答一个问题：**本技能里那些「学习法」到底有没有证据、效应量多大。**
> 检索日期 2026-10-22，来源为 `web_search` 三源（github 存档 / deepseek / wiki）。**凡与本文件冲突，以一手原文为准。**
> ⚠️ 写「待核」不等于没网——`web_search` 随时可用；本机 **curl 打外网不通**（DNS 被注），所以"查证"要指向 `web_search` 或浏览器，不要写"等有网再查"。

## 0. 证据分级

| 记号 | 含义 | 能不能作为「为什么这样做」的理由 |
|---|---|---|
| **[MA]** | meta-analysis / systematic review | 能，优先引用 |
| **[RCT]** | 随机对照实验（含 cluster RCT） | 能，但要看随机化层级 |
| **[EXP]** | 受控认知实验（小样本、实验室条件） | 能，说明外部效度限制 |
| **[CS]** | 经典奠基研究 | 能，注意后续修订 |
| **[OBS]** | 观察 / 应用 / 无对照 | 只能作线索 |
| **[D] 社区口传** | 无一手来源 | **不能**。借外壳可以，理由必须另挂 |

## 1. 条目表（数字已核到具体出处）

| 学习法 | 证据 | 一手来源与数值 | 落地决定 |
|---|---|---|---|
| **retrieval practice** | **[MA]** | Rowland 2014, *Psych. Bulletin* 140(6), DOI `10.1037/a0037559`：testing vs restudy（随机效应）**g = 0.50, 95% CI [0.42, 0.58]**；课堂场景 Yang et al. 2021, *Psych. Bulletin* 147(4):399–435（**222 项研究 / 48,478 名学生**）；Dunlosky et al. 2013 评为 **high utility** | 复习只测「本质一句 + 消失测试」，不给选择题、不重读 |
| **反馈（与自测配套）** | **[MA]（方向确定，具体值勿乱引）** | 带 feedback 的自测优于不带，方向一致；但网上流传的 **0.73 / 0.39 这组数字常见误引**（0.73 亦见于 Hattie 2009 的 feedback 效应量，量纲与定义不同） | 复习**必须给反馈**（对原证、指出错在哪）；**引用具体数值前先读原文**，宁可不写数 |
| **spaced repetition** | **[MA]** | Cepeda et al. 2006（254 项研究）：**最优间隔 ≈ 保持期的 10–20%**，平均效应 **d ≈ 0.42** | D+1/3/7/21 是**默认启发式**（≈10% 保持期）；按月以上目标应拉长到周级 |
| **desirable difficulties** | **[EXP]** | Bjork 1994 | 允许「先攻后守」的卡顿；当场顺畅 ≠ 学会 |
| **interleaving** | **[RCT]（cluster 级）+ 有约束** | Rohrer, Dedrick & Stershic 2014/2015, DOI `10.1037/edu0000001`（**整班随机**，非个体随机）；约束：**题型高度可区分时 blocked 更好**；**新手早期交错会超载工作记忆** | **晚交错、按需交错**：能执行步骤但分不清「何时用哪个」时才交错；内化单一模板时按块练并说明取舍 |
| **Feynman technique** | **[D] 社区口传** | **无一手学术文献**（常被误挂到费曼本人；2026-10-22 检索未找到原始出处） | 外壳可留（讲给外行听），理由重挂 retrieval practice + self-explanation |
| **Zettelkasten / 卡片盒** | **[D]→[OBS]** | Luhmann 卡片盒本身 + Ahrens《How to Take Smart Notes》（B 级，无对照实验） | 双链是**检索与连接辅助**，不是记忆法 |
| **Ebbinghaus 遗忘曲线** | **[CS] 有硬伤** | 1885：**n=1（他自己）**、材料为**无意义音节** | 不把指数衰减套到概念学习；只借「间隔优于集中」（已被 [MA] 独立验证） |
| **learning styles（视觉/听觉/动觉匹配）** | **[MA] 无证据** | Pashler et al. 2008, *Learning Styles: Concepts and Evidence*；调查显示 **89.1% 教师仍相信** | **禁用句式**：「你是视觉型学习者，所以……」 |
| **SM-2 / Anki 调度** | **[D] 工程实践** | Wozniak 1987 实现 / 1990 硕士论文《Optimization of Learning》 | 当**调度工具**，不当**学习理论**；不宣称「Anki 排的表 = 科学最优顺序」 |
| **四问锚点 / 第一性原理式推导** | **[D] / [待证]** | 2026-10-22 检索**未找到**直接实证（检索式：`first principles learning method empirical study`、`derivation-first instruction physics`） | 本技能的**工程假设**：合理性挂在你自己的「先证后信」协议上，不挂论文 |

## 2. 怎么用这张表（三条硬规矩）

1. **拿学习法当理由必须带级别**：写「自测优于重读 [MA]，g=0.50」可以；写「费曼法证明你理解了」不行。
2. **[D] 级只借外壳，理由重挂**：「讲给外行听」照做，理由写成 retrieval practice + self-explanation。
3. **禁用句式**（见到就删）：「你是视觉型 / 听觉型学习者」「艾宾浩斯曲线证明必须第 X 天复习」「费曼技巧所以一定有效」「Anki 的表就是科学最优顺序」「据说研究表明」（无出处的"研究表明"）。

## 3. 对现有流程的具体改动

| 原来怎么写 | 现在改成 |
|---|---|
| 复习节奏当定律 | **默认启发式**：间隔 ≈ 保持期 10–20% [MA]（Cepeda 2006） |
| 复习只测本质 + 消失测试 | 补：**必须给反馈**（对原证、指出错在哪）[MA 方向] |
| 「模板内化 ≥5 题」 | 保留，标 **[OBS]**：自定阈值，不是研究结论 |
| 交错练题 | **晚交错、按需交错**：能执行但分不清「何时用哪个」时才交错；新手早期交错会超载工作记忆 [RCT 约束] |

## 4. 社区做法里值得抄的两条

1. **给主张标 `evidence_strength` + `evidence_sources`**（`GarethManning/education-agent-skills` 的字段设计）——把证据做成 skill 的一等公民，而不是散在正文里的"据说"。
2. **claim-based 结构**：`Learning-Design-Alliance/learning-wiki` 把每条主张做成独立文件（`claims/*.md` + `strategies/*.md`），每条挂来源、约束与反例。锚点卡未来照此长：**一个概念一张卡，一个主张一条记录，主张必须可被反例杀死**。

## 5. 已核 / 未核（2026-10-22 收口）

**已核（可引）**：Rowland 2014 总体 g=0.50 [0.42,0.58]；Yang et al. 2021 课堂 222 研究 / 48,478 学生；Cepeda 2006 间隔 10–20% 保持期、d≈0.42（254 研究）；Rohrer et al. 2014/2015 整班随机 + 交错约束；Pashler 2008 学习风格无证据（89.1% 教师仍信）；SM-2 = Wozniak 1987/1990；Dunlosky 2013 判定 practice testing 与 distributed practice 为 high utility。

**仍未核（要读原文，不是要"等有网"）**：① Rowland 2014 中 feedback 亚组的精确 g 与 CI（网上 0.73/0.39 疑似串了 Hattie 2009）；② Cepeda 2006 的"10–20%"在不同材料/保持期下的边界；③ Rohrer 交错的最近一次独立复现（2022+）；④ 四问 / 推导优先教学法的实证——**目前查无**。
