# 学习科学的证据分级（v4.2 新增）

> 本文件回答一个问题：**本技能里那些「学习法」到底有没有证据？**
> 上一版只在 `sources.md` 写了**检索手法**（怎么找资料），没写**学习法本身的证据强弱**——这是两件事。
> 检索日期 2026-10-22（`web_search` 三源），未逐篇读原文者标 `[待核]`。**凡与本文件冲突，以一手原文为准。**

## 0. 证据分级（借鉴社区做法：`GarethManning/education-agent-skills` 的 `evidence_strength` 字段）

| 记号 | 含义 | 能不能作为「为什么这样做」的理由 |
|---|---|---|
| **[MA]** | meta-analysis / systematic review | 能，优先引用 |
| **[RCT]** | 随机对照实验 | 能 |
| **[EXP]** | 受控认知实验（小样本、实验室条件） | 能，但要说明外部效度限制 |
| **[CS]** | 经典奠基研究 | 能，但注意后续是否被修正 |
| **[OBS]** | 观察 / 应用 / 无对照 | 只能作线索 |
| **[D] 社区口传** | 无一手来源，靠博客/视频/名言流传 | **不能**。可以用它的外壳，理由必须另挂 |

## 1. 条目表（本技能实际用到的每个学习法）

| 学习法 | 证据 | 一手来源 | 本技能的落地决定 |
|---|---|---|---|
| **retrieval practice / 自测效应** | **[MA]** | Roediger & Karpicke 2006, *Test-enhanced learning*, Psych. Science；Rowland 2014 meta：整体中等效应，**带反馈 g≈0.73 vs 不带 g≈0.39** | 复习**只测「本质一句 + 消失测试」**，不给选择题、不重读；给反馈（对答案 + 说错在哪） |
| **spaced repetition / 间隔** | **[MA]** | Cepeda et al. 2006, *Distributed practice in verbal recall tasks*（254 项研究）：**最优间隔随保持期增长** | D+1/3/7/21 是**启发式不是定律**；目标越远，间隔越长（约 1:10 比例起步）[待核比例细节] |
| **desirable difficulties / 合意困难** | **[EXP]** | Bjork 1994（*Memory and metamemory considerations in the training of human beings*） | 允许「先攻后守」的挫败：当场顺畅 ≠ 学会了；允许闭卷自推时的卡顿 |
| **interleaving / 交错练习** | **[EXP]**（数学类有争议） | Rohrer 系列 vs 块状练习；结论依赖题型与迁移目标 [待核最新复现] | 题组**交错**排，但**不许声称"交错一定更好"**——遇到「同类题连做更利于内化模板」的场景要说明取舍 |
| **Feynman technique / 费曼技巧** | **[D] 社区口传**（无一手学术文献，常被误挂到费曼本人） | 无原始论文 | 可以保留「讲给外行听」的外壳，但**理由挂到** retrieval practice + self-explanation（有实证）；**禁止**写「费曼证明/费曼说」 |
| **Zettelkasten / 卡片盒双链** | **[D]→[OBS]** 混合 | 一手是 Luhmann 的卡片盒本身 + Ahrens《How to Take Smart Notes》（B 级，无对照实验） | 双链是**检索与连接辅助**，不是记忆增强；不许把它当"记忆法"卖 |
| **Ebbinghaus 遗忘曲线** | **[CS] 但有硬伤** | Ebbinghaus 1885：**n=1（他自己）**、材料是**无意义音节** | 不把指数衰减当定律套到概念学习上；只借「间隔复习优于集中」这个已被 [MA] 独立验证的结论 |
| **learning styles（视觉型/听觉型/动觉型匹配教学）** | **[MA] 无证据** | Pashler et al. 2008, *Learning Styles: Concepts and Evidence*（并有调查显示 89.1% 教师仍相信） | **禁止**用「你是视觉型学习者」解释学习困难；这是本技能的禁用句式 |
| **SM-2 间隔算法（Anki 内核）** | **[D] 工程实践**（非学习科学） | Wozniak 1987 实现 / 1990 硕士论文《Optimization of Learning》 | 当**调度工具**用，不当**学习理论**用；Anki 的到期表可以照跑，但不因此宣称「已按最佳间隔复习」 |

## 2. 怎么用这张表（三条硬规矩）

1. **锚点卡里引用学习法，必须带证据级别**：写「自测优于重读 [MA]」可以，写「费曼法证明理解到位」不行。
2. **[D] 级只能借外壳，理由必须重挂**：「讲给外行听」这个动作照做，但理由写成「retrieval practice + self-explanation [MA/EXP]」。
3. **禁用句式**（见到就删）：「你是视觉型 / 听觉型学习者」「艾宾浩斯曲线证明必须在第 X 天复习」「这是费曼技巧，所以一定有效」「Anki 排的表就是科学最优顺序」。

## 3. 对现有流程的具体改动

| 原来怎么写 | 现在改成 |
|---|---|
| 复习节奏「D+1 / D+3 / D+7 / D+21」当定律 | 写成**默认启发式**，并注明「保持期越远间隔越长 [MA]；按月以上目标应拉长到周级」 |
| 复习「测本质一句 + 消失测试」 | 保留，**补一条**：必须给反馈（对照原证 / 指出错在哪），因为带反馈的效应量是不带的近两倍 [MA] |
| 「模板内化 ≥5 题」 | 保留（工程经验，标 [OBS]），并说明这是**自定阈值**，不是研究结论 |
| 交错练题 | 改成「默认交错，但遇到需要内化单一模板时按块练，并说明这是取舍不是定论」 |

## 4. 社区做法里值得抄的两条

1. **给每条主张标 `evidence_strength` + `evidence_sources`**（`education-agent-skills` 的 skill 字段设计）——让「证据」成为 skill 的一等公民，而不是散在正文里的"据说"。
2. **claim-based wiki 结构**：`learning-wiki` 把「主张」做成独立条目（如 `claims/learning-styles-matching-does-not-improve-learning.md`），每条主张挂来源与反例。锚点卡未来可以照这个形态长：**一个概念一张卡，一个主张一条记录，主张可被反例杀死**。
