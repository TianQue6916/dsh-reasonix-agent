### 常见问题一句话答案

| 问题 | 答案 |
|------|------|
| 习题（Exercises）要不要翻译？ | **不翻译**，保留英文原文（见 `references/format.md` 差异化规则；铁律 9） |
| 公式用什么格式？ | 行内 `$...$`，块级 fenced math block（三个反引号 + math），**禁止 `$$...$$`**（铁律 6） |
| 谁做核心翻译？ | **小规模（≤50 页）**：主代理直接翻译；**大规模（>50 页）**：25×2 dsh 任务翻译，主代理只做切分合并回填 |
| 审计用什么模型？ | 全部 **v4.1 flash（`deepseek-v4.1-flash`）**；超强审计加 `-e max` 并**多轮优化**；**所有审计都是「审计+修复一体」** |
| 写注用什么模型？ | **v4.1 flash（`deepseek-v4.1-flash`）**，全任务统一 |
| 翻译前要找什么资料？ | **全资源搜索**：本机 PocketWiki/ZIM 优先 + 双盘区 + 主力机 SSH + 网络 |
| 一次最多并行几个 dsh 任务？ | 视主力机并发能力分批派发（铁律 21：不用 Reasonix 子代理） |
| 字幕引文怎么写？ | 🎥 标注 + **每条必须附中文翻译**（`（翻译：……）`，见铁律 10） |
| 原书插图要不要保留？ | **要，原图一律不丢**（🚨 铁律 26）——图注翻译**不能**替代图本身；扫描版走「vision 给 bbox → `clip` 裁切 → `assets/`」，见 `references/image-pipeline.md` §10.2 |
| 图里印着的英文（坐标轴、标签、流程图文字）要不要全译？ | 三选一，见 `references/image-pipeline.md` §10.2.5 决策树：**能重排就重排 LaTeX** → **不能就保留原图 + 附转写/翻译** → 混合时「原图 + 中文重绘版」并列 |
| 难概念能不能自己画图？ | **鼓励**（`references/image-pipeline.md` §10.3）：先看判定清单（空间/结构/流程/几何直觉/多步比较），再用四条通道之一生成，图注双语 + 标「译者绘制」 |
